# NS_DamageNumbers (damage number rendering)

- asset_path: /Game/RogueRigs/FX/NS_DamageNumbers (Niagara system, no Blueprint graph); /Game/RogueRigs/FX/M_DamageNumber (material); /Game/RogueRigs/FX/T_DamageDigitsOutline (texture)
- parent_class: none (spawned as one persistent component by `URRDamageNumberSubsystem`, [[sys-damage-numbers]])
- purpose: one sprite per digit; C++ lays out every digit ([[sys-damage-numbers-niagara]]), the asset only spawns and animates them; no actor per hit.
- components: one emitter `DirectionalBurst` (renamed template): CPU sim, world space, fixed bounds +-30000 xy, sprite renderer (Unaligned, FaceCamera, SubImage 16x1, no shadow). Emitter State: Life Cycle Self, Loop Behavior Infinite, so the persistent component never completes.
- exposed_defaults: user parameters set by C++ (contract in [[sys-damage-numbers-niagara]]): `User.DigitPositions/Indices/Sizes/Colors/Criticals/SpawnTimes` (arrays), `User.DigitCount`, `User.DigitBatchId` (int). Old `User.DamageNumber*` removed. Lifetime 0.7 s, rise 85.7 uu/s (60 uu), fade over the last 45 % of life, 0.1 s pop (scale +15 %, crit +35 % and flash to white).
- events: Emitter Spawn sets `Emitter.LastBatchId` 0. Emitter Update: `SpawnPerFrame` count = `(User.DigitBatchId != Emitter.LastBatchId) ? User.DigitCount : 0`, then a SetParameters module sets `Emitter.LastBatchId = User.DigitBatchId`. Initialize Particle: Lifetime Mode Direct Set, Lifetime 0.7 (task-028-02, was Random 0.7-1.75 overridden later). Particle Spawn: `Particles.DNIdx = Engine.ExecIndex` (NOT `Engine.ExecutionIndex`, which reads 0); `Select*FromArray` (Direct Set, index `Particles.DNIdx`) read Size, Position, Color, Digit (Int), Crit (Int), SpawnTime; SubImageIndex = digit, Position = digit centre, Lifetime 0.7. Particle Update sets color alpha and size. No digit math, no division, no modulo.
- logic_in_bp: none (all in Niagara modules; gameplay stays in C++).
- assets: T_DamageDigitsOutline 1024x64 RGBA (replaces T_DamageDigits, task-028-02), 16 cells of 64 px, digits 0-9 in cells 0-9 (5x7 pixel font, 6 px per font pixel, soft edges), RGB white inside and black in a 3 px outline, alpha = digit plus outline, generated by a throwaway script and imported with TextureTools; M_DamageNumber unlit translucent, ParticleSubUV alpha x ParticleColor alpha, emissive = ParticleColor x texture RGB (black outline stays dark over yellow chasers), usage flag NiagaraSprites.
- limits: SpawnTimes is read into `Particles.DNSpawnT` only to keep the parameter exposed (an unreferenced Data Interface user parameter is dropped, and `AddUserVariables` cannot create one: it is created by linking a module input to it). Check: `RogueRigs.DamageNumbers.NiagaraIntegration` in the editor: 4 digits pushed, 4 particles spawned, no Niagara warning. Per-digit index variation to be confirmed visually (task-025-06).
- owner_agent: agent-bp
