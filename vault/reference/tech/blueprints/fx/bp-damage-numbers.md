# NS_DamageNumbers (damage number rendering)

- asset_path: /Game/RogueRigs/FX/NS_DamageNumbers (Niagara system, no Blueprint graph); /Game/RogueRigs/FX/M_DamageNumber (material); /Game/RogueRigs/FX/T_DamageDigitsOutline (texture)
- parent_class: none (spawned as one persistent component by `URRDamageNumberSubsystem`, [[sys-damage-numbers]])
- purpose: one sprite per digit; C++ lays out every digit ([[sys-damage-numbers-niagara]]), the asset only spawns and animates them; no actor per hit.
- components: one emitter `DirectionalBurst` (renamed template): CPU sim, world space, fixed bounds +-30000 xy, sprite renderer (Unaligned, FaceCamera, SubImage 16x1, no shadow). Emitter State: Life Cycle Self, Loop Behavior Infinite, so the persistent component never completes.
- exposed_defaults: user parameters set by C++ (contract in [[sys-damage-numbers-niagara]]): `User.DigitPositions/Indices/Sizes/Colors/Criticals/SpawnTimes` (arrays), `User.DigitVelocities` (Vector Array, task-240-02), `User.DigitCount`, `User.DigitBatchId` (int). Old `User.DamageNumber*` removed. Lifetime 0.7 s, rise = per-number velocity from `User.DigitVelocities` multiplied by 4 in the asset, then thrown in an arc under a Gravity Force of (0,0,-980) uu/s2 (task-242, below; the array keeps the nominal 85.7 uu/s; speed x0.7-1.3, angle +-35 degrees, drawn in C++), fade over the last 45 % of life, 0.25 s pop (scale +15 %, crit +35 % and flash to white; Particle Update SetVariables expressions `saturate(Particles.Age / 0.25)` on Color and SpriteSize, was 0.1; provisional, owner 2026-10-19, task-241).
- events: Emitter Spawn sets `Emitter.LastBatchId` 0. Emitter Update: `SpawnPerFrame` count = `(User.DigitBatchId != Emitter.LastBatchId) ? User.DigitCount : 0`, then a SetParameters module sets `Emitter.LastBatchId = User.DigitBatchId`. Initialize Particle: Lifetime Mode Direct Set, Lifetime 0.7 (task-028-02, was Random 0.7-1.75 overridden later). Particle Spawn: `Particles.DNIdx = Engine.ExecIndex` (NOT `Engine.ExecutionIndex`, which reads 0); `Select*FromArray` (Direct Set, index `Particles.DNIdx`) read Size, Position, Color, Digit (Int), Crit (Int), SpawnTime; SubImageIndex = digit, Position = digit centre, Velocity = `SelectVectorFromArray` (Direct Set, index `Particles.DNIdx`, array linked to `User.DigitVelocities`; was the constant float3(0,0,85.714)), Lifetime 0.7. After the Velocity setter, an added SetParameters module (task-242-01) sets `Particles.Velocity = Particles.Velocity * float3(4.0, 4.0, 4.0)` (horizontal and vertical scaled alike). Particle Update: ParticleState, then `GravityForce001` (Gravity (0,0,-980), Coordinate Space World; inserted before SolveForcesAndVelocity, which must stay after the forces), SolveForcesAndVelocity, then the color/size SetVariables. Arc arithmetic at the nominal speed: v0 = 85.714 x 4 = 342.86 uu/s, g = 980, peak = v0^2 / (2g) = 60.0 uu, reached at v0 / g = 0.35 s, back to the spawn height at 0.7 s (the end of life); speed x0.7-1.3 gives peaks 29 to 101 uu at 0.25 to 0.45 s. Provisional, owner 2026-10-19, task-242; the visual check is not done by the bp agent. No digit math, no division, no modulo.
- logic_in_bp: none (all in Niagara modules; gameplay stays in C++).
- assets: T_DamageDigitsOutline 1024x64 RGBA (replaces T_DamageDigits, task-028-02), 16 cells of 64 px, digits 0-9 in cells 0-9 (5x7 pixel font, 6 px per font pixel, soft edges), cell 10 = "+" (task-324-01: 5x7 plus on the same grid origin x 17, y 11 of the cell, stem and bar 1 font pixel wide, same soft edge and 3 px outline; cells 0-9 and 11-15 pixel-identical to before; cell 11 = Duskite icon (task-430-01, below); source PNG Art/Source/damage-digits/T_DamageDigitsOutline.png, previous atlas T_DamageDigitsOutline_before_task-324-01.png, cell 10 drawn by a throwaway script; asset reimported by delete + TextureTools import, same settings, M_DamageNumber reference reassigned), RGB white inside and black in a 3 px outline, alpha = digit plus outline, generated by a throwaway script (cells 0-9) and imported with TextureTools; M_DamageNumber unlit translucent, ParticleSubUV alpha x ParticleColor alpha, emissive = ParticleColor x texture RGB (black outline stays dark over yellow chasers), usage flag NiagaraSprites.
- icon cell (task-430-01, provisional, owner 2026-11-04): cell 11 of T_DamageDigitsOutline holds the Duskite icon, the HUD ore crystal T_Icon_Ore ([[wbp-ore-counter]]) shrunk to 40 px on its long side, in its own violet colours, with a black outline drawn under it (the first version, commit 6a1ca762, rendered black in game; fixed in f092bfb7: violet colours kept, outline under the icon). Drawn by C++ as glyph `OreGlyph` 11 with white particle colour ([[sys-damage-numbers]] ore numbers). Source PNG `Art/Source/damage-digits/T_DamageDigitsOutline.png`; previous atlas (cell 11 empty) `Art/Source/damage-digits/T_DamageDigitsOutline_before_task-430-01.png`. `/Game/RogueRigs/FX/T_DamageDigitsOutline` and `M_DamageNumber` updated (material change in 6a1ca762 and f092bfb7; the diffs are binary, the exact material edit is `open`). In game the icon reads about the height of the digit "1". Cells 12-15 stay free.
- limits: SpawnTimes is read into `Particles.DNSpawnT` only to keep the parameter exposed (an unreferenced Data Interface user parameter is dropped, and `AddUserVariables` cannot create one: it is created by linking a module input to it).
