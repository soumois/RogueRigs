# BP_PickupXP

- asset_path: /Game/RogueRigs/Blueprints/Pickups/BP_PickupXP
- parent_class: ARRPickup (/Script/RogueRigs.RRPickup)
- purpose: the XP pickup dropped by dead robots; visuals only ([[sys-pickups]]).
- components: inherited root PickupMesh plus TrailFX (NiagaraComponent, Asset NS_XPTrail, bAutoActivate off, attached to the root; replaces the former stretched-cube Trail StaticMeshComponent, removed in task-054-01).
- exposed_defaults: PickupType = XP; PickupMesh = /Game/RogueRigs/Art/XPNut/SM_XPNut (hex nut, 30 cm across corners, pivot at the geometric centre, z -5.85 to 5.85, like the old cube; an exception to the bottom-centre pivot of [[asset-pipeline]] because the pickup root is placed by SetActorLocation, owner 2026-10-13), scale (1, 1, 1) (the old cube at 0.3 had the same 30 cm footprint); OverrideMaterials[0] = M_XPNut_body, [1] = M_XPNut_hole (task-132-01). Collision unchanged. The PickupMesh casts no shadow (CastShadow false, task-134-01). TrailFX relative scale (0.3, 0.3, 0.3) so its effective scale stays that of the old cube-scale root (it inherits the root scale, now 1). Vertical offset not applied: PickupMesh is the root and the C++ sets the actor location directly, so a root offset cannot persist (task-135: this is why the pivot is now centred in the FBX and the mesh was reimported by the owner in the editor, bounds read back z -5.85 to 5.85). The sparkle uses SpawnSystemAtLocation in world space and needs no change.
- events: OnMagnetStart activates TrailFX and rotates the actor to face the miner (FindLookAtRotation, set once); OnCollected(Location) calls Niagara SpawnSystemAtLocation with NS_PickupSparkle at Location, auto-destroy ([[bp-pickup-sparkle]]); on BP_PickupXPBig the system is NS_PickupSparkleBig (magenta copy, particle Color (1, 0.15, 0.75), task-122-01).
- logic_in_bp: display only (two events).
- assets: /Game/RogueRigs/Art/XPNut/: SM_XPNut; M_XPNutGlow (copy of M_GreyBoxGlow, emissive = GlowColor x GlowAmount x (1 + PulseAmount x sin(2 pi (Time x PulseFrequency + phase))), phase = dot(ObjectPositionWS, (0.0137, 0.0211, 0)) in cycles so pickups do not blink together; PulseAmount parent default 0.15, overridden to 0.4 on the three glow instances (provisional, owner 2026-10-13, task-136-01); PulseFrequency 0.8333 = period 1.2 s; no tick); M_XPNut_body (parent M_GreyBox, Color linear (0.162, 0.178, 0.198) = #70757B); M_XPNut_hole (parent M_XPNutGlow, Color and GlowColor (0, 0.9, 1), GlowAmount 25 (was 4, then 10; set by the owner in the editor after a test at 50 showed no light on the floor, owner 2026-10-13), PulseAmount 0.4, [[color-code]]). MI_GB_PickupXP (Color 0, 0.9, 1, 1) is no longer used by this Blueprint (the cube pickup is gone). /Game/RogueRigs/Materials/GreyBox/MI_GB_PickupXP (Color 0, 0.9, 1, 1, glowing cyan, [[color-code]]). NS_XPTrail (/Game/RogueRigs/FX/NS_XPTrail, ribbon in world space, cyan 0/0.9/1, width 10, lifetime 0.35 s, SpawnRate 60 per second in the emitter update: without a spawn module the emitter produced no particle and the trail was invisible, task-058-01) and NS_PickupSparkle (/Game/RogueRigs/FX/NS_PickupSparkle, 18-sprite cyan burst, lifetime 0.18-0.28 s, no gravity). MI_XPTrail is no longer used.
- big_block (task-110-02): the cube class default `XPBigPickupClass` = BP_PickupXPBig (/Game/RogueRigs/Blueprints/Pickups/BP_PickupXPBig), which turns the big XP block feature on ([[sys-pickups]]). To turn it off, clear `XPBigPickupClass` in the class defaults of BP_PickupXP (set it to None), compile and save.
- sibling BP_PickupXPBig: a duplicate of BP_PickupXP (same parent ARRPickup, NOT a child of the cube, so its own `XPBigPickupClass` stays empty); PickupType XP, same components and events (TrailFX, magnet look-at, sparkle). Task-133-01: root PickupMesh = /Game/RogueRigs/Art/XPChip/SM_XPChipBig (chip 30 x 30 x 10.6 cm, centred pivot z -5.3 to 5.3, 844 tris), template scale (1.8, 1.8, 1.8) (30 cm footprint x 1.8 = 54 cm, as the old cube 100 cm x 0.54; the pool restores the scale from the spawned root template, no C++ constant, [[sys-pickups-xp]]); OverrideMaterials[0..6] = M_XPChip_board, casing, casing_chamfer, edge_band, core_bright, core_dark, legs (slot order of the mesh, also set as mesh defaults). Non-emissive slots: instances of M_GreyBox with linear Color from the FBX report (#2B2E34, #3C4048, #585E69, #8F959F, #8A9099). core_bright: parent M_XPNutGlow, Color and GlowColor (0.8, 0.25, 1.0) lilac-violet, GlowAmount 25 (was 10, magenta (1, 0.2, 0.8) before; same level as the nut; provisional, owner 2026-10-13, task-140-01, colour a first guess from a sample of bright sRGB (233, 155, 245) and centre (112, 41, 124)); core_dark: same parent, (0.45, 0.12, 0.6), GlowAmount 12 (was 5, (0.69, 0.06, 0.5) before; provisional, owner 2026-10-13; keeps facet relief); PulseAmount 0.4 unchanged; NS_PickupSparkleBig, NS_XPTrailBig and MI_PickupXPBig stay magenta (mismatch for the owner to decide); same pulse as the nut (40 percent, period 1.2 s, phase from world position, no tick). TrailFX (Asset NS_XPTrailBig, magenta copy of NS_XPTrail, task-122-01) relative scale (0.3, 0.3, 0.3): it inherits the root scale 1.8, so the effective scale stays 0.54 as before. Vertical offset: PickupMesh is the inherited root, so the pivot of the FBX is centred instead (task-135, reimported by the owner, bounds read back z -5.3 to 5.3). MI_PickupXPBig is no longer used by this Blueprint (asset kept). Assets in /Game/RogueRigs/Art/XPChip/. Collision, no light and no ground disc unchanged. The PickupMesh casts no shadow (CastShadow false, task-134-01).
