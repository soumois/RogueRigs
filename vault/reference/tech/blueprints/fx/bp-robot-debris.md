# NS_RobotDebris

- asset_path: /Game/RogueRigs/FX/NS_RobotDebris (Niagara system, no Blueprint; created from the NS_RobotDeathPuff template, its sprite emitter removed, emitter `Debris` added from the engine template UpwardMeshBurst)
- parent_class: UNiagaraSystem
- purpose: debris pieces thrown by a dying chaser or shield chaser at the end of the 0.15 s shrink; stays 3 s, then sinks into the floor in 0.4 s ([[enemy-death]]); played at the robot feet by `URRNiagaraPoolSubsystem` ([[sys-actor-pool]], [[sys-enemies-base]] `DebrisSystem`, pool 40).
- user_params: `User.PieceMeshIndex` (Array Int32), `User.PieceOffset` (Array Vector), `User.HitDirection` (Vector). Created through a Linked stack input (AddUserVariables silently ignores data interface types).
- components: one CPU mesh emitter `Debris`, world space, mesh renderer with the 13 `SM_ChaserDebris_*` meshes in report order (0 Torso, 1/2 UpperArm L/R, 3/4 Forearm, 5/6 Arm, 7/8 Thigh, 9/10 LowerLeg, 11/12 Leg), mesh materials kept (no override), shadows off.
- spawn: SpawnBurst_Instantaneous at t = 0, count = dynamic input GetInt32ArrayCount(User.PieceMeshIndex). InitializeParticle: lifetime 3.4 s (direct), colour white, scale 1, Mesh Renderer Mesh Index = Direct Set with SelectIntFromArray(User.PieceMeshIndex, index = ReturnExecIndex) (writes Particles.MeshIndex). Initial orientation Mode System (robot yaw).
- spawn_sets (SetParameters, HLSL expressions): `Particles.PieceLocal` = 13-entry table of `centre_offset_cm_unreal` keyed by Particles.MeshIndex; `Particles.Position` = `max(Particles.Position + PieceLocal rotated by Engine.Owner.Rotation + float3(rand(2.0)-1.0, rand(2.0)-1.0, rand(2.0)-1.0)*10.0, float3(-1e30, -1e30, Engine.Owner.Position.z))` (task-172: baked rest offset, then a random offset uniform in [-10, 10] cm per axis, one rand per axis; the component-wise max clamps Z to the system Z so no piece starts under the floor); `Emitter.ThrowScale` (emitter spawn SetParameters module, `1.3 + 0.7*rand(1.0)`, drawn once per system activation, shared by all particles); `Particles.ThrowAngle` = `(rand(1.0)*2.0 - 1.0)*0.2617994` (±15 degrees in radians, one per piece); `Particles.Velocity` (same module, after ThrowAngle) = `Emitter.ThrowScale * (HitDirection rotated around Z by ThrowAngle x (250 + 200 rand) + up (300 + 200 rand) + horizontal spread 100)`; `Particles.SpinRate` random vector.
- update: ParticleState (kill at lifetime), GravityForce -980 world, UpdateMeshOrientation rate 1.5 rev/s about Particles.SpinRate, Drag 0.3, ScaleMeshSize removed (scale stays 1), Collision (CPU Analytical Planes, one plane, normal +Z, position HLSL `Engine.Owner.Position - float3(0, 0, (Particles.Age >= 3.0) ? 1000.0 : 0.0)` (plane dropped 10 m at age 3.0 s so it no longer holds the piece), world space, radius 6 cm, restitution 0.35, friction 0.5; no scene query), SolveForcesAndVelocity (Collision requires it after), then a SetParameters module after the solver: `Particles.Velocity` = `(Particles.Age >= 3.0) ? float3(0, 0, -140) : Particles.Velocity` (sink: stops sideways slide, about 150 cm/s down plus gravity, roughly 60 cm in 0.4 s, piece fully under the floor at age 3.4 s).
- one_shot: system loop Once, duration 0.1 s, inactive response Complete (inherited from the puff template, read back); emitter loop Once, duration 0.1 s; last particle dies at 3.4 s, then the pooled component returns.
- deviations: (1) `User.PieceOffset` is declared and linked but NOT read: no Niagara module or dynamic input reads an Array Vector element by index (SelectVectorFromArray picks at random; DI calls in an HLSL expression fail to compile). The offset is rebuilt from a baked table of the 13 offsets keyed by MeshIndex and rotated by the component rotation, which reproduces the C++ yaw-rotated offset exactly as long as DebrisPieces keep the json offsets. (2) Sink (task-170): no end shrink; from age 3.0 s the collision plane is lowered and the velocity forced downward, so the piece sinks without shrinking. Sink depth is approximate (velocity-driven), not an exact 60 cm.
- events: none
- logic_in_bp: none
- assets: used by BP_Chaser ([[bp-chaser]]) and BP_ShieldChaser ([[bp-shield-chaser]]) as DebrisSystem.
- tools_that_worked: AddSetParametersModule in EmitterSpawnScript (new Emitter.* float), AddSetParameterEntry, RemoveSetParameterEntry (param parameterName), RemoveModule (param moduleToRemove), NiagaraToolset_System CreateNiagaraSystem, AddEmitter, RemoveEmitter, AddModule, RemoveModule, AddSetParametersModule, SetStackInputData (DynamicInput, Linked, HlslExpression, Enum), SetRendererData, GetStackIssues, GetSystemCompileState. Compile is asynchronous: wait a few seconds then read GetStackIssues (compile errors appear there and in compile events).
