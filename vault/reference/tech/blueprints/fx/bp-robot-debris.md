# NS_RobotDebris

- asset_path: /Game/RogueRigs/FX/NS_RobotDebris (Niagara system, no Blueprint; created from the NS_RobotDeathPuff template, its sprite emitter removed, emitter `Debris` added from the engine template UpwardMeshBurst)
- parent_class: UNiagaraSystem
- purpose: debris pieces thrown by a dying chaser or shield chaser at the end of the 0.15 s shrink; stays 4.5 s, then sinks into the floor in 0.4 s ([[enemy-death]]); played at the robot feet by `URRNiagaraPoolSubsystem` ([[sys-actor-pool]], [[sys-enemies-base]] `DebrisSystem`, pool 40).
- user_params: `User.PieceMeshIndex` (Array Int32), `User.PieceOffset` (Array Vector), `User.HitDirection` (Vector). Created through a Linked stack input (AddUserVariables silently ignores data interface types).
- gpu_switch (task-191-01, owner 2026-10-15): emitter `Debris` is now GPUComputeSim (read back), `CalculateBoundsMode` Fixed, FixedBounds min (-2000, -2000, -200) max (2000, 2000, 1500) cm. All modules and expressions kept unchanged; the system compiles UpToDate with `ParticleGPUComputeScript` UpToDate, no stack issue (2 info notes). Collision module: `GPU Collision Type` = GPU Distance Fields (enum NewEnumerator2; NewEnumerator1 is Depth Buffer; NewEnumerator0 left it unchanged), `Collision Enabled` = HLSL `Particles.Age < 4.5` (collision off from age 4.5 s, so the sink goes through the floor), Radius 6, Restitution 0.35, Friction 0.5 unchanged. The module offers ONE GPU mode (distance fields, depth buffer or analytical planes): the analytic floor plane is not used on GPU; the floor is collided as part of the scene distance fields (grid HISMs). The old `Analytical Collision Plane Position 1` expression stays in the module but is inert. The CPU description below (analytic plane) applies to the history before task-191-01.
- components: one mesh emitter `Debris` (GPU since task-191-01; CPU before), world space, mesh renderer with the 13 `SM_ChaserDebris_*` meshes in report order (0 Torso, 1/2 UpperArm L/R, 3/4 Forearm, 5/6 Arm, 7/8 Thigh, 9/10 LowerLeg, 11/12 Leg), mesh materials kept (no override), shadows off.
- spawn: SpawnBurst_Instantaneous at t = 0, count = dynamic input GetInt32ArrayCount(User.PieceMeshIndex). InitializeParticle: lifetime 4.9 s (task-182-01, was 3.4) (direct), colour white, scale 1, Mesh Renderer Mesh Index = Direct Set with SelectIntFromArray(User.PieceMeshIndex, index = ReturnExecIndex) (writes Particles.MeshIndex). Initial orientation Mode System (robot yaw).
- spawn_sets (SetParameters, HLSL expressions): `Particles.PieceLocal` = 13-entry table of `centre_offset_cm_unreal` keyed by Particles.MeshIndex; `Particles.Position` in two steps (task-174): (1) `Particles.Position + (Particles.PieceLocal + 2.0*cross(Engine.Owner.Rotation.xyz, cross(Engine.Owner.Rotation.xyz, Particles.PieceLocal) + Engine.Owner.Rotation.w*Particles.PieceLocal)) + float3(rand(2.0)-1.0, rand(2.0)-1.0, rand(2.0)-1.0)*10.0` (baked rest offset rotated by the owner quaternion, plus a random offset uniform in [-10, 10] cm per axis); (2) a second SetParameters module right after it: `float3(Particles.Position.x, Particles.Position.y, max(Particles.Position.z, Engine.Owner.Position.z))` (clamps Z to the system Z so no piece starts under the floor; the former single vector max compiled to one scalar for all axes and sent pieces to (s,s,s) near the origin); `Emitter.ThrowScale` (emitter spawn SetParameters module, `1.3 + 0.7*rand(1.0)`, drawn once per system activation, shared by all particles); `Particles.ThrowAngle` = `(rand(1.0)*2.0 - 1.0)*0.2617994` (±15 degrees in radians, one per piece); `Particles.Velocity` (same module, after ThrowAngle) = `Emitter.ThrowScale * (HitDirection rotated around Z by ThrowAngle x (250 + 50 rand) + up (269.2 + 5.8 rand) + horizontal spread 100)` (task-186-01, owner 2026-10-15: with F 1.3-2 the final speed is 325-600 along the direction and 350-550 upward; was 250-450 and 300-500 base); `Particles.SpinRate` random vector (axis); `Particles.SpinSpeed` (task-190-01, own SetParameters module after the Velocity one) = `0.3 + 0.5 * rand(1.0)` rev/s per piece.
- update: ParticleState (kill at lifetime), GravityForce -980 world, UpdateMeshOrientation about Particles.SpinRate with Rotation Rate linked to Particles.SpinSpeed (task-190-01, was a fixed 1.5 rev/s), Drag 0.3, ScaleMeshSize removed (scale stays 1), Collision (CPU Analytical Planes, one plane, normal +Z, position HLSL `Engine.Owner.Position - float3(0, 0, (Particles.Age >= 4.5) ? 1000.0 : 0.0)` (plane dropped 10 m at age 4.5 s so it no longer holds the piece), world space, radius 6 cm, restitution 0.35, friction 0.5; no scene query; `Analytical Plane Debug Mode` = 0 since task-179: the template default 1 drew a red 200 x 200 cm plane at the system position, i.e. a red square on the floor under every active debris system; the `DebugDraw` data interface input stays at its default and draws nothing in mode 0), SolveForcesAndVelocity (Collision requires it after), then a SetParameters module after the solver: `Particles.Velocity` = `(Particles.Age >= 4.5) ? float3(0, 0, -140) : Particles.Velocity` (sink: stops sideways slide, about 150 cm/s down plus gravity, roughly 60 cm in 0.4 s, piece fully under the floor at age 4.9 s). Then three SetParameters modules (task-190-01, one per variable because entries of one module read the old values): (a) `Particles.SpinSpeed` = `Particles.SpinSpeed * exp2(-Engine.DeltaTime / 1.0) * (((Particles.Velocity.z > 0.0) && (Particles.PrevVelZ < 0.0) && ((Particles.Position.z - Engine.Owner.Position.z) < 15.0)) ? 0.5 : 1.0)` (half-life 1 s; bounce = post-solve Velocity Z flips from negative to positive within 15 cm of the floor plane, halves the spin); (b) `Particles.SpinSpeed` = `(((Particles.Position.z - Engine.Owner.Position.z) < 12.0) && (length(Particles.Velocity) < 20.0)) ? 0.0 : Particles.SpinSpeed` (rest); (c) `Particles.PrevVelZ` = `Particles.Velocity.z` (kept for the next update).
- one_shot: system loop Once, duration 0.1 s, inactive response Complete (inherited from the puff template, read back); emitter loop Once, duration 0.1 s; last particle dies at 4.9 s, then the pooled component returns.
- deviations: (1) `User.PieceOffset` is declared and linked but NOT read: no Niagara module or dynamic input reads an Array Vector element by index (SelectVectorFromArray picks at random; DI calls in an HLSL expression fail to compile). The offset is rebuilt from a baked table of the 13 offsets keyed by MeshIndex and rotated by the component rotation, which reproduces the C++ yaw-rotated offset exactly as long as DebrisPieces keep the json offsets. (2) Sink (task-170): no end shrink; from age 4.5 s the collision plane is lowered and the velocity forced downward, so the piece sinks without shrinking. Sink depth is approximate (velocity-driven), not an exact 60 cm.
