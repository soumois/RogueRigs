- purpose: the playable miner pawn; visuals only, all logic in C++ ([[sys-player]]).
- components: inherited from C++ plus LevelUpDisc (engine cylinder, scale 1.5, 1.5, 0.02 at z -80, MI_GB_PickupXP cyan, hidden, NoCollision, no shadow); PlayerLight (task-263-02, below); int variable DiscStep; function DiscStep_Tick.

- events: BeginPlay assigns the LevelUp component delegate OnLevelUpEffect to a custom event (task-014-04; rebuilt in task-024-05). The event clears the DiscStep_Tick timer, sets DiscStep 0, resets LevelUpDisc scale to 1.5, shows it and sets a 0.1 s timer by function name; DiscStep_Tick adds 1 to DiscStep, sets scale 1.5 + 0.8 * step, re-arms the timer until step 5, then hides the disc (0.5 s, max scale 5.5; orchestrator decision 2026-10-05: keep this short animation). No component is added or destroyed, so overlapping level-ups just restart the animation (the old AddComponent/Delay version raised "not valid (pending kill or garbage)" runtime errors). Task-028-02: the same event also spawns BP_HealRing ([[bp-heal-ring]]) at the miner feet (location z - 85) through SpawnActorFromClass, so the level-up heal shows the green ring (PIE: no runtime error). Sound hook: open, empty. Tunables ChoiceDelay 0.8, HealFraction 0.2, CardCount 3 are the C++ defaults ([[sys-level-up]]).
- logic_in_bp: visual effect only (level-up disc timer steps)
- assets: SKM_Quinn_Simple and ABP_Unarmed from the template mannequins.
- owner_agent: agent-bp
- weapons (task-024-05): StartingWeapons = [BP_BurstRifle_C] only; GuaranteedWeaponClasses empty; WeaponCatalogue = BP_BurstRifle_C, BP_Shotgun_C, BP_TurretLauncher_C with English descriptions since task-032-02 ("Precise bursts that pierce through robots.", "A short-range spray of pellets that knocks robots back.", "Places turrets that fire at nearby robots on their own."); MaxWeapons 4. The values listed below are the task-263-02 ones (revert: radius 1400, intensity 60).
Provisional, owner 2026-10-20: the owner tunes by eye (nothing could be seen by the agent, values read back only). Previous state: no light component on BP_Miner. The warm pool of light around the miner, the only shadow caster ([[lights-no-shadows]]).
- Component: PointLightComponent `PlayerLight`, child of the capsule (CollisionCylinder, the C++ root), not of the skeletal mesh, so it does not bob. Added with `ActorTools.add_component` (owner = the Blueprint asset), values with `ObjectTools.set_properties` on `BP_Miner_C:PlayerLight_GEN_VARIABLE`, then compile and save.
- Read back after compile and save: mobility Movable; relativeLocation (0, 0, 300) (about 300 uu above the capsule centre), absolute location false; lightColor (1.0, 0.62, 0.30) (stored 8-bit, 0.6196 / 0.3020); intensityUnits Candelas; intensity 60; attenuationRadius 1400; sourceRadius 20; softSourceRadius 0; bUseInverseSquaredFalloff true (lightFalloffExponent unused); castShadows true; castStaticShadows false; castDynamicShadows true; bAffectTranslucentLighting true; indirectLightingIntensity 1; volumetricScatteringIntensity 0; bUseTemperature false; lightFunctionMaterial None; shadowBias 0.5, shadowSlopeBias 0.5 (defaults). Lumen and MegaLights settings left at default.
- Intensity reasoning: Candelas, inverse squared falloff, so illuminance = cd / d^2 (d in metres). The sun is 1.0 and the sky light 0.5, both violet ([[lights-dark-ambient]]). At 60 cd the floor under the light (3 m) gets about 6.7, a wall at 700 uu about 1.1, the 1400 uu edge about 0.3 (clamped to 0 at the radius). So the pool reads clearly above the ambient near the miner and fades toward the edge. Auto-exposure was not checked.
- Tune: intensity (30 dimmer, 100 stronger pool); AttenuationRadius (pool size; also the main cost knob); relative Z (higher = wider, softer wall shadows, lower = longer shadows); lightColor.
- Revert: remove the component with `ActorTools.remove_component` on the PlayerLight path (or Components panel, Delete), compile, save. The Blueprint then has no light as before.
- Perf: a moving local light with shadows invalidates its virtual shadow map pages every frame ([[perf-risks]], row Player light shadows). Knobs: lower AttenuationRadius, set castShadows false (pool stays, no wall shadows), or raise shadow bias/lower shadowResolutionScale.
- Unverified: appearance in game, exposure, shadow quality, frame cost.
