# WBP_UpgradeChoice

- asset_path: /Game/RogueRigs/UI/WBP_UpgradeChoice
- parent_class: URRHUDPanelWidget (/Script/RogueRigs.RRHUDPanelWidget, [[sys-hud-events]])
- purpose: shows the three upgrade cards and the reroll button; a sub-widget of [[wbp-hud]], which only places it (variable UpgradeChoice, last child of Root, anchors 0,0 to 1,1, zero offsets, z-order 10, Visibility SelfHitTestInvisible: the instance itself takes no clicks, its Backdrop and buttons do, as UpgradeScreen did).
- components: CanvasPanel Root > UpgradeScreen (CanvasPanel, full screen, Collapsed until an offer) = Backdrop (Border, black alpha 0.7) + Panel (VerticalBox, centred, auto size): TitleText "Choose an upgrade" (36), CardsRow (HorizontalBox) of three SizeBox CardSize0..2 (512 x 732, row padding 14 left and right, 40 px gap; Border 6 + Button padding 6: card stack 500 x 720, task-177-02) > CardBorder<i> (Border, padding 6; tier colour for a new-weapon card, alpha 0 for a stat card) > CardButton<i> (all states NoDrawType) > CardStack<i> (Overlay): CardPanel<i> (Image, RoundedBox brush #15171c, slot Fill with padding 14 24 14 25 = about half the opening inset, so it fills only the frame opening and its edges hide under the frame), FrameGroup<i> (Overlay of FrameBase / FrameAccents / FrameGlow, task-168-09: plain Image brushes (Draw As Image, margins 0) of the baked textures T_CardFrame_Stat_Baked, _Accents_Baked (1000 x 1440 since task-177-02), _Glow_Baked (still 880 x 1440, stretches slightly until task-178-02), ImageSize 500 x 720, all frame image slots Fill, base untinted, Accents and Glow tinted by tier), CardBox<i> (VerticalBox, padding 38 58 38 60 = opening inset 28 48 28 50 + 10) = ImageArea<i> (SizeBox 408 x 320) > ImageBg<i> (Border #1c1f26, radius 4) > ImageRow<i> (HorizontalBox) of WeaponBox<i> (SizeBox 190 x 80 > ScaleBox > WeaponIcon<i>, right padding 14) and StatIconBox<i> (SizeBox, no override since task-176-01, sized by the StatIcon desired size set in StyleCard > StatIcon<i>); EffectScale<i> (ScaleBox, DownOnly, top 18) > EffectRow<i> = CardValue<i> (Roboto Bold 30, tier colour) + CardName<i> (Bold 30 white); CardTarget<i> (Bold 20 #C9CCD4, top 8); CardDesc<i> (lore, Italic 16 #8B909D, wrapped, slot Fill with bottom alignment so it is always at the bottom of the box). New-weapon variant (task-169-04): WeaponGroup<i> (Overlay in CardStack<i>, slot Fill, between FrameGroup and CardBox, Collapsed unless NewWeapon) = FrameWeapon<i> (Image, Image brush of T_CardFrame_Weapon_Baked untinted, 1000 x 1440 texture, ImageSize 500 x 720, slot Fill) + WeaponHeader<i> (Roboto Bold 24 white, top, padding top 5, on the header plate about 37 px tall) + WeaponBody<i> (VerticalBox, padding 38 56 38 44 = opening insets 28 sides, bottom bar 33.5, plus 10): WeaponImgBox<i> (SizeBox 408 x 290) > WeaponImgScale<i> (ScaleToFit) > WeaponImg<i>, WeaponName<i> (Bold 30 white), WeaponDesc<i> (Roboto 17 #C9CCD4, wrapped). EffectScale<i> is now a variable. Then RerollButton (HAlign centre) > RerollText "Reroll" (24). Variables: UpgradeScreen, CardSize/Border/Button/Name/Target/Value/Desc, FrameGroup, FrameAccents, FrameGlow, ImageArea, WeaponBox, WeaponIcon, StatIcon, EffectRow, RerollButton, RerollText. No widget of the old tree was removed.
- events: hook BindToMiner(Miner, PreviousMiner): UnbindCards(Previous); valid miner: assigns the level-up component's OnUpgradeOfferShown and OnUpgradeOfferClosed to custom events (editor names OnUpgradeOfferShown_Event_0, OnUpgradeOfferClosed_Event_0) and, when IsAwaitingChoice, calls ShowCards(GetOfferCards, CanReroll) (bind-time read); otherwise CloseCards. Null miner: CloseCards. Offer shown calls ShowCards; closed calls CloseCards. Construct assigns the OnClicked of CardButton0..2 and RerollButton to custom events (OnClicked_Event .. _2) that call ChooseCard(0..2) and RerollCards (the old component-bound OnClicked events could not be written through the DSL). Destruct calls UnbindCards(GetMiner).
- functions: ShowCards(Cards, bCanReroll): UpgradeScreen Visible, RerollButton enabled, then per index 0..2 SetCard + StyleCard when the card exists else CardSize Collapsed. SetCard(Card, Size, Border, Name, Target, Value, Accents, Glow): texts from DisplayName / TargetText / ValueText; per Tier (grey 0.55, green 0.2/0.8/0.25, blue 0.2/0.45/1, purple 0.65/0.25/0.9, yellow 1/0.85/0.1) sets Border colour, Accents and Glow tint and the Value text colour. StyleCard(Card, Border, Desc, Value, FrameGroup, ImageArea, WeaponBox, WeaponIcon, StatIcon): StatUpgrade = Border alpha 0, FrameGroup and ImageArea visible, Value visible, ShowCardFlavor, StatIcon = GetStatIcon(Stat), then SetDesiredSizeOverride StatIcon 156 x 156 (task-176-01); by Target: Player and AllWeapons collapse WeaponBox (icon stays 156 x 156), Weapon shows it, resets the StatIcon override to 100 x 100 with GetWeaponIconByName(TargetText), sets the icon brush resource, then SetDesiredSizeOverride to the texture's real size (guarded by IsValid) so the ScaleBox (ScaleToFit) keeps the icon aspect inside 168 x 64. NewWeapon = Border alpha 0 (no teal border any more), FrameGroup, ImageArea, EffectScale, CardTarget and CardValue Collapsed, WeaponGroup SelfHitTestInvisible, WeaponHeader = DisplayName, WeaponName = TargetText, WeaponDesc = DescriptionText, WeaponImg = GetWeaponIconByName(TargetText) with the same desired-size override, CardDesc = LoreText (Visible only when non-empty; bottom-anchored). StyleCard now also takes WeaponGroup, WeaponHeader, WeaponDesc, WeaponImg, EffectScale, Target, WeaponTitle (the StatUpgrade branch collapses WeaponGroup and shows EffectScale and Target). ShowCards passes them by name. Meaning change: on a weapon card CardDesc<i> now holds the lore, not DescriptionText, and CardTarget<i> keeps TargetText but is Collapsed; the integration test RRWeaponsIntegrationTests (Integration.WeaponCardEquipsShotgun) was updated in task-169-05: WeaponHeader, WeaponName, WeaponDesc and CardDesc = LoreText checked headless, passing. ShowCardFlavor(Card, Desc): StatUpgrade sets Desc to Card.LoreText, Visible when non-empty. CardFlavorText is now unused. CloseCards, ChooseCard, RerollCards, UnbindCards unchanged. Strays left by DSL rewrites were deleted by orphan detection.
- selection input: mouse clicks on the buttons only (as before, no key binding); the click calls the miner's URRLevelUpComponent directly instead of URRHUDWidget::ChooseUpgrade / RequestReroll, which still exist in C++.
- tick: none, no timer.
- logic_in_bp: display only.
- assets: /Game/RogueRigs/UI/Icons/T_Icon_Stat_* (12) and /Game/RogueRigs/UI/Cards/T_CardFrame_Stat_Baked, _Accents_Baked, _Glow_Baked, T_CardFrame_Weapon_Baked (UI group, no mips, used by the frames); the old 9-slice textures T_CardFrame_Stat, _Accents, _Glow, T_CardFrame_Weapon are left in place, unused.
