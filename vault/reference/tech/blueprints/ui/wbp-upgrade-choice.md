# WBP_UpgradeChoice

- asset_path: /Game/RogueRigs/UI/WBP_UpgradeChoice
- parent_class: URRHUDPanelWidget (/Script/RogueRigs.RRHUDPanelWidget, [[sys-hud-events]])
- purpose: shows the three upgrade cards and the reroll button; a sub-widget of [[wbp-hud]], which only places it (variable UpgradeChoice, last child of Root, anchors 0,0 to 1,1, zero offsets, z-order 10, Visibility SelfHitTestInvisible: the instance itself takes no clicks, its Backdrop and buttons do, as UpgradeScreen did).
- components: CanvasPanel Root > UpgradeScreen (CanvasPanel, full screen, Collapsed until an offer) = Backdrop (Border, black alpha 0.7) + Panel (VerticalBox, centred, auto size): TitleText "Choose an upgrade" (36), CardsRow (HorizontalBox) of three SizeBox CardSize0..2 (512 x 732, row padding 14 left and right, 40 px gap; Border 6 + Button padding 6: card stack 500 x 720, task-177-02) > CardBorder<i> (Border, padding 6; tier colour for a new-weapon card, alpha 0 for a stat card) > CardButton<i> (all states NoDrawType) > CardStack<i> (Overlay): CardPanel<i> (Image, RoundedBox brush #15171c, slot Fill with padding 14 24 14 25 = about half the opening inset, so it fills only the frame opening and its edges hide under the frame), FrameGroup<i> (Overlay of FrameBase / FrameAccents / FrameGlow, task-168-09: plain Image brushes (Draw As Image, margins 0) of the baked textures T_CardFrame_Stat_Baked, _Accents_Baked (1000 x 1440 since task-177-02), _Glow_Baked (1000 x 1440 since task-178-02), ImageSize 500 x 720, all frame image slots Fill, base untinted, Accents and Glow tinted by tier), CardBox<i> (VerticalBox, padding 38 58 38 60 = opening inset 28 48 28 50 + 10) = ImageArea<i> (SizeBox 408 x 320) > ImageBg<i> (Border #1c1f26, radius 4) > ImageRow<i> (HorizontalBox) of WeaponBox<i> (SizeBox 190 x 80 > ScaleBox > WeaponIcon<i>, right padding 14) and StatIconBox<i> (SizeBox, no override since task-176-01, sized by the StatIcon desired size set in StyleCard > StatIcon<i>); EffectScale<i> (ScaleBox, DownOnly, top 18) > EffectRow<i> = CardValue<i> (Roboto Bold 30, tier colour) + CardName<i> (Bold 30 white); CardTarget<i> (Bold 20 #C9CCD4, top 8); CardDesc<i> (lore, Italic 16 #8B909D, wrapped, slot Fill with bottom alignment so it is always at the bottom of the box). New-weapon variant (task-169-04): WeaponGroup<i> (Overlay in CardStack<i>, slot Fill, between FrameGroup and CardBox, Collapsed unless NewWeapon) = FrameWeapon<i> (Image, Image brush of T_CardFrame_Weapon_Baked untinted, 1000 x 1440 texture, ImageSize 500 x 720, slot Fill) + WeaponHeader<i> (Roboto Bold 24 white, top, padding top 5, on the header plate about 37 px tall) + WeaponBody<i> (VerticalBox, padding 38 56 38 44 = opening insets 28 sides, bottom bar 33.5, plus 10): WeaponImgBox<i> (SizeBox 408 x 290) > WeaponImgScale<i> (ScaleToFit) > WeaponImg<i>, WeaponName<i> (Bold 30 white), WeaponDesc<i> (Roboto 17 #C9CCD4, wrapped). EffectScale<i> is now a variable. Then RerollButton (HAlign centre) > RerollText "Reroll" (24). Variables: UpgradeScreen, CardSize/Border/Button/Name/Target/Value/Desc, FrameGroup, FrameAccents, FrameGlow, ImageArea, WeaponBox, WeaponIcon, StatIcon, EffectRow, RerollButton, RerollText. No widget of the old tree was removed.
- events: hook BindToMiner(Miner, PreviousMiner): UnbindCards(Previous); valid miner: assigns the level-up component's OnUpgradeOfferShown and OnUpgradeOfferClosed to custom events (editor names OnUpgradeOfferShown_Event_0, OnUpgradeOfferClosed_Event_0) and, when IsAwaitingChoice, calls ShowCards(GetOfferCards, CanReroll) (bind-time read); otherwise CloseCards. Null miner: CloseCards. Offer shown calls ShowCards; closed calls CloseCards. Construct assigns the OnClicked of CardButton0..2 and RerollButton to custom events (OnClicked_Event_7 .. _10) that call ChooseCard(0..2) and RerollCards, and the OnHovered / OnUnhovered of CardButton0..2 to custom events (OnHovered_Event, _0, _1 and OnUnhovered_Event, _0, _1) that call SetRenderOpacity on FrameGlow0..2 with 1.0 / 0.6 (task-178-02; no tick, no timer; instant change). Destruct calls UnbindCards(GetMiner).
- functions: ShowCards(Cards, bCanReroll): UpgradeScreen Visible, RerollButton enabled, then per index 0..2 SetCard + StyleCard when the card exists else CardSize Collapsed. SetCard(Card, Size, Border, Name, Target, Value, Accents, Glow): texts from DisplayName / TargetText / ValueText; per Tier (grey 0.55, green 0.2/0.8/0.25, blue 0.2/0.45/1, purple 0.65/0.25/0.9, yellow 1/0.85/0.1) sets Border colour, Accents and Glow tint and the Value text colour. StyleCard(Card, Border, Desc, Value, FrameGroup, ImageArea, WeaponBox, WeaponIcon, StatIcon): StatUpgrade = Border alpha 0, FrameGroup and ImageArea visible, Value visible, ShowCardFlavor, StatIcon = GetStatIcon(Stat), then SetDesiredSizeOverride StatIcon 156 x 156 (task-176-01); by Target: Player and AllWeapons collapse WeaponBox (icon stays 156 x 156), Weapon shows it, resets the StatIcon override to 100 x 100 with GetWeaponIconByName(TargetText), sets the icon brush resource, then SetDesiredSizeOverride to the texture's real size (guarded by IsValid) so the ScaleBox (ScaleToFit) keeps the icon aspect inside 168 x 64. NewWeapon = Border alpha 0 (no teal border any more), FrameGroup, ImageArea, EffectScale, CardTarget and CardValue Collapsed, WeaponGroup SelfHitTestInvisible, WeaponHeader = DisplayName, WeaponName = TargetText, WeaponDesc = DescriptionText, WeaponImg = GetWeaponIconByName(TargetText) with the same desired-size override, CardDesc = LoreText (Visible only when non-empty; bottom-anchored). StyleCard now also takes WeaponGroup, WeaponHeader, WeaponDesc, WeaponImg, EffectScale, Target, WeaponTitle (the StatUpgrade branch collapses WeaponGroup and shows EffectScale and Target). ShowCards passes them by name. Meaning change: on a weapon card CardDesc<i> now holds the lore, not DescriptionText, and CardTarget<i> keeps TargetText but is Collapsed; the integration test RRWeaponsIntegrationTests (Integration.WeaponCardEquipsShotgun) was updated in task-169-05: WeaponHeader, WeaponName, WeaponDesc and CardDesc = LoreText checked headless, passing. ShowCardFlavor(Card, Desc): StatUpgrade sets Desc to Card.LoreText, Visible when non-empty. CardFlavorText is now unused. CloseCards, ChooseCard, RerollCards, UnbindCards unchanged. Strays left by DSL rewrites were deleted by orphan detection.
- deal and flip (task-243-05, timing values provisional, owner 2026-10-19): per card an Image CardBack<i> (variable, last child of CardStack<i> so it covers the face, slot Fill, brush ImageSize 500 x 720 Image margins 0, Visibility HitTestInvisible, default texture T_CardBack_Grey). Variables AnimStart (float, GetRealTimeSeconds at the deal start) and RerollAllowed (bool). Functions: SetBack(Card, Back): switch on Card.Tier (Grey, Green, Blue, Purple, Yellow) sets the back texture with SetBrushResourceObject (new-weapon cards use their Tier back too). StartDeal(bCanReroll): clears the AnimStep timer, stores AnimStart and RerollAllowed, disables CardButton0..2 and RerollButton, calls AnimStep once (cards start face down at once), then sets the looping timer AnimStep 0.016 s. AnimStep: elapsed = now - AnimStart; CardAnim(elapsed, k, CardSize<k>, CardBack<k>) for k 0, 1, 2; at elapsed >= 0.8 clears its timer and enables the three card buttons and RerollButton (= RerollAllowed). CardAnim(E, K, Target, Back), pure display maths on the render transform of CardSize<k> (pivot 0.5, 0.5): arrival ta = clamp((E - 0.15 K) / 0.25, 0, 1), ease-out-back with c1 1.70158 and c3 2.70158 (ease = 1 + c3 (ta-1)^3 + c1 (ta-1)^2), rem = 1 - ease; translation Y = 820 * rem, angle = (K - 1) * 6 * rem (so -6, 0, +6 degrees fanned, upright at rest); flip tf = clamp((E - 0.3 - 0.15 K) / 0.2, 0, 1), scale X = |cos(tf * pi)|, scale Y 1; CardBack Visible (HitTestInvisible) while tf < 0.5, Collapsed after (face revealed at the midpoint). Sequence: arrivals start 0 / 0.15 / 0.30 s and last 0.25 s; flips start 0.30 / 0.45 / 0.60 s and last 0.2 s (flips overlap by 0.05 s); everything ends at 0.8 s. ShowCards: after the Reroll SetIsEnabled it calls StartDeal(bCanReroll); in each existing-card branch, after StyleCard, it calls SetBack(card, CardBack<i>) (edited by pin splicing, the other nodes are untouched). CloseCards first clears the AnimStep timer, so closing mid-sequence cancels it. ShowCards runs on every offer shown, the bind-time read and the reroll (the reroll re-fires OnUpgradeOfferShown), so each replays the sequence. Hover glow, ChooseCard, RerollCards, UnbindCards untouched. Suspense reordering is not done (task-244).
- selection input: mouse clicks on the buttons only (as before, no key binding); the click calls the miner's URRLevelUpComponent directly instead of URRHUDWidget::ChooseUpgrade / RequestReroll, which still exist in C++.
- tick: none. One looping timer AnimStep (0.016 s) runs only during the deal sequence (task-243-05); it clears itself at 0.8 s and in CloseCards. MCP has no tool for widget animation tracks (UMGToolSet has none), hence the timer, as in [[wbp-weapons]] ProgressStep.
