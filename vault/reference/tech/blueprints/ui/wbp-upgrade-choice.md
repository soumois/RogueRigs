# WBP_UpgradeChoice

- asset_path: /Game/RogueRigs/UI/WBP_UpgradeChoice
- parent_class: URRHUDPanelWidget (/Script/RogueRigs.RRHUDPanelWidget, [[sys-hud-events]])
- purpose: shows the three upgrade cards and the reroll button; a sub-widget of [[wbp-hud]], which only places it (variable UpgradeChoice, last child of Root, anchors 0,0 to 1,1, zero offsets, z-order 10, Visibility SelfHitTestInvisible: the instance itself takes no clicks, its Backdrop and buttons do, as UpgradeScreen did).
- components: CanvasPanel Root > UpgradeScreen (CanvasPanel, full screen, Collapsed until an offer) = Backdrop (Border, black alpha 0.7) + Panel (VerticalBox, centred, auto size): TitleText "Choose an upgrade" (36), CardsRow (HorizontalBox) of three SizeBox CardSize0..2 (452 x 732, row padding 14 left and right; Border 6 + Button padding 6: card stack 440 x 720) > CardBorder<i> (Border, padding 6; tier colour for a new-weapon card, alpha 0 for a stat card) > CardButton<i> (all states NoDrawType) > CardStack<i> (Overlay): CardPanel<i> (Image, RoundedBox brush #15171c, slot Fill: it is the dark panel behind everything, an Image brush with no texture draws nothing), FrameGroup<i> (Overlay of FrameBase / FrameAccents / FrameGlow, Box brushes of T_CardFrame_Stat, _Accents, _Glow, margins 0.2081 / 0.11948 / 0.21179 / 0.12776, ImageSize 271.5 x 362 = texture 1086 x 1448 x 0.25, all frame image slots Fill, base untinted, Accents and Glow tinted by tier), CardBox<i> (VerticalBox, padding 45 49 46 51 = opening inset x 0.25 + 10) = ImageArea<i> (SizeBox 348 x 320) > ImageBg<i> (Border #1c1f26, radius 4) > ImageRow<i> (HorizontalBox) of WeaponBox<i> (SizeBox 190 x 80 > ScaleBox > WeaponIcon<i>, right padding 14) and StatIconBox<i> (125 x 125 > StatIcon<i>); EffectScale<i> (ScaleBox, DownOnly, top 18) > EffectRow<i> = CardValue<i> (Roboto Bold 30, tier colour) + CardName<i> (Bold 30 white); CardTarget<i> (Bold 20 #C9CCD4, top 8); CardDesc<i> (lore, Italic 16 #8B909D, wrapped, slot Fill with bottom alignment so it is always at the bottom of the box). New-weapon variant (task-169-04): WeaponGroup<i> (Overlay in CardStack<i>, slot Fill, between FrameGroup and CardBox, Collapsed unless NewWeapon) = FrameWeapon<i> (Image, Box brush of T_CardFrame_Weapon untinted, ImageSize 271.5 x 362, slot Fill, margins 140/1086, 180/1448, 140/1086, 190/1448) + WeaponHeader<i> (Roboto Bold 24 white, top, padding top 8, on the header plate) + WeaponBody<i> (VerticalBox, padding 45 56 46 115): WeaponImgBox<i> (SizeBox 348 x 290) > WeaponImgScale<i> (ScaleToFit) > WeaponImg<i>, WeaponName<i> (Bold 30 white), WeaponDesc<i> (Roboto 17 #C9CCD4, wrapped). EffectScale<i> is now a variable. Then RerollButton (HAlign centre) > RerollText "Reroll" (24). Variables: UpgradeScreen, CardSize/Border/Button/Name/Target/Value/Desc, FrameGroup, FrameAccents, FrameGlow, ImageArea, WeaponBox, WeaponIcon, StatIcon, EffectRow, RerollButton, RerollText. No widget of the old tree was removed.
- events: hook BindToMiner(Miner, PreviousMiner): UnbindCards(Previous); valid miner: assigns the level-up component's OnUpgradeOfferShown and OnUpgradeOfferClosed to custom events (editor names OnUpgradeOfferShown_Event_0, OnUpgradeOfferClosed_Event_0) and, when IsAwaitingChoice, calls ShowCards(GetOfferCards, CanReroll) (bind-time read); otherwise CloseCards. Null miner: CloseCards. Offer shown calls ShowCards; closed calls CloseCards. Construct assigns the OnClicked of CardButton0..2 and RerollButton to custom events (OnClicked_Event .. _2) that call ChooseCard(0..2) and RerollCards (the old component-bound OnClicked events could not be written through the DSL). Destruct calls UnbindCards(GetMiner).
- functions: ShowCards(Cards, bCanReroll): UpgradeScreen Visible, RerollButton enabled, then per index 0..2 SetCard + StyleCard when the card exists else CardSize Collapsed. SetCard(Card, Size, Border, Name, Target, Value, Accents, Glow): texts from DisplayName / TargetText / ValueText; per Tier (grey 0.55, green 0.2/0.8/0.25, blue 0.2/0.45/1, purple 0.65/0.25/0.9, yellow 1/0.85/0.1) sets Border colour, Accents and Glow tint and the Value text colour. StyleCard(Card, Border, Desc, Value, FrameGroup, ImageArea, WeaponBox, WeaponIcon, StatIcon): StatUpgrade = Border alpha 0, FrameGroup and ImageArea visible, Value visible, ShowCardFlavor, StatIcon = GetStatIcon(Stat); by Target: Player and AllWeapons collapse WeaponBox, Weapon shows it with GetWeaponIconByName(TargetText), sets the icon brush resource, then SetDesiredSizeOverride to the texture's real size (guarded by IsValid) so the ScaleBox (ScaleToFit) keeps the icon aspect inside 168 x 64. NewWeapon = Border alpha 0 (no teal border any more), FrameGroup, ImageArea, EffectScale, CardTarget and CardValue Collapsed, WeaponGroup SelfHitTestInvisible, WeaponHeader = DisplayName, WeaponName = TargetText, WeaponDesc = DescriptionText, WeaponImg = GetWeaponIconByName(TargetText) with the same desired-size override, CardDesc = LoreText (Visible only when non-empty; bottom-anchored). StyleCard now also takes WeaponGroup, WeaponHeader, WeaponDesc, WeaponImg, EffectScale, Target, WeaponTitle (the StatUpgrade branch collapses WeaponGroup and shows EffectScale and Target). ShowCards passes them by name. Meaning change: on a weapon card CardDesc<i> now holds the lore, not DescriptionText, and CardTarget<i> keeps TargetText but is Collapsed; the integration test RRWeaponsIntegrationTests (Integration.WeaponCardEquipsShotgun) was updated in task-169-05: WeaponHeader, WeaponName, WeaponDesc and CardDesc = LoreText checked headless, passing. ShowCardFlavor(Card, Desc): StatUpgrade sets Desc to Card.LoreText, Visible when non-empty. CardFlavorText is now unused. CloseCards, ChooseCard, RerollCards, UnbindCards unchanged. Strays left by DSL rewrites were deleted by orphan detection.
- selection input: mouse clicks on the buttons only (as before, no key binding); the click calls the miner's URRLevelUpComponent directly instead of URRHUDWidget::ChooseUpgrade / RequestReroll, which still exist in C++.
- tick: none, no timer.
- logic_in_bp: display only.
- assets: /Game/RogueRigs/UI/Icons/T_Icon_Stat_* (12) and /Game/RogueRigs/UI/Cards/T_CardFrame_Stat, _Accents, _Glow, T_CardFrame_Weapon (UI group, no mips).
- owner_agent: agent-bp
- layout fix (task-168-06): frames were left/top aligned in their overlay slots at the old ImageSize, and CardPanel had no visible brush (hence the transparent centre, the oversized bands and the small square at the top left, by cause analysis); now all slots Fill.
