# WBP_UpgradeChoice

- asset_path: /Game/RogueRigs/UI/WBP_UpgradeChoice
- parent_class: URRHUDPanelWidget (/Script/RogueRigs.RRHUDPanelWidget, [[sys-hud-events]])
- purpose: shows the three upgrade cards and the reroll button; a sub-widget of [[wbp-hud]], which only places it (variable UpgradeChoice, last child of Root, anchors 0,0 to 1,1, zero offsets, z-order 10, Visibility SelfHitTestInvisible: the instance itself takes no clicks, its Backdrop and buttons do, as UpgradeScreen did).
- components: CanvasPanel Root > UpgradeScreen (CanvasPanel, full screen, Collapsed until an offer) = Backdrop (Border, black alpha 0.7) + Panel (VerticalBox, centred, auto size): TitleText "Choose an upgrade" (36), CardsRow (HorizontalBox) of three SizeBox CardSize0..2 (392 x 572, row padding 14 left and right: visible cards 380 x 560 with a 40 px gap) > CardBorder<i> (Border, padding 6; tier colour for a new-weapon card, alpha 0 for a stat card) > CardButton<i> (all states NoDrawType) > CardStack<i> (Overlay): CardPanel<i> (Image #15171c), FrameGroup<i> (Overlay of FrameBase / FrameAccents / FrameGlow, Box brushes of T_CardFrame_Stat, _Accents, _Glow, margins 0.2081 / 0.11948 / 0.21179 / 0.12776, ImageSize 380.1 x 506.8, base untinted, Accents and Glow tinted by tier), CardBox<i> (VerticalBox, padding 36 36 36 38) = ImageArea<i> (SizeBox 308 x 252) > ImageBg<i> (Border #1c1f26, radius 4) > ImageRow<i> (HorizontalBox) of WeaponBox<i> (SizeBox 168 x 64 > ScaleBox > WeaponIcon<i>, right padding 14) and StatIconBox<i> (100 x 100 > StatIcon<i>); EffectScale<i> (ScaleBox, DownOnly, top 18) > EffectRow<i> = CardValue<i> (Roboto Bold 30, tier colour) + CardName<i> (Bold 30 white); CardTarget<i> (Bold 20 #C9CCD4, top 8); CardDesc<i> (lore, Italic 16 #8B909D, wrapped, slot Fill with bottom alignment so it is always at the bottom of the box). Then RerollButton (HAlign centre) > RerollText "Reroll" (24). Variables: UpgradeScreen, CardSize/Border/Button/Name/Target/Value/Desc, FrameGroup, FrameAccents, FrameGlow, ImageArea, WeaponBox, WeaponIcon, StatIcon, EffectRow, RerollButton, RerollText. No widget of the old tree was removed.
- events: hook BindToMiner(Miner, PreviousMiner): UnbindCards(Previous); valid miner: assigns the level-up component's OnUpgradeOfferShown and OnUpgradeOfferClosed to custom events (editor names OnUpgradeOfferShown_Event_0, OnUpgradeOfferClosed_Event_0) and, when IsAwaitingChoice, calls ShowCards(GetOfferCards, CanReroll) (bind-time read); otherwise CloseCards. Null miner: CloseCards. Offer shown calls ShowCards; closed calls CloseCards. Construct assigns the OnClicked of CardButton0..2 and RerollButton to custom events (OnClicked_Event .. _2) that call ChooseCard(0..2) and RerollCards (the old component-bound OnClicked events could not be written through the DSL). Destruct calls UnbindCards(GetMiner).
- functions: ShowCards(Cards, bCanReroll): UpgradeScreen Visible, RerollButton enabled, then per index 0..2 SetCard + StyleCard when the card exists else CardSize Collapsed. SetCard(Card, Size, Border, Name, Target, Value, Accents, Glow): texts from DisplayName / TargetText / ValueText; per Tier (grey 0.55, green 0.2/0.8/0.25, blue 0.2/0.45/1, purple 0.65/0.25/0.9, yellow 1/0.85/0.1) sets Border colour, Accents and Glow tint and the Value text colour. StyleCard(Card, Border, Desc, Value, FrameGroup, ImageArea, WeaponBox, WeaponIcon, StatIcon): StatUpgrade = Border alpha 0, FrameGroup and ImageArea visible, Value visible, ShowCardFlavor, StatIcon = GetStatIcon(Stat); by Target: Player and AllWeapons collapse WeaponBox, Weapon shows it with GetWeaponIconByName(TargetText). NewWeapon = teal border (0, 0.9, 0.85), FrameGroup and ImageArea Collapsed, Desc shows DescriptionText, Value Collapsed (old look kept, task-169-04 restyles). ShowCardFlavor(Card, Desc): StatUpgrade sets Desc to Card.LoreText, Visible when non-empty. CardFlavorText is now unused. CloseCards, ChooseCard, RerollCards, UnbindCards unchanged. Strays left by DSL rewrites were deleted by orphan detection.
- selection input: mouse clicks on the buttons only (as before, no key binding); the click calls the miner's URRLevelUpComponent directly instead of URRHUDWidget::ChooseUpgrade / RequestReroll, which still exist in C++.
- tick: none, no timer.
- logic_in_bp: display only.
- assets: /Game/RogueRigs/UI/Icons/T_Icon_Stat_* (12) and /Game/RogueRigs/UI/Cards/T_CardFrame_Stat, _Accents, _Glow, T_CardFrame_Weapon (UI group, no mips).
- owner_agent: agent-bp
- verified: compiled with warnings as errors, saved, tree and graph pin wiring read back (task-168-05). Not seen on screen or in PIE: nothing rendered was looked at. Unverified: that the Box brush margins (ImageSize 380.1 x 506.8) draw 79/61/80/65 px edges; weapon icon aspect (the Image fills a 168 x 64 box, the ScaleBox cannot know the texture aspect, so a texture not about 2.6:1 is stretched); hover feedback is lost (button states NoDrawType); long stat names scale down in EffectScale. Earlier breaks for task-094-10 (tests look widgets up in the HUD tree) still stand.
