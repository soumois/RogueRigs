# WBP_Weapons

- asset_path: /Game/RogueRigs/UI/WBP_Weapons
- parent_class: URRHUDPanelWidget (/Script/RogueRigs.RRHUDPanelWidget, [[sys-hud-events]])
- purpose: shows the weapon slots and the turret charges; a sub-widget of [[wbp-hud]], which only places it (variable Weapons, HitTestInvisible, anchors 0.5/1 to 0.5/1, alignment 0.5/1, auto size, offset left 0, top -54: the row is centred on the screen and its bottom edge is 54 px above the screen bottom; owner wish 2026-10-11).
- components: VerticalBox Root > TurretBox (VerticalBox, Collapsed until a turret launcher is owned, centred, above the row) = TurretText (Size 18, teal 0/0.85/1) + SizeBox 200 x 10 > TurretBar (teal); then SlotsRow (HorizontalBox, 4 cells of 150 x 90, gap 12 as left padding of cells 1..3, row 636 px wide) of SizeBox Col0..3 (150 x 90) > Frame<i> (Border, dark 0/0/0/0.45 rounded box, outline 2 px white-gold 1/0.9/0.5, content padding 4, centred top) > ColBox<i> (VerticalBox) = IconZone<i> (SizeBox 120 x 50: the reserved icon zone, contains WeaponSlot<i> TextBlock Roboto Bold 22, centred, wrapped, shows the weapon name or LOCKED; task 106-02 puts an icon here) + BarBox<i> (SizeBox 130 x 14, top padding 6) > Overlay > AmmoBar<i> (white-gold 1/0.9/0.5), ReloadBar<i> (red 1/0.1/0.1), BlockRow<i> (HorizontalBox) of 8 ProgressBars Blk<i>_0..7 (slot Fill, padding 1 left and right, so about 16 px per block). Overlay slots are Fill/Fill. The text, bars, rows, TurretBox, TurretText and TurretBar are variables; bars and rows start Collapsed. Outline colour is static (no per-state grey for LOCKED: that needs logic, left out by task 106-01).
- column width bug (task-106-01): every SizeBox had its value set (WidthOverride 160, BarBox 112 x 10) but the flags bOverride_WidthOverride and bOverride_HeightOverride were false, so the value was ignored and the columns collapsed to their text. Rule: set the bOverride_* flag together with the value through MCP set_properties.
- icons (task 106-02): each Frame<i> content is now CellOverlay<i> (Overlay, takes the old Border slot: padding 4, centred top) > ColBox<i> (as before) + LockImage<i> (Image 50 x 50, padlock texture T_Icon_padlock, Collapsed, centred in the overlay). IconZone<i> is now 134 x 62 (was 120 x 50) and holds ZoneBox<i> (VerticalBox) = IconImage<i> (Image, brush 42 x 42, Collapsed, texture set by logic) over WeaponSlot<i> (name, Roboto Bold 16, no wrap, centred; was 22). BarBox<i> top padding 4 (was 6). Height budget: inner cell 90 - 2 x 4 padding = 82; 62 + 4 + 14 = 80. IconImage<i>, LockImage<i> are variables. Textures /Game/RogueRigs/UI/Icons/T_Icon_padlock, _burst_rifle, _shotgun, _turret_launcher (UI group, no mips, sRGB, UserInterface2D); placeholders, see [[placeholder-weapon-icons]].
- icons, big icon (task 109-02): IconZone<i> is now 134 x 60. ZoneBox<i> = IconBox<i> (SizeBox, bOverride_MaxDesiredWidth/Height true, 130 x 56, slot padding top and bottom 2, centred) > IconScale<i> (ScaleBox, Stretch ScaleToFit, direction Both) > IconImage<i> (brush size comes from the texture through SetBrushfromTexture with bMatchSize), above WeaponSlot<i>. The icon textures keep their aspect ratio (rifle 256 x 105 about 130 x 53, shotgun 256 x 98, launcher 256 x 170 about 86 x 56). Max sizes (not fixed overrides) so a collapsed icon takes no room. Height budget: 60 + 4 (BarBox top padding) + 14 = 78 of 82. Locked slot unchanged (LockImage 50 x 50). Reimport quirk: TextureTools.import_file refuses an existing asset; the textures were deleted and reimported under the same path (LODGroup set back to UI), which nulled the GetWeaponIcon return pins, set again with set_pin_value.
- variables: TurretSlotPlusOne (int, slot index + 1 of the launcher shown in TurretBox, 0 = none).
- events: hook BindToMiner(Miner, PreviousMiner): UnbindWeapons(Previous); valid miner: assigns OnWeaponSlotChanged to OnWeaponSlotChanged_Event_0 and calls ShowSlot(i, GetWeaponSlotHUD(i)) for i 0..3 (bind-time read); null miner: ShowSlot with an empty struct (all LOCKED). OnWeaponSlotChanged_Event_0(SlotIndex, Slot) calls ShowSlot. It also covers ammo, reload and turret charge changes (the miner aggregates ARRWeapon::OnAmmoChanged, the reload events and OnTurretChargesChanged), so no other event is bound. Destruct calls UnbindWeapons(GetMiner).
- functions: ShowSlot(Index, Slot): starts the 0.016 s looping timer ProgressStep when the slot reloads or a launcher recharges; shows TurretBox with "Turrets: n / max" for an owned launcher (hides it when that slot stops being one); calls ShowSlotWidgets for the column of Index. ShowSlotWidgets(Slot, AmmoBar, ReloadBar, BlockRow, SlotText): not owned: LOCKED, all hidden; owned: name, reload bar while reloading (not launcher), AmmoBar when the magazine is above 7, else the block row (count = MaxCharges for a launcher or MagazineSize, filled = Charges or Rounds, the block at index Charges red at RechargeProgress while recharging). ProgressSlot(Slot, ReloadBar, BlockRow) returns bRunning: sets the reload bar percent while reloading and the recharging block and TurretBar percent while a launcher recharges. ProgressStep: calls ProgressSlot for the four slots (GetWeaponSlotHUD) and clears its own timer when none runs. UnbindWeapons(M): clears the timer, unbinds all OnWeaponSlotChanged listeners of a valid miner (named to avoid resolving to other widget functions).
- icon functions: GetWeaponIcon(WeaponName: Text) returns Texture2D: the single mapping place (if chain on the name string: "Burst rifle", "Shotgun", "Turret launcher" -> T_Icon_*; anything else returns null). ShowSlotIcon(Index, Slot) switches on Index and calls ShowSlotIconWidgets(Slot, IconImage, LockImage, SlotText): owned: padlock hidden; icon valid: icon set with SetBrushfromTexture (match size) and shown, name collapsed; icon not valid: icon hidden, name shown (fallback); not owned: padlock shown, icon and name hidden. ShowSlot calls ShowSlotIcon just before its switch on ShowSlotWidgets (ShowSlotWidgets itself is unchanged; its LOCKED text is hidden by ShowSlotIconWidgets).
