# WBP_AlertObjectives

- asset_path: /Game/RogueRigs/UI/WBP_AlertObjectives
- parent_class: URRHUDPanelWidget (/Script/RogueRigs.RRHUDPanelWidget, [[sys-hud-events]])
- purpose: shows the alert bar, the event icons, the HORDE INCOMING banner, the objective and hack texts, the shuttle countdown and the end screen; a sub-widget of [[wbp-hud]], which only places it (variable AlertObjectives, last child of Root, anchors 0,0 to 1,1, zero offsets, z-order 20, Visibility SelfHitTestInvisible: not HitTestInvisible, so the Play again button stays clickable).
- components: CanvasPanel Root > AlertBar (ProgressBar orange fill 1/0.35/0.1, background tint 0.012/0.016/0.018 = dark track (task-453), 600 x 36 at -300,48, top-centre anchor; no ALERT text next to it and no pause indicator, owner decision 2026-10-15, task-185-01), AlertFrame (Image T_HUD_AlertFrame, riveted gauge frame with a transparent window over the bar, HitTestInvisible, variable, task-453), ObjectiveText (22, -400,140, 800 x 27, Collapsed), HackBar (teal, -150,174, 300 x 14, Collapsed), ShuttleText (30, teal, -300,196, 600 x 40, Collapsed), EndScreen (full screen, z 20 inside, Collapsed) = EndBackdrop (Border black alpha 0.75) + EndPanel (VerticalBox centred) with EndTitle (64), EndSubtitle (TextBlock, variable, Roboto Regular 28, outline 2, centred, Collapsed; task-209-04), EndOreRow (HorizontalBox, variable, centred, padding top 16 bottom 24, task-183-04) with EndOreIcon (Image 64 x 64, T_Icon_Ore, variable) and EndOreText (Roboto Bold 40 white, outline 2, variable, "Duskite secured: N"; designer default "Duskite secured: 0" (task-396-02, was "Ore secured: 0"; graph untouched), overwritten at runtime on success, row Collapsed otherwise), and RestartButton > RestartText ("Play again", or "Main Menu" after a won run, task-390-02); HordeBanner (64 bold red, outline 3, centred 220 above the centre, z 5, Collapsed); icons AlertIconConsole "C" (cyan 0/0.85/1), AlertIconShuttle "S" (white), AlertIconChest "B" (yellow 1/0.78/0.1): TextBlocks Roboto Bold 28 outline 3; AlertIconHorde0..3: Images T_HUD_AlertMark (red "!" in a dark capsule tab, 29 x 60; TextBlocks "!" before task-453); letters z 4 in front of the marks z 3 (task-460), all Collapsed, set on the track itself (layout below). all but EndBackdrop and EndPanel are variables. Variables bHackDone, LastShuttleSeconds (-1 at Construct), bReturnToMenu (bool, task-390-02).
- layout (task-453, look of [[art-prompts-hud-unified-mockup]]; all anchors min = max 0.5,0, top centre; slate units):

  Each letter is centred on the bar left end and track centre line (y 66); each horde mark on the bar left end and the bar top (y 48, task-460: it spans y 18..78 and rises above the frame top 21). PlaceAlertIcon moves each icon by RenderTranslation X = Position x 600.
- exposed_defaults: none.
- events: hook BindToRunFlow(RunFlow, PreviousRunFlow): valid run flow: assigns OnAlertChanged, OnObjectiveChanged, OnObjectiveProgressChanged, OnExtractionReady, OnShuttleCountdown, OnRunEnded, OnAlertBarEventsChanged and OnHordeIncoming to custom events (editor names OnAlertChanged_Event, OnObjectiveChanged_Event, OnObjectiveProgressChanged_Event, OnExtractionReady_Event, OnShuttleCountdown_Event, OnRunEnded_Event, OnAlertBarEventsChanged_Event_0, OnHordeIncoming_Event) and reads the current values (ShowAlertBar(GetAlert, HasPendingObjective), ShowConsoleNow(GetConsole), ShowReachShuttle when IsExtractionReady, ShowShuttleNow(GetShuttle), ShowRunEnd when IsRunEnded, ShowAlertIcons(GetAlertBarEvents)); then, if PreviousRunFlow is valid, unbinds all eight events from it. Construct sets LastShuttleSeconds -1 and assigns the OnClicked of RestartButton to a custom event (OnClicked_Event): GetRunFlow, Branch on bReturnToMenu: true calls RunFlow ReturnToMainMenu ([[sys-objectives-run-flow]]), false calls RunFlow RestartLevel as before. Destruct unbinds all eight events from GetRunFlow. The horde event shows the banner HitTestInvisible, Delay (SecondsUntil, 4 when <= 0), Collapsed (a second banner during the delay is ignored, as before). The unbind is "unbind all" (the run flow subsystem type cannot be a function parameter through MCP, so it is inline); the C++ URRHUDWidget listeners on the same delegates are removed with it at Destruct.
- offer hiding (task-168-07): hook BindToMiner(Miner, PreviousMiner): UnbindOffer(PreviousMiner) (unbind all OnUpgradeOfferShown / OnUpgradeOfferClosed of its level-up component, same pattern as WBP_UpgradeChoice), RestoreAfterOffer, then for a valid miner assigns the two level-up events to custom events OnUpgradeOfferShown_Event_2 / OnUpgradeOfferClosed_Event_2 and, when IsAwaitingChoice, calls HideForOffer. Shown calls HideForOffer (bool variable bOfferShown = true; AlertBar, AlertFrame and all seven alert icons Collapsed); closed calls RestoreAfterOffer (bOfferShown = false; AlertBar Visible, its only designed state; AlertFrame HitTestInvisible; icons recomputed by ShowAlertIcons(GetAlertBarEvents)). The OnAlertBarEventsChanged handler skips ShowAlertIcons while bOfferShown so icons do not reappear over the cards. HordeBanner, ObjectiveText, HackBar and ShuttleText are not hidden: they sit lower (ObjectiveText at y 140, ShuttleText y 196, banner 220 above centre) and may overlap the top of the cards; not checked on screen. Restore is to the fixed Visible value, not a saved per-widget value (a Blueprint variable of ESlateVisibility cannot be created through MCP). The unbind-all also removes WBP_UpgradeChoice's bindings on the previous miner only (acceptable: it unbinds the same miner). The 33 unconnected custom events left by failed DSL rewrites were deleted in task-175-01 (EventGraph checked for every pin; wired nodes and the _Event_2 handlers kept; compiled with warnings as errors, saved).
- loss path (task-484-05, commit 2b2bb7f4): ShowRunEnd starts with a Branch on bSuccess: a loss (shuttle missed) returns at once, so EndScreen, "RUN LOST" and Play again never show; the run-lost screen [[wbp-run-lost]] owns every loss. The "RUN LOST" literal and the Play again branch stay in the graph, unreachable on a loss.
