# WBP_AlertObjectives

- asset_path: /Game/RogueRigs/UI/WBP_AlertObjectives
- parent_class: URRHUDPanelWidget (/Script/RogueRigs.RRHUDPanelWidget, [[sys-hud-events]])
- purpose: shows the alert bar, the event icons, the HORDE INCOMING banner, the objective and hack texts, the shuttle countdown and the end screen; a sub-widget of [[wbp-hud]], which only places it (variable AlertObjectives, last child of Root, anchors 0,0 to 1,1, zero offsets, z-order 20, Visibility SelfHitTestInvisible: not HitTestInvisible, so the Play again button stays clickable).
- components: CanvasPanel Root > AlertBar (ProgressBar orange 1/0.35/0.1, 600 x 36 at -300,48, top-centre anchor), AlertLabel (36, right aligned, -310,44), ObjectiveText (22, -400,140, 800 x 27, Collapsed), HackBar (teal, -150,174, 300 x 14, Collapsed), ShuttleText (30, teal, -300,196, 600 x 40, Collapsed), EndScreen (full screen, z 20 inside, Collapsed) = EndBackdrop (Border black alpha 0.75) + EndPanel (VerticalBox centred) with EndTitle (64) and RestartButton > RestartText "Play again"; HordeBanner (64 bold red, outline 3, centred 220 above the centre, z 5, Collapsed); icons AlertIconConsole "C", AlertIconShuttle "S", AlertIconChest "B" (left -316, top 82), AlertIconHorde0..3 "!" (left -316, top 0), font 44 outline 4, z 3, Collapsed. Same values as in WBP_HUD (task-094-07); all but EndBackdrop and EndPanel are variables. Variables bHackDone, LastShuttleSeconds (-1 at Construct).
- exposed_defaults: none.
- events: hook BindToRunFlow(RunFlow, PreviousRunFlow): valid run flow: assigns OnAlertChanged, OnObjectiveChanged, OnObjectiveProgressChanged, OnExtractionReady, OnShuttleCountdown, OnRunEnded, OnAlertBarEventsChanged and OnHordeIncoming to custom events (editor names OnAlertChanged_Event, OnObjectiveChanged_Event, OnObjectiveProgressChanged_Event, OnExtractionReady_Event, OnShuttleCountdown_Event, OnRunEnded_Event, OnAlertBarEventsChanged_Event_0, OnHordeIncoming_Event) and reads the current values (ShowAlertBar(GetAlert, HasPendingObjective), ShowConsoleNow(GetConsole), ShowReachShuttle when IsExtractionReady, ShowShuttleNow(GetShuttle), ShowRunEnd when IsRunEnded, ShowAlertIcons(GetAlertBarEvents)); then, if PreviousRunFlow is valid, unbinds all eight events from it. Construct sets LastShuttleSeconds -1 and assigns the OnClicked of RestartButton to a custom event (OnClicked_Event) that calls RunFlow RestartLevel. Destruct unbinds all eight events from GetRunFlow. The horde event shows the banner HitTestInvisible, Delay (SecondsUntil, 4 when <= 0), Collapsed (a second banner during the delay is ignored, as before). The unbind is "unbind all" (the run flow subsystem type cannot be a function parameter through MCP, so it is inline); the C++ URRHUDWidget listeners on the same delegates are removed with it at Destruct.
- offer hiding (task-168-07): hook BindToMiner(Miner, PreviousMiner): UnbindOffer(PreviousMiner) (unbind all OnUpgradeOfferShown / OnUpgradeOfferClosed of its level-up component, same pattern as WBP_UpgradeChoice), RestoreAfterOffer, then for a valid miner assigns the two level-up events to custom events OnUpgradeOfferShown_Event_2 / OnUpgradeOfferClosed_Event_2 and, when IsAwaitingChoice, calls HideForOffer. Shown calls HideForOffer (bool variable bOfferShown = true; AlertBar, AlertLabel and all seven alert icons Collapsed); closed calls RestoreAfterOffer (bOfferShown = false; AlertBar and AlertLabel Visible, which is their only designed state; icons recomputed by ShowAlertIcons(GetAlertBarEvents)). The OnAlertBarEventsChanged handler skips ShowAlertIcons while bOfferShown so icons do not reappear over the cards. HordeBanner, ObjectiveText, HackBar and ShuttleText are not hidden: they sit lower (ObjectiveText at y 140, ShuttleText y 196, banner 220 above centre) and may overlap the top of the cards; not checked on screen. Restore is to the fixed Visible value, not a saved per-widget value (a Blueprint variable of ESlateVisibility cannot be created through MCP). The unbind-all also removes WBP_UpgradeChoice's bindings on the previous miner only (acceptable: it unbinds the same miner). The 33 unconnected custom events left by failed DSL rewrites were deleted in task-175-01 (EventGraph checked for every pin; wired nodes and the _Event_2 handlers kept; compiled with warnings as errors, saved).
- functions: ShowAlertBar(Alert, bPaused): percent and "ALERT" / "ALERT (paused)". ShowObjectiveState(bActive, RocksLeft, RocksTotal): hidden when inactive or bHackDone, else "Clear the marked rocks (cleared/total)" while rocks remain, then "Hack the console: stay close to it" with HackBar. ShowObjectiveFor(Console, Left, Total): bActive = Console valid. ShowConsoleNow(Console): bind-time read (objective, then hack progress). ShowHackProgress(Progress): percent; at 1 sets bHackDone and hides both. ShowReachShuttle: "Reach the shuttle". ShowShuttleSeconds(Remaining): sets the text "Shuttle: n s" only when the rounded seconds change (the event fires every frame). ShowShuttleNow(Shuttle). ShowRunEnd(bSuccess): EndScreen Visible, "EXTRACTION SUCCESSFUL" or "RUN LOST", ShuttleText Collapsed. CollapseAlertIcons; PlaceAlertIcon(Icon, Position, bDone): HitTestInvisible, RenderTranslation X = Position x 600, opacity 0.35 when done; ShowAlertIcons(Events): collapse all, then per event a switch on Type (horde by Index 0..3). The old WBP_HUD function PlaceIcon became PlaceAlertIcon.
- tick: none, no timer. The icon list is recomputed by the C++ run flow only on change.
- logic_in_bp: display only.
