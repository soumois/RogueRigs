- variables: HitFlash, LowHealthAlpha, HitHoldRemaining, LastFadeTime (float); HitHoldTime (float, 0.15, instance editable).
- events: hook BindToMiner(Miner, PreviousMiner): UnbindMiner(Previous) (unbinds all OnHealthChanged / OnDamaged listeners of a valid previous miner), then for a valid miner assigns OnHealthChanged and OnDamaged and calls ShowHealth(GetCurrentHealth, GetMaxHealth) (the C++ native bind, run just before the hook, already drives bar and text). Hook BindToGameMode(GameMode, PreviousGameMode): UnbindGameMode(Previous), assigns OnGameOver. Handlers (editor names with the "_1" / "_2" suffix from MCP authoring): OnHealthChanged_Event_1(Current, Max) calls ShowHealth; OnDamaged_Event_2(Amount, HealthFraction) sets HitFlash = 0.4 + 0.4 * (1 - HealthFraction), HitHoldRemaining = HitHoldTime, ApplyVignette, StartFade; OnGameOver_Event_1 shows GameOverText. Destruct unbinds miner and game mode and clears the fade timer.
- functions: ShowHealth(Current, Max): only LowHealthAlpha = 0.4 - percent when percent < 0.4 else 0 (percent = Current / max(Max, 1) when Max > 0 else 0), then ApplyVignette; the HealthBar percent and HealthText writes were removed (task-203-07), the C++ class owns them. ApplyVignette: vignette RenderOpacity = clamp(HitFlash + LowHealthAlpha, 0.001, 0.9) (the 0.001 floor replaces the C++ KeepVignetteWarm, which only finds widgets of the HUD tree). StartFade: starts the looping timer FadeStep (0.016 s, once per frame); LastFadeTime is no longer used. FadeStep: dt = GetWorldDeltaSeconds (task-104-01: the old dt = game time minus LastFadeTime read the pure LastFadeTime getter after SetLastFadeTime had run, so dt was always 0 and the flash never faded); while HitHoldRemaining > 0 the flash holds and the hold drops by dt, else HitFlash decays 2 per s; ApplyVignette; clears its timer when flash and hold are 0.
- tick: none. The only per-frame work is the FadeStep timer, running about 0.5 s after a hit; the low-health tint follows OnHealthChanged. A hit now always restarts the hold (the old PrevHitFlash comparison is gone).
- logic_in_bp: display only (show values and timing of a fade).
