# WBP_ShopScreen

- asset_path: /Game/RogueRigs/UI/WBP_ShopScreen
- parent_class: URRShopScreenWidget (/Script/RogueRigs.RRShopScreenWidget, abstract, [[sys-run-transition]], task-317-01)
- purpose: full-screen shop shown after the stats screen on levels 1 to 3 ([[sys-run-shop]]): title bar "SPARE PARTS" with subtitle, 5 priced stat cards, ore balance counter panel, paid reroll and the Continue button. Created by BP_RRPlayerController (ShopScreenWidgetClass, Z-order 50) on OnShopScreenStarted, removed on OnLoadingStarted. Built in task-317-03 by duplicating [[wbp-intermission]] and removing the recap part (changed to the stats screen in task-317-04).
- components: CanvasPanel Root, direct children only (task-356-01, no Content / TitleRow / ShopBox / RerollBox / ContinueBox container any more): Backdrop (Border, black, alpha 1); ShopPanel (Border, T_Shop_Panel Box 512 x 205, margins 0.146 / 0.183, content padding 70 / 48 / 70 / 44) > CardsRow (HorizontalBox) of ShopCard0..4 (WBP_ShopCard, [[wbp-shop-card]], SlotIndex 0..4, each slot Fill 1, padding L/R 8); TitleBarL, Title (TextBlock 48, outline 3), TitleBarR (T_Shop_TitleBar, the right one mirrored by render scale X -1); Subtitle (TextBlock Bold 26); RerollButton (T_Shop_ButtonReroll, Box, margin 0.164, tints 1.0 / 1.3 hover / 0.7 pressed / 0.35 disabled) > RerollRow = RerollIcon (48 x 48) + RerollText + RerollDivider (3 x 52) + RerollOre (38) + RerollCost (Bold 34, violet); ContinueButton (T_Shop_ButtonContinue, Box, margin 0.155) > ContinueText (Bold 38, dark brown); IndicatorRessource (SizeBox 340 x 152, the ore counter: CounterOverlay > CounterBg + CounterCanvas > OreIcon + OreBalanceText, no Row; detail in [[wbp-shop-screen-indicator]]; OreIcon is still the flight start); FlyIcon0..9; InputBlock. Variables: Title, Subtitle, TitleBarL, TitleBarR, ShopCard0..4, CounterBg, OreIcon, OreBalanceText, RerollButton, RerollIcon, RerollText, RerollDivider, RerollOre, RerollCost, ContinueButton, ContinueText.
- anchor_rule (task-356, Q1; offsets in slate units, DPI-scaled; the owner edits these by hand in the Designer; rule [[umg-layout]]). Each Root child, anchors min-max / alignment / offsets / size:
  - Backdrop: (0,0)-(1,1), offsets 0, stretched.
  - ShopPanel: min (0.013, 0.13), max (0.987, 0.786), alignment (0,0), offsets 0, stretched (follows the screen ratio); its five card slots share the width equally (Fill 1).
  - TitleBarL: anchor (0.5,0), alignment (1,0.5), x -205, y 55. Title: anchor (0.5,0), alignment (0.5,0.5), x 0, y 55. TitleBarR: anchor (0.5,0), alignment (0,0.5), x 205, y 55, render scale X -1. Subtitle: anchor (0.5,0), alignment (0.5,0.5), x 0, y 117. All content-sized.
  - RerollButton: anchor (0.5,1), alignment (0.5,1), x 0, y -110, size 440 x 110. ContinueButton: anchor (0.5,1), alignment (0.5,1), x 0, y -3, size 416 x 106.
  - IndicatorRessource: anchor (0,0), alignment (0,0), offsets 0, content size. Its inner anchors (OreIcon, OreBalanceText on the CounterCanvas centre, CounterBg fill) are in [[wbp-shop-screen-indicator]].
  - FlyIcon0..9: unchanged, Collapsed, auto-size canvas slots. InputBlock: (0,0)-(1,1), offsets 0, Collapsed.
  - Known departures from umg-layout: the Reroll and Continue plates keep fixed slot sizes (440 x 110, 416 x 106); the indicator interior is a small canvas anchored on its centre (task-357, [[wbp-shop-screen-indicator]]).
- dpi: UI scale is the engine default (UIScaleRule ShortestSide, curve 480 -> 0.444, 720 -> 0.666, 1080 -> 1.0, 8640 -> 8, DesignScreenSize 1920 x 1080), no Config override.
- exposed_defaults: none. Tree default of Title is "SPARE PARTS".
- events: EventConstruct assigns ContinueButton OnClicked to custom event ContinueClicked (calls the C++ `Continue()` of URRShopScreenWidget) and RerollButton OnClicked to RerollClicked (calls RequestReroll on GetShop), then calls RefreshShop and LoadShopTexts once. OnShopRefreshed (C++ event, fired on every OnShopChanged) calls RefreshShop. RefreshShop: OreBalanceText = GetOreBalance, RerollCost = GetRerollCost, RerollButton SetIsEnabled(CanReroll). LoadShopTexts: Title = GetScreenTitle("shop_screen"); Subtitle = GetScreenSubtitle("shop_screen") ("RIG SERVICE TERMINAL", task-348-07); from GetScreenText("intermission_recap"): ContinueText = Labels[1], RerollText = Labels[5] ([[sys-text-content]]). The cards refresh and buy by themselves.
- ore_flight (task-342-03): Construct binds the shop's OnSlotBought (BindBoughtHook, end of Construct), Destruct unbinds. Widgets: FlyIcon0..9 (Image T_Icon_Ore 40 x 40, Collapsed, auto-size canvas slots on Root) and InputBlock (Border alpha 0, Collapsed, full screen above the content). Variables FlyActive, FlyStart, FlyCount, FlyPrice, FlyBefore, FlySrc, FlyDest, FlyCard. Functions CenterOf(W), FlyIconStep(K, E, Fly), ShopFlyStep() (not FlyStep: that name resolved to WBP_UpgradeChoice's), BeginFly(), FinishFly(). Event OnSlotBought_Event stores price, balance before, icon count and the bought card (FlyCard), then BeginFly; Event Tick calls ShopFlyStep while FlyActive. Values (owner Q7): one icon per 10 ore of price, min 3, max 10; 0.05 s between launches, 0.5 s per icon; smoothstep; 140 px upward bulge; scale 1 to 0.55; from the center of OreIcon to the center of the bought card's BuyButton; time = GetRealTimeSeconds (the game is paused). OreBalanceText starts at BalanceBefore and drops by Price * landed / Count per landing, ending on the true balance. RefreshShop has a Branch on FlyActive that skips the OreBalanceText write (reroll cost and enabled still update). InputBlock is visible for the whole flight: cards, Reroll and Continue get no click. FinishFly: flight stops, InputBlock hidden, RefreshShop, EndPurchaseFx on FlyCard ([[wbp-shop-card]]). Whole sequence measured about 0.67 s; the 1.2 s of the plan needs the effects of tasks 343/344, not built.
- logic_in_bp: display only (text, button state from C++ booleans, two calls to C++: Continue, RequestReroll) plus the ore-flight animation.
- assets: T_Icon_Ore (reused by the FlyIcons). Task-348 textures in /Game/RogueRigs/UI/Shop (task-348-05: group UI, NoMipmaps, sRGB, TC_EditorIcon, NeverStream true): T_Shop_TitleBar, T_Shop_Panel, T_Shop_CounterPanel, T_Shop_ButtonReroll, T_Shop_IconReroll, T_Shop_ButtonContinue (the others are used by [[wbp-shop-card]]). The 8 graphs of task-342 are kept.
