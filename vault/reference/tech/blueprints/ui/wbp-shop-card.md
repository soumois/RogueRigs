# WBP_ShopCard

- asset_path: /Game/RogueRigs/UI/WBP_ShopCard
- parent_class: UUserWidget (/Script/UMG.UserWidget). Not a HUD panel: placed five times by [[wbp-shop-screen]] (task-316-03, [[sys-run-shop]]).
- purpose: one shop slot: a stat card with the look of a [[wbp-upgrade-choice]] stat card (baked frame, tier tint, stat icon, value, name, target, lore), a price row (T_Icon_Ore + price) and a Buy button. Display only, no deal, suspense, flip or fly animation. Five fit in one row on 1920 x 1080 (330 px each, 1650 px plus gaps).
- components: VerticalBox Root > CardHost (SizeBox 330 x 470, centred) > CardScale (ScaleBox, ScaleToFit) > CardFace (SizeBox 500 x 720 = the UpgradeChoice card stack, so every inner value is copied from there and the whole card is scaled 0.653) > CardStack (Overlay): CardPanel (Image, RoundedBox #15171c, padding 14 24 14 25), FrameGroup (Overlay of FrameBase / FrameAccents / FrameGlow, the baked textures T_CardFrame_Stat_Baked, _Accents_Baked, _Glow_Baked, ImageSize 500 x 720, Glow RenderOpacity 0.6), CardBox (VerticalBox, padding 38 58 38 60): ImageArea (SizeBox 408 x 320) > ImageBg (Border, rounded 4) > StatIconBox (SizeBox 156 x 156) > StatIcon; EffectScale (ScaleBox DownOnly, top 18) > EffectRow = CardValue (Roboto Bold 30, tier colour) + CardName (Bold 30 white); CardTarget (Bold 20, grey); CardDesc (Italic 16 lore, Collapsed when empty, Fill slot, bottom aligned); SoldPanel (Border, rounded, Collapsed) > SoldText (Bold 30 grey); DimShade (Image, black alpha 0.55, Collapsed, same padding as CardPanel). Below the card: PriceRow (HorizontalBox, centred, top 10) = OreIcon (Image 40 x 40, T_Icon_Ore) + PriceText (Bold 36 white); BuyHost (Overlay, vbox slot padding top 8, centred; task-343-01) > BuyButton (default Button style, overlay slot Fill/Fill) > BuyText (Bold 28), with BuyFlash (Image white, Fill/Fill, HitTestInvisible, render opacity 0) over it; SparkHost (CanvasPanel, HitTestInvisible) holding Spark0..Spark7 (Image 10 x 10, RoundedBox radius 5, canvas anchor 0.5/0.5, alignment 0.5/0.5, opacity 0). Only the weapon-card variant of UpgradeChoice is absent: the shop sells stat cards only. All named widgets above are variables.
- exposed_defaults: SlotIndex (int, instance editable, default 0): the shop slot this card shows (0 to ShopCardCount - 1). BuyLabel "Buy", SoldLabel "Sold. No refunds.", ShortLabel "Short on ore" (Text variables, English defaults, replaced at Construct by LoadLabels).
- events (parent contract, important): the card is self-driving, the parent needs no cross-Blueprint call. Construct: LoadLabels, RefreshFromShop, assigns BuyButton OnClicked (event OnClicked_Event_3) and binds the shop's OnShopChanged to custom event ShopChangedEv (the delegate pin was wired by hand with connect_pins, the DSL left it open); Destruct unbinds only this card's own ShopChangedEv from OnShopChanged (Unbind Event node, delegate pin wired by hand to the same event as the bind), so the C++ widget and the other cards keep their bindings. ShopChangedEv calls RefreshUnlessHolding (task-342-02; Construct still calls RefreshFromShop directly). Hold for the ore flight: variable bHolding (bool, false); custom event OnSlotBought_Event(BoughtSlot) bound in Construct to the shop's OnSlotBought (assigned after the OnShopChanged bind) and unbound in Destruct, calls HoldIfBought. While bHolding the card ignores OnShopChanged, so it stays visible until the screen's flight ends and calls EndPurchaseFx. The click event calls the C++ BuySlot(SlotIndex) on `URRIntermissionShopSubsystem` then the dispatcher OnBuyClicked(SlotIndex int). So the parent only has to put five instances in its tree and set SlotIndex 0..4 on each (variable value on the placed widget), and may ignore the dispatcher (it exists for effects such as a purchase sound; binding it from WBP_Intermission is untested).
- functions (public, callable from the parent; MCP lists them as `Class|WBPShopCard|<name>` node types inside other Blueprints, so a widget-to-widget call is possible, only not needed): SetCard(Card FRRUpgradeCard, Price int, bAffordable bool): texts from ValueText / DisplayName / TargetText / LoreText, StatIcon = `GetStatIcon(Stat)` at 156 x 156, tier colour on FrameAccents, FrameGlow and CardValue (grey 0.55, green 0.2/0.8/0.25, blue 0.2/0.45/1, purple 0.65/0.25/0.9, yellow 1/0.85/0.1, same as UpgradeChoice) through TintCard(Color); card visible, SoldPanel Collapsed, PriceText = Price, price row and button shown; bAffordable true: button enabled with BuyLabel, price white, no dim; false: button disabled (greyed by Slate) with ShortLabel, price red (1, 0.35, 0.3), DimShade shown over the card. SetBought(): card and frame Collapsed, SoldPanel shown with SoldLabel, price row and button Hidden (they keep their space so the row does not shift), button disabled; this is the empty slot look. RefreshFromShop(): gets the shop subsystem (`Get Intermission Shop`), `GetSlot(SlotIndex)`; slot found and not sold: SetCard(slot Card, Price, `CanBuySlot(SlotIndex)`); else SetBought. HoldIfBought(BoughtSlot): if BoughtSlot == SlotIndex, bHolding = true then StartJuice (only the bought card reacts; OnSlotBought fires once per successful BuySlot, never on refusal, rr.Shop.Buy included). Buy button juice (task-343-01, values provisional, Q10 of [[task-343-shop-buy-juice]], no sound): variables bJuiceActive (bool), JuiceStart (float), TierColor (LinearColor, stored by TintCard, so SetCard sets it). StartJuice: JuiceStart = GetRealTimeSeconds, bJuiceActive = true, JuiceStep once. JuiceStep: E = real time - JuiceStart; drives the button scale, BuyFlash opacity and SparkStep(I, E, Spark) per spark; at E >= 0.35 clears bJuiceActive. Event Tick runs JuiceStep only while bJuiceActive (real time, not game time). Scale 1 to 0.88 linear over 0 to 0.06 s, then 0.88 + 0.12 * easeOutBack(u) over 0.06 to 0.30 s with c1 = 8.25, c3 = 9.25 (peak 1.12 near 0.157 s, exactly 1 at 0.30 s; c1 chosen by the bp agent to meet Q10). Flash white opacity 0.8 * (1 - E/0.2) (0.8 peak is the bp agent's choice, not decided). 8 sparks at angle I * 45 deg, radius 64 * (1 - (1-p)^2) with p = E/0.35, scale 1 to 0.5, opacity 1 to 0, colour TierColor. RefreshUnlessHolding(): RefreshFromShop when not bHolding. EndPurchaseFx() (public, contract with the parent): bHolding = false then SetBought (sold look); [[wbp-shop-screen]] calls it on the bought card when its flight ends. LoadLabels(): `GetScreenText("intermission_recap")` ([[sys-text-content]]), Labels[2] -> BuyLabel, Labels[3] -> SoldLabel, Labels[4] -> ShortLabel; on failure keeps the English defaults. TintCard(Color). Labels index 2, 3, 4 of screen_texts.json `intermission_recap` are read by the card itself, so the parent does not pass them.
- dispatchers: OnBuyClicked(SlotIndex int), called after BuySlot on every click.
- logic_in_bp: display only (text, visibility, colours); the purchase itself is the C++ call BuySlot.
- assets: reuses T_CardFrame_Stat_Baked, _Accents_Baked, _Glow_Baked, T_Icon_Ore, the stat icons through `URRIconLibrary`.
- owner_agent: agent-bp
- verified: task-316-03: compiled with warnings as errors (compile_blueprint true, CompileWidgetBlueprint true) and saved; tree and every property read back; graphs SetCard, SetBought, RefreshFromShop, LoadLabels, TintCard and the EventGraph read back, Break node output wiring (DisplayName, ValueText, TargetText, LoreText, Stat, Tier, Card, Price, bSold) and array indices 2, 3, 4 checked. Unverified (no PIE, nothing seen, no capture): the look at 0.653 scale, the stat icon appearance, fit of long names, the Buy button look and size, the grey and dim look when unaffordable, the sold look, that OnShopChanged really refreshes five instances, that the click buys, a name collision of two cards sharing an event name (each instance has its own graph).
- verified_juice: task-343-02 capture (-game, rr.Shop.Buy, frames about 0.1 s apart): flash, 8 tier-coloured sparks and the overshoot (about 1.06 to 1.08 width) seen, back to normal by +0.31 s. Not resolved: the 0.88 low point and the 1.12 peak. Not tested: greyed button, real mouse click.
