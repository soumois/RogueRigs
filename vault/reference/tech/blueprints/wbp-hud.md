# WBP_HUD

- asset_path: /Game/RogueRigs/UI/WBP_HUD
- parent_class: URRHUDWidget (/Script/RogueRigs.RRHUDWidget)
- purpose: in-run HUD display; the data comes from C++ ([[sys-hud]]).
- components: CanvasPanel Root; HealthBar (ProgressBar, top-left 20,20, 280 x 28, red fill 0.9/0.05/0.05, percent 1); HealthText (TextBlock under the bar, "0 / 0"); GameOverText (TextBlock "GAME OVER", size 72, red, centred, Visibility Collapsed); XPBar (ProgressBar, cyan fill 0/0.85/1, percent 0, anchored bottom and stretched across the width: left 90, right 20, top -36, 16 uu tall); LevelText (TextBlock "Lv 1", size 22, bottom-left at 20, -42, auto size); LevelUpText (TextBlock "LEVEL UP", size 56, cyan, centred a little above the screen centre (0, -120), Visibility Collapsed). UpgradeScreen (CanvasPanel, full screen, z-order 10, Visibility Collapsed) = Backdrop (Border, black alpha 0.7) + Panel (VerticalBox, centred, auto size): TitleText "Choose an upgrade" (size 36), CardsRow (HorizontalBox) of three SizeBox 260 x 230 (CardSize0..2) each holding CardBorder (Border, tier colour, padding 6) > CardButton (Button) > CardBox (VerticalBox) with CardName (26), CardTarget (18), CardValue (30) TextBlocks (centred, wrapped), then RerollButton with RerollText "Reroll". Card, border, size and text widgets, RerollButton and UpgradeScreen are variables. Run flow widgets (task-016-03), top centre: AlertBar (ProgressBar, orange 1/0.35/0.1, 300 x 18) with AlertLabel "ALERT"; ObjectiveText (TextBlock 22, white, centred, Collapsed until a console exists, top 66 since task-027-02 so it clears the alert icon row at top 34); HackBar (ProgressBar teal 0/0.85/1, 300 x 14, top 100, Collapsed); ShuttleText (TextBlock 30, teal, top 122, Collapsed). EndScreen (CanvasPanel full screen, z-order 20, Collapsed) = EndBackdrop (Border, black alpha 0.75) + EndPanel (VerticalBox centred) with EndTitle (64) and RestartButton > RestartText "Play again". All except EndBackdrop and EndPanel are variables; bool variable bHackDone. The upgrade UI lives in this widget (a separate WBP_UpgradeChoice could not be called from the HUD graph through MCP and was deleted).
- Other: All other named widgets are variables except Root.
- exposed_defaults: none.
- events: OnHealthChanged(Current, Max) sets the bar percent to Current / Max (0 when Max <= 0) and the text to "round(Current) / round(Max)"; OnXPChanged(Current, Needed, Level) sets XPBar percent to Current / Needed (0 when Needed <= 0) and LevelText to "Lv " + Level; OnLevelUp(NewLevel) sets LevelUpText Visible, a Delay of 1 s, then Collapsed (a second level-up inside 1 s hides it early); OnGameOver sets GameOverText Visible; OnUpgradeOfferShown(Cards, bCanReroll) sets UpgradeScreen Visible, RerollButton enabled = bCanReroll, then functions SetCard0..2(Cards): if Cards has that index, CardSize Visible, the three texts from DisplayName / TargetText / ValueText and a switch on Tier sets CardBorder colour (grey 0.55 grey, green 0.2/0.8/0.25, blue 0.2/0.45/1, purple 0.65/0.25/0.9, yellow 1/0.85/0.1), else CardSize Collapsed; OnUpgradeOfferClosed sets UpgradeScreen Collapsed; OnClicked of CardButton0..2 calls ChooseUpgrade(0..2), of RerollButton RequestReroll. Run flow events: OnAlertChanged sets AlertBar percent and the label ("ALERT", "ALERT (paused)" while paused); OnObjectiveChanged: hidden when inactive or bHackDone, else text "Clear the marked rocks (cleared/total)" while rocks remain, then "Hack the console: stay close to it" with HackBar visible; OnObjectiveProgressChanged sets HackBar percent and at 1 sets bHackDone and hides both; OnExtractionReady sets the text "Reach the shuttle"; OnShuttleCountdown shows ShuttleText "Shuttle: n s"; OnRunEnded shows EndScreen with "EXTRACTION SUCCESSFUL" or "RUN LOST" and hides ShuttleText; RestartButton OnClicked calls RestartLevel. Display only, no gameplay logic (the single reroll rule is in C++, [[sys-level-up]]).
- weapons (task-024-05): CardDesc0..2 (TextBlock 16, wrapped, Collapsed, under CardBox0..2); function StyleCards(Cards) calls StyleCard0..2, called at the end of OnUpgradeOfferShown: for a NewWeapon card the border is teal-white (0, 0.9, 0.85), CardDesc shows DescriptionText and CardValue is hidden (title "New weapon" and weapon name come from DisplayName and TargetText through SetCard); for a stat card CardDesc is hidden.
