# WBP_HUD

- asset_path: /Game/RogueRigs/UI/WBP_HUD
- parent_class: URRHUDWidget (/Script/RogueRigs.RRHUDWidget)
- purpose: in-run HUD display; the data comes from C++ ([[sys-hud]]).
- components: CanvasPanel Root; HealthBar (ProgressBar, top-left 20,20, 280 x 28, red fill 0.9/0.05/0.05, percent 1); HealthText (TextBlock under the bar, "0 / 0"); GameOverText (TextBlock "GAME OVER", size 72, red, centred, Visibility Collapsed); XPBar (ProgressBar, cyan fill 0/0.85/1, percent 0, anchored bottom and stretched across the width: left 90, right 20, top -36, 16 uu tall); LevelText (TextBlock "Lv 1", size 22, bottom-left at 20, -42, auto size); LevelUpText (TextBlock "LEVEL UP", size 56, cyan, centred a little above the screen centre (0, -120), Visibility Collapsed). UpgradeScreen (CanvasPanel, full screen, z-order 10, Visibility Collapsed) = Backdrop (Border, black alpha 0.7) + Panel (VerticalBox, centred, auto size): TitleText "Choisis une amélioration" (size 36), CardsRow (HorizontalBox) of three SizeBox 260 x 230 (CardSize0..2) each holding CardBorder (Border, tier colour, padding 6) > CardButton (Button) > CardBox (VerticalBox) with CardName (26), CardTarget (18), CardValue (30) TextBlocks (centred, wrapped), then RerollButton with RerollText "Relancer". Card, border, size and text widgets, RerollButton and UpgradeScreen are variables. Run flow widgets (task-016-03), top centre: AlertBar (ProgressBar, orange 1/0.35/0.1, 300 x 18) with AlertLabel "ALERTE"; ObjectiveText (TextBlock 22, white, centred, Collapsed until a console exists); HackBar (ProgressBar teal 0/0.85/1, 300 x 14, Collapsed); ShuttleText (TextBlock 30, teal, Collapsed). EndScreen (CanvasPanel full screen, z-order 20, Collapsed) = EndBackdrop (Border, black alpha 0.75) + EndPanel (VerticalBox centred) with EndTitle (64) and RestartButton > RestartText "Rejouer". All except EndBackdrop and EndPanel are variables; bool variable bHackDone. The upgrade UI lives in this widget (a separate WBP_UpgradeChoice could not be called from the HUD graph through MCP and was deleted).
- Other: All other named widgets are variables except Root.
- exposed_defaults: none.
- events: OnHealthChanged(Current, Max) sets the bar percent to Current / Max (0 when Max <= 0) and the text to "round(Current) / round(Max)"; OnXPChanged(Current, Needed, Level) sets XPBar percent to Current / Needed (0 when Needed <= 0) and LevelText to "Lv " + Level; OnLevelUp(NewLevel) sets LevelUpText Visible, a Delay of 1 s, then Collapsed (a second level-up inside 1 s hides it early); OnGameOver sets GameOverText Visible; OnUpgradeOfferShown(Cards, bCanReroll) sets UpgradeScreen Visible, RerollButton enabled = bCanReroll, then functions SetCard0..2(Cards): if Cards has that index, CardSize Visible, the three texts from DisplayName / TargetText / ValueText and a switch on Tier sets CardBorder colour (grey 0.55 grey, green 0.2/0.8/0.25, blue 0.2/0.45/1, purple 0.65/0.25/0.9, yellow 1/0.85/0.1), else CardSize Collapsed; OnUpgradeOfferClosed sets UpgradeScreen Collapsed; OnClicked of CardButton0..2 calls ChooseUpgrade(0..2), of RerollButton RequestReroll. Run flow events: OnAlertChanged sets AlertBar percent and the label ("ALERTE", "ALERTE (pause)" while paused); OnObjectiveChanged: hidden when inactive or bHackDone, else text "Dégage les roches marquées (cleared/total)" while rocks remain, then "Pirate la console : reste près d'elle" with HackBar visible; OnObjectiveProgressChanged sets HackBar percent and at 1 sets bHackDone and hides both; OnExtractionReady sets the text "Rejoins la navette"; OnShuttleCountdown shows ShuttleText "Navette : n s"; OnRunEnded shows EndScreen with "EXTRACTION RÉUSSIE" or "RUN PERDUE" and hides ShuttleText; RestartButton OnClicked calls RestartLevel. Display only, no gameplay logic (the single reroll rule is in C++, [[sys-level-up]]).
- weapons (task-024-05): CardDesc0..2 (TextBlock 16, wrapped, Collapsed, under CardBox0..2); function StyleCards(Cards) calls StyleCard0..2, called at the end of OnUpgradeOfferShown: for a NewWeapon card the border is teal-white (0, 0.9, 0.85), CardDesc shows DescriptionText and CardValue is hidden (title "Nouvelle arme" and weapon name come from DisplayName and TargetText through SetCard); for a stat card CardDesc is hidden. WeaponSlot0..3 (TextBlock 18, bottom-left row at y -78, spaced 170): EventTick shows the display names of ARRMiner GetWeapons or "- vide -" up to 4 slots. TurretText (teal, Collapsed) and TurretBar (ProgressBar teal 200 x 10, Collapsed): OnTurretChargesChanged shows them and sets "Tourelles : n / max"; EventTick sets TurretBar percent from GetTurretRechargeProgress.
- pressure (task-026-03): DamageVignette (Image, full screen, first child, HitTestInvisible, RenderOpacity 0, brush = material M_HUDVignette: UI domain, translucent, red emissive, opacity = saturate((distance of UV from centre - 0.2) * 2.5)); HordeBanner (TextBlock 64 bold, red 1/0.12/0.05, outline, centred 220 above the centre, Collapsed); AlertIconConsole "C" (teal) and AlertIconShuttle "N" (white) under the alert bar (top 34), AlertIconHorde0..3 "!" (red) over its top edge (top -6), all TextBlocks 22 bold, Collapsed, left -108 from the centre anchor (bar left -100, width 300). Variables HitFlash, LowHealthAlpha. OnPlayerDamaged sets HitFlash = 0.4 + 0.4 * (1 - HealthFraction); function UpdateVignette(DeltaTime), called each EventTick: HitFlash decays 2 per s, LowHealthAlpha = 0.4 - HealthBar percent when percent < 0.4 (else 0), vignette RenderOpacity = clamp(sum, 0, 0.9). OnHordeIncoming shows the banner for SecondsUntil s (4 when <= 0) then Collapsed (Delay: a second banner inside it is ignored). OnAlertEventsChanged collapses every icon, then per event calls PlaceIcon(Icon, Position, bDone) (switch on Type, horde by Index 0..3): visible, RenderTranslation X = Position * 300, RenderOpacity 0.35 when done else 1. Display only. Not built: light halo (needs a C++ hook, see [[task-026-03-bp-pressure]]).
