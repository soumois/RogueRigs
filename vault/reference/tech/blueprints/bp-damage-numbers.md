# NS_DamageNumbers (damage number rendering)

- asset_path: /Game/RogueRigs/FX/NS_DamageNumbers (Niagara system, no Blueprint graph); /Game/RogueRigs/FX/M_DamageNumber (material); /Game/RogueRigs/FX/T_DamageDigits (texture)
- parent_class: none (spawned as one persistent component by `URRDamageNumberSubsystem`, [[sys-damage-numbers]])
- purpose: one sprite per digit, up to 5 digits per number, no actor per hit.
- components: one emitter `DirectionalBurst` (renamed template): CPU sim, world space, fixed bounds ±30000 xy, sprite renderer (Unaligned, FaceCamera, SubImage 16x1, no shadow).
- exposed_defaults: user parameters set by C++: `User.DamageNumberPositions/Values/Sizes/Colors/Criticals/SpawnTimes` (arrays), `User.DamageNumberNewCount` (int). Lifetime 0.7 s, rise 85.7 uu/s (60 uu), fade over the last 45 % of life, 0.1 s pop (scale +15 %, crit +35 % and flash to white), digit advance 0.62 x size.
- events: Emitter Update `SpawnPerFrame` count = `NewCount * 5`. Particle Spawn (chain of SetParameters modules): `Engine.ExecutionIndex` -> number = index / 5, slot = index mod 5; arrays read with `SelectFloat/Position/LinearColorFromArray` in Direct Set mode; digit count and digit value from HLSL on the rounded value; unused slots get lifetime 0.001 and size 0. Particle Update sets color alpha and size.
- logic_in_bp: none (all in Niagara modules; gameplay stays in C++).
- assets: T_DamageDigits 1024x64 RGBA, 16 cells of 64 px, digits 0-9 in cells 0-9 (5x7 pixel font, soft edges, generated by a script and imported with TextureTools); M_DamageNumber unlit translucent, ParticleSubUV alpha x ParticleColor alpha, emissive = ParticleColor, usage flag NiagaraSprites.
- limits: crit is derived from the color (blue < 0.9) because the Bool array has no direct-index read; a sum above 99999 shows five digits; digit offset runs along world Y (camera yaw 0).
- owner_agent: agent-bp
