# Player

- responsibility: the miner pawn (ASC, stats, camera, movement, aim, starting weapons), the input routing from Enhanced Input to the miner, the run game mode (game over on death, level restart). No dash, shot, AoE or item logic; pickups only report collection to the miner ([[sys-pickups]]); XP and level live in its progression component ([[sys-progression]]).
- main_classes (all in `Source/RogueRigs/Player/`, all `Abstract`, subclassed in Blueprint):
  - `ARRMiner : ACharacter, IAbilitySystemInterface` (`RRMiner.h`): `URRAbilitySystemComponent` plus `URRHealthAttributeSet`, `URRMovementAttributeSet`, `URRPlayerAttributeSet` as default subobjects (registered by the ASC's `InitializeComponent`), and `URRProgressionComponent` `Progression` (`GetProgression()`, [[sys-progression]]), `URRUpgradeComponent` `Upgrades` (`GetUpgrades()`, [[sys-upgrades]]), `URRLevelUpComponent` `LevelUp` (`GetLevelUp()`, [[sys-level-up]]). Spring arm with absolute rotation (never turns with the pawn) and camera. Editable: `BaseStatsRowName` (`Miner`), `CameraPitch` (−50), `CameraYaw` (0), `CameraArmLength` (1700), `bCameraLag` (false: no spring-arm lag, the miner stays centered; lag speed 0.5 when on), `CameraFieldOfView` (75), `AimRotationInterpSpeed` (0 = instant), `MouseAimPlaneHeight` (0), `StickAimMinInput` (0.1), `DroneClass` (none; set to the drone Blueprint), `DigReachMargin` (30 uu), `DigMinMoveInput` (0.1, provisional), `StartingWeapons` (array of `ARRWeapon` classes, empty; `BP_Miner`: the burst rifle only since task-024-04), `GuaranteedWeaponClasses` (empty by default: each class spawned after `StartingWeapons` unless an entry of `StartingWeapons` is that class or a subclass), `WeaponCatalogue` (`FRRWeaponCatalogueEntry` list offered by new-weapon cards, [[sys-upgrades]]; native defaults `ARRShotgun`, `ARRTurretLauncher` with provisional French descriptions; `BP_Miner` lists the Blueprints), `MaxWeapons` (4), `WeaponAttachSocketName` (none = attach to the capsule, which turns with the aim yaw), `WeaponAttachOffset` ((0, 20, −40) uu from the capsule center, X forward, Y right; used only when the socket is none). Damage: `IFramesDuration` (0.25 s), `IFramesEffectClass` (`URRGE_IFrames`), `BlinkRate` (12 Hz, full hide/show cycles). Holds the spawned drone in `Drone` (`GetDrone()`) and the arena grid in `ArenaGrid` (`GetArenaGrid()`). Movement defaults (gravity 1.5, acceleration 1000, no ledge walk-off) are component properties, editable in Blueprint.
  - `ARRPlayerController` (`RRPlayerController.h`): editable `DefaultMappingContext`, `MappingContextPriority`, `MoveAction`, `StickAimAction`, `MouseAimAction`, `PlaceTurretAction` (Boolean, bound on Started → `ARRMiner::PlaceTurret`), `PlaceTurretKeys` (E, right mouse button, gamepad face button bottom), `bHideCursorWhileStickAiming`. While `PlaceTurretAction` is unset, a transient action mapped to `PlaceTurretKeys` lives in a transient mapping context added at `MappingContextPriority` + 1, so the button works without assets; once the asset is set its keys come from `DefaultMappingContext`. Cursor shown by default. HUD: editable `HUDWidgetClass` (none; set to the HUD widget Blueprint); `BeginPlay` creates it for a local player only and binds it, `OnPossess` rebinds it to the new miner; `GetHUDWidget()` ([[sys-hud]]).
  - `ARRGameMode : AGameModeBase` (`RRGameMode.h`): default pawn and controller classes set in Blueprint. Game over: `RegisterMiner(ARRMiner*)` (called by the miner `BeginPlay` when the auth game mode is an `ARRGameMode`) binds the miner `OnDeath`; the first death disables the input of every player controller (`DisableInput`), broadcasts `OnGameOver` (BlueprintAssignable) once and arms a timer that reopens the current level (`UGameplayStatics::OpenLevel` on `GetCurrentLevelName`) after editable `RestartDelay` (3 s, miner gdd M1). `IsGameOver()`, `GetRestartDelay()`, `GetRestartTimeRemaining()` (−1 when not armed). `EndPlay` clears the timer.
- entry_points:
  - `BeginPlay`: `InitAbilityActorInfo(this, this)`, subscribe to `MoveSpeed` changes, `FRRBaseStatsLoader::LoadAndApplyPlayerBaseStats(ASC, BaseStatsRowName)`, push `MoveSpeed` to `MaxWalkSpeed` ([[sys-gas-core]]), then spawn `DroneClass` at the miner (owner = miner) and call `SetOwnerMiner` ([[sys-drone]]), then store the first `ARRArenaGrid` of the world in `ArenaGrid` (none = warning, no digging), then spawns each `StartingWeapons` class, then each `GuaranteedWeaponClasses` entry not provided (owner = miner), attaches it (mesh socket `WeaponAttachSocketName`, or the capsule at `WeaponAttachOffset` when none), makes the capsule ignore it when moving and calls `ARRWeapon::Acquire` ([[sys-weapons]]); spawned weapons in `Weapons` (`GetWeapons()`). Each acquisition goes through `AddWeapon(Class)` (BlueprintCallable; also for runtime weapons) and broadcasts `OnWeaponAdded(Weapon)`. `OwnsWeaponClass(Class)` (a valid weapon is that class or a subclass), `GetOwnedWeaponCount()`, `CanAcquireWeapon(Class)` (not owned and below `MaxWeapons`), `GetAcquirableWeapons()` (catalogue entries acquirable now), `GetWeaponCatalogue()`, `GetMaxWeapons()`. `FindTurretLauncher()`; `PlaceTurret()` (refused when dead) asks the launcher to place a turret ([[sys-turret]]). `EndPlay` destroys the drone and the weapons. `PossessedBy` calls `RefreshAbilityActorInfo`.
  - Damage ([[sys-damage]]): `BeginPlay` binds the health set `OnDamageReceived` and `OnDeath`. A hit leaving `Health` > 0 applies `IFramesEffectClass` to self (SetByCaller `Data.Duration` = `IFramesDuration`) in the same call stack, then the mesh blinks (hidden the first half of each cycle, `Tick`-driven on world time) and is shown again at the end. Death: input, aim, dig and movement stop (`StopMovementImmediately`), weapons `StopFiring`, blink ends, `OnDeath(Instigator)` (BlueprintAssignable) fires. `IsDead()`, `GetIFramesDuration()`, `GetHealthSet()`.
  - Pickups: `GetPickupRadius()` (current `PickupRadius` attribute, 0 without the set), `NotifyPickupCollected(ERRPickupType)` broadcasts `OnPickupCollected(Type)` (BlueprintAssignable); no effect applied.
  - `ApplyMoveInput(FVector2D)`, `ApplyStickAimInput(FVector2D)`, `UseMouseAim()`, `GetMouseAimPoint(FVector&)` (last cursor point on the aim plane, mouse aim only); `GetAimDirection()`, `IsUsingMouseAim()`, `GetRRAbilitySystemComponent()`.
  - Input axes: screen axes, X = right, Y = up, rotated by the arm's world yaw. A raw gamepad stick needs no modifier; WASD needs the usual swizzle on W/S and negate on S/A. Actions are bound on `Triggered`.
  - Dig trigger (end of `Tick`): `ApplyMoveInput` stores the world-space move input of the frame; `Tick` consumes it. If its length is above `DigMinMoveInput`, the direction is turned into grid space and reduced to its dominant axis (a diagonal picks one neighbour); the target is the miner's cell (`GetCellAtWorld`) + that step. If `IsBlockCell(target)` and the distance from the miner to the facing block face along the push axis is at most capsule radius + `DigReachMargin`, the miner calls `Drone->RequestDig(ArenaGrid, target, -step)` ([[sys-drone]]). The drone owns the cancel rule; releasing the push does not stop a dig.
  - Mouse aim: each tick the cursor ray is intersected with a horizontal plane at the capsule bottom + `MouseAimPlaneHeight`; a stick input switches to stick aim, any mouse aim trigger switches back.
- data: `PlayerBaseStats.csv` row `BaseStatsRowName`; `Config/DefaultGame.ini` stages `RogueRigs/Data` as non-UFS so tables and layouts ship.
- depends_on: [[sys-gas-core]], [[sys-grid]] (dig trigger cell queries), [[sys-pickups]] (`ERRPickupType`); modules `EnhancedInput`, `GameplayAbilities`.
- implements: [[miner]], [[player-stats]].
- gotchas:
  - `bUseControllerRotationYaw` and `bOrientRotationToMovement` are off: the pawn yaw follows only the aim.
  - Collision: the capsule responds Overlap to the `Projectile` channel ([[sys-projectiles]]), so no projectile, own or enemy, ever blocks it, while projectile overlap events (hits by overlap) still fire. Ignore would also suppress those overlaps.
  - A held weapon with blocking collision inside the capsule pushes the miner sideways each move (depenetration): measured in task-008-01, `BP_BurstRifle` `RifleMesh` (`BlockAllDynamic`) on `hand_r` turned 1 s of +X input into 66 uu forward and 350 uu sideways. Weapons have no actor collision and the capsule ignores them when moving.
  - Aim keeps its last direction while no aim input arrives; before the first input it is the spawn facing.
  - Inputs and assets are not wired until the Blueprint subclasses exist.
  - The `Variant_TwinStick` classes are reference only and stay untouched.
