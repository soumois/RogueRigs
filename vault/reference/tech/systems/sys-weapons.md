# Weapons

- responsibility: weapon lifecycle, weapon stats, how upgrades reach weapons and turrets.
- main_classes (in `Source/RogueRigs/Weapons/`): `ARRWeapon` (abstract; own `URRAbilitySystemComponent` + `URRWeaponAttributeSet`, root scene component, `Muzzle` scene component under it (visual reference only), no actor collision (`bActorEnableCollision` off: a held weapon sits inside the miner capsule and would push it), `URRAutoFireComponent` [[sys-auto-fire]]; protected virtual `FireOnce()` decides what is fired: by default the burst rifle shot, overridden by weapons that fire differently); `URRWeaponAttributeSet` (`Damage`, `FireRate`, `ReloadSpeed`, `CritChance`, `CritDamage`, `MagazineSize`, `Ammo`; all >= 0, `Ammo` <= `MagazineSize`, lowered when `MagazineSize` drops); `FRRWeaponStatsRow`; GEs `URRGE_ConsumeAmmo` (instant, `Ammo` -1) and `URRGE_RefillAmmo` (instant, `Ammo` overridden by the target's `MagazineSize`); `ARRShotgun` (Blueprintable, usable natively: `StatsRowName` `Shotgun`) with `FRRShotgunWave`. Weapons: burst rifle (implemented in `ARRWeapon`), shotgun (implemented), turret launcher (not yet).

## Decisions
- One ASC per weapon; upgrades routed by `Weapon.Player.*` tags (approved).
- Magazine and reload by GEs `ConsumeAmmo`, `Reloading`, `RefillAmmo` (approved). Implemented: `ConsumeAmmo`, `RefillAmmo`; the reload is a timer in [[sys-auto-fire]]; `Reloading` (duration GE + tag) waits for the tag hierarchy (open).
- Acquisition order (provisional): spawn and attach → `InitAbilityActorInfo(weapon, weapon)` → base values from CSV (`SetNumericAttributeBase`) → replay of global upgrades → registration in the player's registry.
- Global bonuses are broadcast to every weapon ASC, replayed on acquisition, never removed; the list of applied upgrades serves replay and debug (provisional).
- Player-state conditions (death, level transition) are read on the player's ASC; weapon ASCs do not carry those tags (provisional).
- 4-direction fire is a fire pattern inside `FireOnce()` (main shot + 3 weaker ones), not a projectile behavior (provisional).
- Burst rifle `FireOnce()` (implemented in `ARRWeapon`): `MakeDamageSpec()` (editable `DamageEffectClass`, default `URRGE_Damage`, context instigator and causer = the weapon), then one editable `ProjectileClass` spawned deferred at `GetShotOrigin()`, flat, aim yaw + uniform random in ±`SpreadDeg`, speed `ProjectileSpeed`, lifetime `Range / ProjectileSpeed`; Owner = weapon, Instigator = miner ([[sys-projectiles]]). Skipped with a warning if `ProjectileClass` is unset or `ProjectileSpeed`/`Range` <= 0. The Blueprint subclass sets `ProjectileClass`, the mesh and the `Muzzle` position.
- Shot origin (`GetShotOrigin()`): floor under the owning miner (capsule bottom minus the CharacterMovement floor distance when walking) + editable `ShotHeight` (50 uu; must stay below the grid `BlockHeight`, warning at acquisition otherwise), moved along the aim by capsule radius + editable `ShotForwardOffset` (20 uu, measured from the capsule surface). Shots hit floor-standing targets and stop on blocks whatever the weapon mesh pose. Without an owning miner (tests, future turrets): the `Muzzle`.
- Shotgun (implemented, `ARRShotgun::FireOnce`): no projectile. Wave origin = the miner axis at shot height (`GetWaveOrigin`). Targets (`FindWaveTargets`): every living `ARREnemy` whose center is within `Range` (2D) and within `ConeAngleDeg` / 2 of the aim, kept if `ARRArenaGrid::HasLineOfSight` from the origin is clear ([[sys-grid]]); nearest first. One `MakeDamageSpec()` per wave applied to each target from the weapon ASC, so each robot rolls its own critical ([[sys-damage]]). Then `ARREnemy::ApplyKnockback(outward × KnockbackForce)` ([[sys-enemies]]; a robot killed by the wave is not pushed). Blocks and barrels are not hit. Then `LastWave` (`GetLastWave()`: origin, direction, half angle, range, `ClippedLength` = grid clear distance along the aim, hit count, time), `GetWaveCount()`, and the BlueprintImplementableEvent `OnWaveFired(Origin, Direction, HalfAngleDeg, WaveRange, ClippedLength)` for the VFX; `GetWaveClearDistance(YawOffsetDeg)` clips other rays of the last wave. Without a grid nothing is blocked.
- Reload duration = base `ReloadTime` (CSV) / `ReloadSpeed`.
- Turret launcher: `MagazineSize` = turret charges; placing a turret starts recharging that charge at `ReloadSpeed`, one charge at a time; no cap on active turrets.
- Impact effects are weapon attributes (e.g. `StunChance`, `StunDuration`), changed by ordinary upgrade GEs; an effect is active when its attribute is above 0 (provisional).
- Turrets: at placement, copy every attribute of the turret launcher, impact effects and `Projectile.Behavior.*` tags included (provisional). A turret's specs have the turret as instigator.

- aim seam (task-020-02): `GetAimDirection` and `GetShotOrigin` are virtual (a turret overrides them); `FireOnce` spawns through `ARRProjectile::SpawnProjectile` ([[sys-projectiles]]).
- entry_points: `ARRWeapon::Acquire(Miner)`, called by the miner after spawn and attach ([[sys-player]]): `InitAbilityActorInfo(weapon, weapon)`, base values from CSV row `StatsRowName` (editable, set in Blueprint), magazine filled, auto-fire configured (ticks after the miner) and started if `bStartFiringOnAcquire`. Upgrade replay: after the base values, the owning miner's all-weapons upgrades are re-applied ([[sys-upgrades]]). Player registry: not implemented. `GetDisplayName()` (CSV `DisplayName`, or the row name). `GetAimDirection()` = owning miner's aim (weapon forward without miner). `GetShotOrigin()`, `GetShotHeight()`, `GetShotForwardOffset()`. Getters for the CSV constants. `ApplyStatsRow` is virtual (the shotgun copies `ConeAngleDeg`, `KnockbackForce`; getters `GetConeAngleDeg`, `GetKnockbackForce`).
- data: `Content/RogueRigs/Data/Tables/WeaponStats.csv`, read at runtime with `FRRBaseStatsLoader::LoadTableFromCSV`; row `BurstRifle` = [[burst-rifle]] values; row `Shotgun` = [[shotgun]] values (18, 0.8, `BurstCount` 1, crit 0.05 / 1.5, magazine 6, reload 2 s, `Range` 700, `ConeAngleDeg` 60, `KnockbackForce` 600 uu/s; `ProjectileSpeed`, `SpreadDeg` 0); column `DisplayName` is the French UI name (`Fusil à rafales`, `Fusil à pompe`, working names). Attribute columns become base values; `BurstCount`, `BurstDuty`, `ReloadTime`, `ProjectileSpeed`, `Range`, `SpreadDeg`, `ConeAngleDeg` (full cone angle), `KnockbackForce` (launch speed before resistance; 0 on the rifle) stay constants on the weapon.
- depends_on: [[sys-gas-core]], [[sys-projectiles]], [[sys-player]] (aim).
- implements: [[burst-rifle]], [[shotgun]], [[turret]], [[upgrades]].
- loadout: the miner spawns the shotgun natively through `GuaranteedWeaponClasses` until `BP_Miner` lists a shotgun Blueprint in `StartingWeapons` ([[sys-player]]).
- gotchas: knockback 600 is read as a launch speed in uu/s (interpretation, provisional); ground friction brakes it within a few frames (measured: +30 uu in 3 frames against the chase). `AbilitySystem.DebugAttribute FireRate Damage` shows values above each weapon actor. Turret stats are frozen by attribute copy, not by spec snapshot.
