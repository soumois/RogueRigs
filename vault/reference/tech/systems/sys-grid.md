# Grid

- responsibility: terrain data, rendering, block health and destruction.
- main_classes: `ARRArenaGrid` (`Source/RogueRigs/Grid/RRArenaGrid.h/.cpp`, Blueprintable), `ERRCellType` (Floor, Void, Rock, Ore, HealOre, SpecialOre, Barrel, Spawn), `ERRTerrainDamageSource` (Drone, Barrel, Kamikaze, Shot: projectiles, barrels only), `URRBarrelSource` (`Grid/RRBarrelSource.h`: explosion source key of one barrel cell). Reads `Content/RogueRigs/Data/Levels/<LayoutName>.json` ([[level-layout-schema]]) and fills six HISMs: floor, rock, ore, heal_ore, special_ore, barrel, plus one hidden collision ISM per block type (`RockCollision`, `OreCollision`, `HealOreCollision`, `SpecialOreCollision`, `BarrelCollision`). `BP_ArenaGrid` sets layout, meshes, materials.
- build rules: origin = actor, floor top at actor Z, cell (x, y) center at ((x+0.5)·CellSize, (y+0.5)·CellSize). Floor instance (slab [-FloorThickness, 0]) only on open cells (floor, spawn); block instance only on block cells, spanning [-FloorThickness, BlockHeight] when `bBlocksFillFloorSlab` (default), else [0, BlockHeight]. No face is coplanar with another visible face. Render / collision split (task-012-01): the floor HISM renders and collides (BlockAll); the block HISMs only render (NoCollision, re-applied in `BuildInstances`); each block type's collision ISM (BlockAll, hidden, no shadow, remove-at-swap, same mesh) holds the same instances in the same order, always at the rest transform. Hits on blocks therefore report the collision ISM.
- lifecycle: built in `OnConstruction` (editor) and again in `BeginPlay`; `OnConstruction` is ignored once play has begun, so runtime destruction survives.
- properties (all editable): `LayoutName` `arena_m1`, `CellSize` 200, `BlockHeight` 100 (provisional), `FloorThickness` 200, `bBlocksFillFloorSlab` true, `MeshBaseSize` 100; health in dig-seconds at mining speed 1 (provisional): `RockHealth` 1.5, `OreHealth` 4.5, `HealOreHealth` 4.5, `SpecialOreHealth` 4.5, `BarrelHealth` 1.5; `BarrelShotHealth` 20 (shot damage units, separate from dig health; barrel gdd), `BarrelExplosionRow` `Barrel`; `ShakeAmplitude` 25 uu, `ShakeVerticalAmplitude` 8 uu, `ShakeFrequency` 8 Hz (owner feel feedback task-008-02 and task-011-01; not overridden in `BP_ArenaGrid`); drops: `OrePickupClass`, `HealPickupClass` (none; set to the pickup Blueprints), `DropInterval` 1.5 dig-seconds, `DestroyDropCount` 3 (provisional); `<Type>Mesh`/`<Type>Material`.
- entry_points: `GetCellCenter(X, Y)`, `GetCellAtWorld(FVector)`, `GetCellFaceCenter(Cell, Side)` (world center of the block face toward `Cell + Side`, at half `BlockHeight`; Side reduced to a unit step on its dominant axis), `GetCellSize()`, `GetGridSize()` (width, height in cells), `GetBlockHeight()`, `GetSpawnCell()`, `GetCellType(FIntPoint)` (current type; destroyed = Floor), `IsBlockCell(FIntPoint)`, `GetClearDistance(From, Direction, MaxDistance)` (grid line of sight on XY: exact cell traversal, distance to the first block cell entered, capped; 0 inside a block; a ray through a cell corner is blocked if either side cell is a block; void and floor never block; unscaled grid assumed), `HasLineOfSight(From, To)` (no block cell crossed, To's cell included; shotgun targets and wave clipping, [[sys-weapons]]), `GetCellHealth(FIntPoint)`, `ApplyTerrainDamage(Cell, Amount, Source)` (true when it destroyed the block), `DestroyCell(Cell, Source)`, `DestroyCellsInRadius(Center, Radius, Source)` (every block whose center is within the 2D radius, returns count), `SetCellShaking(Cell, bool)`, `GetCellShotHealth(Cell)`, `GetCellFromHit(FHitResult)` (cell of the hit block instance via the instance maps, collision ISM or block HISM, else the cell 1 uu behind the impact point along the normal), `ApplyShotDamage(Cell, Damage)` (barrels only; true when it destroyed the barrel), `GetBarrelSource(Cell)`. Delegates `OnCellDamaged(Cell, Type, Amount, Source)`, `OnCellDestroyed(Cell, Type, Source)`. Objective marks (task-016-01, [[sys-objectives]]): `SetCellMarked(Cell, bMarked)` (block cells only), `IsCellMarked`, `GetMarkedCells`, `GetMarkedCustomDataIndex`; a mark writes `MarkedCustomDataValue` (1, else 0) into per-instance custom data float `MarkedCustomDataIndex` (0; each block HISM gets index + 1 floats at build) of the block's rendering instance, for a material outline, and calls the Blueprint event `OnCellMarkedChanged(Cell, bMarked, CellCenter)`; `DestroyCell` unmarks (event with false). Marks reset on rebuild; remove-at-swap moves custom data with the instance.
- barrels: a barrel cell keeps its block HISM instance and has two healths: dig health (`BarrelHealth`, drone) and shot health (`BarrelShotHealth`, projectiles via `ApplyShotDamage`; other block types ignore shot damage). Shot health 0 destroys the cell (source Shot). Every barrel destruction, whatever the source (Shot, Drone, Barrel or Kamikaze explosion), queues `URRExplosionSubsystem::QueueExplosion(cell center, BarrelExplosionRow, grid as instigator, GetBarrelSource(Cell))` in `DestroyCell`, before `OnCellDestroyed`; never synchronous, so barrels chain one link per `ChainDelay` ([[sys-explosions]]). Source object: one `URRBarrelSource` per barrel cell, created on first request, owned by the grid (`BarrelSources` map, Transient, reset on rebuild), so it is unique, stable and alive for the world; the subsystem lets it explode once.
- drops: ore and heal ore spawn one pickup each time their accumulated damage crosses a multiple of `DropInterval` (never on the destroying hit) and `DestroyDropCount` in `DestroyCell`, whatever the source; rule detail in [[sys-pickups]].
- destruction: removes the block instance (render HISM and collision ISM at the same index), adds a floor instance, cell becomes Floor, health 0, logged Verbose by type and source. Instance maps (cell → index, index → cell per block type) serve both components of a type: they are added and removed in lockstep, both remove at swap (HISM always, the ISM through `SetRemoveSwap`), so the same index is the same cell in both. Shake moves only the rendering instance: horizontal jitter (bounded by `ShakeAmplitude`) with a vertical bob (bounded by `ShakeVerticalAmplitude`) (actor ticks only while something shakes), restored on stop; the collision instance never moves, so a shaking block never pushes the miner (`RogueRigs.Dig.ShakeKeepsCollision`).
- rules (approved): the grid is the terrain source of truth; its use for pathfinding and line of sight is provisional ([[sys-enemy-ai]]); line of sight is implemented for the shotgun. One HISM per asset type. Autotiling: 6 shapes by open sides, with variants; top face variants with random 90° rotation; neighbors re-shape on destruction. M1 grey box: one cube and one material per type ([[color-code]]).
- data: layout JSON (M1), deterministic generator (M2). Modules Json, JsonUtilities.
- depends_on: [[sys-explosions]] (barrel destruction queues into it).
- implements: [[arena-grid]], [[destruction-rules]], [[ore-blocks]], [[explosions]] (terrain side).
- gotchas: missing file or parse error logs on `LogRogueRigs` and leaves the grid empty. The layout folder must be packaged as a non-asset directory. Moving a shaking instance dirties the HISM tree each frame (fine for a few cells). The split doubles the block instance count (collision ISMs have no cluster tree and no render cost). A Blueprint that re-enables collision on a block HISM is overridden at build. Explosions call `DestroyCellsInRadius` only from `URRExplosionSubsystem` (queued, source Barrel or Kamikaze from the CSV row; [[sys-explosions]]); the run log will react to the delegates. Autotiling, top-face variants and the destroy particle burst: not implemented. Chaos Destruction is not used; terrain damage stays outside GAS.
