# Grid

- responsibility: terrain data, rendering, block health and destruction.
- main_classes: `ARRArenaGrid` (`Source/RogueRigs/Grid/RRArenaGrid.h/.cpp`, Blueprintable), `ERRCellType` (Floor, Void, Rock, Ore, HealOre, SpecialOre, Barrel, Spawn), `ERRTerrainDamageSource` (Drone, Barrel, Kamikaze, Shot: projectiles, barrels only), `URRBarrelSource` (`Grid/RRBarrelSource.h`: explosion source key of one barrel cell). Reads `Content/RogueRigs/Data/Levels/<LayoutName>.json` ([[level-layout-schema]]) and fills chunked instanced components (task-029-01): per chunk of `ChunkCells` × `ChunkCells` cells (16) and per visual type (floor, rock, ore, heal_ore, special_ore, barrel), one HISM, plus one hidden collision ISM per block type, held in `FRRGridChunkVisual` (`ChunkVisuals`, created at build when the chunk holds the type, transient). The default-subobject components (`FloorInstances`, `RockInstances`..., `RockCollision`...) are empty templates whose settings each chunk component copies. `BP_ArenaGrid` sets meshes and materials; layout and cell size come from the C++ defaults (no override in the Blueprint or in `L_ArenaM1`).
- build rules: origin = actor, floor top at actor Z, cell (x, y) center at ((x+0.5)·CellSize, (y+0.5)·CellSize). Floor instance (slab [-FloorThickness, 0]) on open cells (floor, spawn) and on barrel cells (task-108-01: a barrel stands on its slab, same floor HISM and material; the cell stays a block cell for gameplay); block instance only on block cells, spanning [-FloorThickness, BlockHeight] when `bBlocksFillFloorSlab` (default), else [0, BlockHeight]. No face is coplanar with another visible face. Render / collision split (task-012-01): the floor HISM renders and collides (BlockAll); the block HISMs only render (NoCollision, re-applied in `BuildInstances`); each block type's collision ISM (BlockAll, hidden, no shadow, remove-at-swap, same mesh) holds the same instances in the same order, always at the rest transform. Hits on blocks therefore report the collision ISM. Barrel render transform (task-107-01, `GetBlockRenderTransform`): the barrel HISM instance uses `BarrelMesh` with a uniform scale S = min(CellSize / max(bounds X, bounds Y), BlockHeight / bounds Z), its bounds bottom centre (the pivot of a bottom-pivot mesh) on the cell centre at the floor top (z = 0 always, task-108-01; task-107-01 anchored it at -FloorThickness, sunk in a floorless cell); null `BarrelMesh` or zero bounds fall back to the cube transform; shake moves around this transform. Every other block, and every collision ISM including barrels, keeps the MeshBaseSize cube transform (`GetBlockInstanceTransform`). The barrel collision ISM uses `BarrelCollisionMesh` (default `/Engine/BasicShapes/Cylinder`, the barrel shape before task-107; null falls back to `BarrelMesh`), so the decorative mesh never changes barrel collision.
- lifecycle: built in `OnConstruction` (editor) and again in `BeginPlay`; `OnConstruction` is ignored once play has begun, so runtime destruction survives.
- properties (all editable): `LayoutName` `arena_m1_fine` (240 × 240; was `arena_m1` 80 × 80, kept for the logic tests), `CellSize` 67 (was 200; task-029-04, [[arena-grid]]), `BlockHeight` 100 (provisional), `FloorThickness` 200, `bBlocksFillFloorSlab` true, `MeshBaseSize` 100; health in dig-seconds at mining speed 1 per 67 uu block (provisional, [[drone]], [[ore-blocks]]): `RockHealth` 0.5 (was 1.5), `OreHealth` 1.5 (was 4.5), `HealOreHealth` 1.5 (was 4.5), `SpecialOreHealth` 1.5 (was 4.5), `BarrelHealth` 0.5 (was 1.5, same as rock); `BarrelShotHealth` 20 (shot damage units, separate from dig health; barrel gdd), `BarrelExplosionRow` `Barrel`; `ShakeAmplitude` 25 uu, `ShakeVerticalAmplitude` 8 uu, `ShakeFrequency` 8 Hz (owner feel feedback task-008-02 and task-011-01; not overridden in `BP_ArenaGrid`); drops: `OrePickupClass`, `HealPickupClass` (none; set to the pickup Blueprints), `DropInterval` 1.5 dig-seconds (equal to the ore health, so no dig drop at 67 uu), `DestroyDropCount` 1 (was 3: one chunk per broken block, [[ore-blocks]]); `<Type>Mesh`/`<Type>Material`.
- deposits (task-070-01, [[ore-blocks]]): `FRROreTypeRow` (`Grid/RROreTypeRow.h`), one row per ore type in `Content/RogueRigs/Data/Tables/OreTypes.csv` (row name = ore id; columns `CellType`, `RockShare`, `GroupSize`, `ChunkValue`, `HealValue`, `Color`), read through `FRRBaseStatsLoader`; `Duskite` (renamed from Gold, task-100-01): Ore, 0.08, 2, 1, 0, colour alpha 0 (no colour written, the crystals keep the violet of their material; name provisional); `Heal` (task-088-02, [[heal-ore]]): HealOre, 0 (never placed: heal veins come from the layout), 2, 0, 15 HP per pickup, colour alpha 0 (no colour written, the heal material keeps its own). `BuildDeposits` runs after `LoadLayout`: layout Ore and HealOre cells become one deposit per 4-connected group, taking the first row (by id) of their block type (`arena_m1_fine`: 12 heal veins of 2 × 2, 48 cells, row `Heal`), then, when `bPlaceOreDeposits` (true), each row with a share places round(share × layout rock / size²) squares of GroupSize × GroupSize rock blocks, turned into the row CellType: anchors scored by a fixed integer hash of (x, y, `OreSeed` (1), CRC of the ore id), taken greedily while their square is still all rock, so only rock is converted (never heal ore, barrels, floor) and deposits may touch; no start-zone protection. Logged per type (`359 Duskite deposits of 2 x 2` on `arena_m1_fine`, 17 964 rock blocks after task-088-01; 44 on `arena_m1`). `FRRGridDeposit` (OreId, CellType, Cells, ChunkValue, HealValue, Color, `bHasColor`, `bPlacedFromTable`), `Deposits` (id = index), `CellDepositId` (cleared when a block breaks). Colour: block types of deposits with a row whose colour alpha is above 0 get custom data floats `OreColorCustomDataIndex` (1) to +2 = R, G, B on every instance, for the material (task-070-02). Consoles skip table deposit blocks (`ARRConsole::FindMarkableCells`, [[sys-objectives]]).
- entry_points: `GetCellCenter(X, Y)`, `GetCellAtWorld(FVector)`, `GetCellFaceCenter(Cell, Side)` (world center of the block face toward `Cell + Side`, at half `BlockHeight`; Side reduced to a unit step on its dominant axis), `GetCellSize()`, `GetGridSize()` (width, height in cells), `GetBlockHeight()`, `GetSpawnCell()`, `GetCellType(FIntPoint)` (current type; destroyed = Floor), `IsBlockCell(FIntPoint)`, `GetDepositCells(Cell, OutCells)` (C++, replaces `GetVeinCells` in task-070-01: the standing blocks of Cell's deposit, by id, Cell first; a block outside deposits gives Cell alone; a non-block nothing; used by the drone for whole-deposit mining and shake, [[sys-drone]]), `GetDepositId`, `GetDepositOreId`, `IsTableDepositCell`, `GetPlacedDepositCount(OreId)`, `GetDeposit(Id)`, `GetDepositCount`, `GetOreColorCustomDataIndex`, static `GetOreType(OreId, Row)`, `GetClearDistance(From, Direction, MaxDistance)` (grid line of sight on XY: exact cell traversal, distance to the first block cell entered, capped; 0 inside a block; a ray through a cell corner is blocked if either side cell is a block; void and floor never block; unscaled grid assumed), `HasLineOfSight(From, To)` (no block cell crossed, To's cell included; shotgun targets and wave clipping, [[sys-weapons]]), `GetCellHealth(FIntPoint)`, `ApplyTerrainDamage(Cell, Amount, Source)` (true when it destroyed the block), `DestroyCell(Cell, Source)`, `DestroyCellsInRadius(Center, Radius, Source)` (every block whose center is within the 2D radius, returns count), `SetCellShaking(Cell, bool)`, `GetCellShotHealth(Cell)`, `GetCellFromHit(FHitResult)` (cell of the hit block instance via the instance maps, collision ISM or block HISM, else the cell 1 uu behind the impact point along the normal), `ApplyShotDamage(Cell, Damage)` (barrels only; true when it destroyed the barrel), `GetBarrelSource(Cell)`. Delegates `OnCellDamaged(Cell, Type, Amount, Source)`, `OnCellDestroyed(Cell, Type, Source)`. Objective marks (task-016-01, [[sys-objectives]]): `SetCellMarked(Cell, bMarked)` (block cells only), `IsCellMarked`, `GetMarkedCells`, `GetMarkedCustomDataIndex`; a mark writes `MarkedCustomDataValue` (1, else 0) into per-instance custom data float `MarkedCustomDataIndex` (0; each block HISM gets index + 1 floats at build) of the block's rendering instance, for a material outline, and calls the Blueprint event `OnCellMarkedChanged(Cell, bMarked, CellCenter)`; `DestroyCell` unmarks (event with false). Marks reset on rebuild; remove-at-swap moves custom data with the instance.
- barrels: a barrel cell keeps its block HISM instance and has two healths: dig health (`BarrelHealth`, drone) and shot health (`BarrelShotHealth`, projectiles via `ApplyShotDamage`; other block types ignore shot damage). Shot health 0 destroys the cell (source Shot). Every barrel destruction, whatever the source (Shot, Drone, Barrel or Kamikaze explosion), queues `URRExplosionSubsystem::QueueExplosion(cell center, BarrelExplosionRow, grid as instigator, GetBarrelSource(Cell))` in `DestroyCell`, before `OnCellDestroyed`; never synchronous, so barrels chain one link per `ChainDelay` ([[sys-explosions]]). Source object: one `URRBarrelSource` per barrel cell, created on first request, owned by the grid (`BarrelSources` map, Transient, reset on rebuild), so it is unique, stable and alive for the world; the subsystem lets it explode once.
- drops: ore and heal ore spawn one pickup each time their accumulated damage crosses a multiple of `DropInterval` (never on the destroying hit) and `DestroyDropCount` in `DestroyCell`, whatever the source, each with the ore value (`ChunkValue`, 1 without a row) and heal value (`HealValue`, 0 without a row: pickup default) of its deposit, requested from `URRPickupSubsystem::RequestSpawn` (4 per frame, rest queued); rule detail in [[sys-pickups]].
- destruction: removes the block instance (render HISM and collision ISM at the same index), adds a floor instance only when the cell has none (`CellFloorInstanceIndex` is INDEX_NONE; a barrel keeps its slab, so no duplicate), cell becomes Floor, health 0, logged Verbose by type and source. Instance maps: two cell → index arrays, `CellInstanceIndex` (block instances) and `CellFloorInstanceIndex` (floor instances), chosen by visual type (`GetInstanceIndexMap`), since a barrel cell is in both visuals; plus index → cell per chunk visual (`InstanceCells`); they serve both components of a chunk visual: they are added and removed in lockstep, both remove at swap (HISM always, the ISM through `SetRemoveSwap`), so the same index is the same cell in both. Shake moves only the rendering instance: horizontal jitter (bounded by `ShakeAmplitude`) with a vertical bob (bounded by `ShakeVerticalAmplitude`) (actor ticks only while something shakes), restored on stop; the collision instance never moves, so a shaking block never pushes the miner (`RogueRigs.Dig.ShakeKeepsCollision`).
- rendering (task-029-01): no grid component affects navigation (no navmesh; a navigation-relevant ISM recomputed its bounds over all instances on each add or remove). `bGridAffectsDistanceFields` (true; false keeps chunk HISMs out of the mesh distance field scene, measured no gain once chunked). A destruction touches the rock (or other block) chunk and the floor chunk of its cell only. Measurements: [[stress-grid-cells]].
- rules (approved): the grid is the terrain source of truth; its use for pathfinding and line of sight is provisional ([[sys-enemy-ai]]); line of sight is implemented for the shotgun. One HISM per asset type per chunk. Autotiling: 6 shapes by open sides, with variants; top face variants with random 90° rotation; neighbors re-shape on destruction. M1 grey box: one cube and one material per type ([[color-code]]).
- data: layout JSON (M1), deterministic generator (M2). Modules Json, JsonUtilities.
- depends_on: [[sys-explosions]] (barrel destruction queues into it).
- implements: [[arena-grid]], [[destruction-rules]], [[ore-blocks]], [[explosions]] (terrain side).
- gotchas: missing file or parse error logs on `LogRogueRigs` and leaves the grid empty. The layout folder must be packaged as a non-asset directory. Moving a shaking instance dirties the HISM tree each frame (fine for a few cells). The split doubles the block instance count (collision ISMs have no cluster tree and no render cost). A Blueprint that re-enables collision on a block HISM is overridden at build. Explosions call `DestroyCellsInRadius` only from `URRExplosionSubsystem` (queued, source Barrel or Kamikaze from the CSV row; [[sys-explosions]]); the run log will react to the delegates. Autotiling, top-face variants and the destroy particle burst: not implemented. Chaos Destruction is not used; terrain damage stays outside GAS.
