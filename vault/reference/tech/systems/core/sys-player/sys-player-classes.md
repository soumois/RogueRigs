# Player — classes

  - `ARRMiner : ACharacter, IAbilitySystemInterface` (`RRMiner.h`): `URRAbilitySystemComponent` plus `URRHealthAttributeSet`, `URRMovementAttributeSet`, `URRPlayerAttributeSet` as default subobjects (registered by the ASC's `InitializeComponent`), and `URRProgressionComponent` `Progression` (`GetProgression()`, [[sys-progression]]), `URRUpgradeComponent` `Upgrades` (`GetUpgrades()`, [[sys-upgrades]]), `URRLevelUpComponent` `LevelUp` (`GetLevelUp()`, [[sys-level-up]]). Spring arm with absolute rotation (never turns with the pawn) and camera. Editable: `BaseStatsRowName` (`Miner`), `CameraPitch` (−50), `CameraYaw` (0), `CameraArmLength` (1700), `bCameraLag` (false: no spring-arm lag, the miner stays centered; lag speed 0.5 when on), `CameraFieldOfView` (75), `AimRotationInterpSpeed` (0 = instant), `MouseAimPlaneHeight` (0), `StickAimMinInput` (0.1), `DroneClass` (none; set to the drone Blueprint), `DigContactMargin` (10 uu, provisional, task-029-05; replaces `DigReachMargin`), `DigMinMoveInput` (0.1, provisional; below it the input does not steer the dig arc), `StartingWeapons` (array of `ARRWeapon` classes, empty; `BP_Miner`: the burst rifle only since task-024-04), `GuaranteedWeaponClasses` (empty by default: each class spawned after `StartingWeapons` unless an entry of `StartingWeapons` is that class or a subclass), `WeaponCatalogue` (`FRRWeaponCatalogueEntry` list offered by new-weapon cards, [[sys-upgrades]]; native defaults `ARRShotgun`, `ARRTurretLauncher` with provisional French descriptions; `BP_Miner` lists the Blueprints), `MaxWeapons` (4), `WeaponAttachSocketName` (none = attach to the capsule, which turns with the aim yaw), `WeaponAttachOffset` ((0, 20, −40) uu from the capsule center, X forward, Y right; used only when the socket is none). Damage: `IFramesDuration` (0.25 s), `IFramesEffectClass` (`URRGE_IFrames`), `BlinkRate` (12 Hz, full hide/show cycles). Holds the spawned drone in `Drone` (`GetDrone()`) and the arena grid in `ArenaGrid` (`GetArenaGrid()`). Movement defaults (gravity 1.5, acceleration 1000, no ledge walk-off) are component properties, editable in Blueprint.
  - `ARRPlayerController` (`RRPlayerController.h`): editable `DefaultMappingContext`, `MappingContextPriority`, `MoveAction`, `StickAimAction`, `MouseAimAction`, `PlaceTurretAction` (Boolean, bound on Started → `ARRMiner::PlaceTurret`), `PlaceTurretKeys` (E, right mouse button, gamepad face button bottom), `bHideCursorWhileStickAiming`. While `PlaceTurretAction` is unset, a transient action mapped to `PlaceTurretKeys` lives in a transient mapping context added at `MappingContextPriority` + 1, so the button works without assets; once the asset is set its keys come from `DefaultMappingContext`. Cursor shown by default. HUD: editable `HUDWidgetClass` (none; set to the HUD widget Blueprint); `BeginPlay` creates it for a local player only and binds it, `OnPossess` rebinds it to the new miner; `GetHUDWidget()` ([[sys-hud]]).
  - `ARRGameMode : AGameModeBase` (`RRGameMode.h`): default pawn and controller classes set in Blueprint. Game over: `RegisterMiner(ARRMiner*)` (called by the miner `BeginPlay` when the auth game mode is an `ARRGameMode`) binds the miner `OnDeath`; the first death disables the input of every player controller (`DisableInput`), broadcasts `OnGameOver` (BlueprintAssignable) once and arms a timer that reopens the current level (`UGameplayStatics::OpenLevel` on `GetCurrentLevelName`) after editable `RestartDelay` (3 s, miner gdd M1). `IsGameOver()`, `GetRestartDelay()`, `GetRestartTimeRemaining()` (−1 when not armed). `EndPlay` clears the timer.
