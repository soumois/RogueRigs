# Automation tests — progression

Part of [[sys-automation-tests]] (harness, command and gotchas live there).

- `RogueRigs.Integration.LevelUpUpgradeLoop` (task-014-05; `StartGameMode`, armed `BP_Miner` on (32, 42) possessed by `BP_RRPlayerController` (gets a player state, no HUD: no local player), `BP_EnemySpawner` held off, `WBP_HUD` created on the world and bound to the miner, upgrade seed 6): five `BP_Chaser` killed by the rifle, Health set to 50, cubes collected: level 2, Health 70, one effect, delay running, no pause; the spawner is then enabled. Screen opens 48 frames (0.800 s) later: world and controller paused, cursor shown, 3 valid cards with reroll; `UpgradeScreen` Visible, `RerollButton` enabled, `CardName0..2` = card names. 60 paused frames: game time, spawner run time, robot count, rifle shots and miner position unchanged. `HUD->RequestReroll` with 10 carried + 20 secured ore (task-315-01): cost 15, carried 0 then secured 15, next cost 20, new cards sharing no stat and target with the first, second reroll not affordable and refused (nothing spent), button disabled. `HUD->ChooseUpgrade` on the damage card (Dégâts, Toutes les armes, +5 %): rifle Damage 10 → 10.5, closed once, `UpgradeScreen` Collapsed, world resumed; 90 frames later 1.5 s of game time, spawner run time 2.3 s and one robot spawned (director off since task-026-01: older 2 s timers), rifle firing (6 shots).
- `RogueRigs.Progression.*` (`BP_Miner` on (42, 38), weapons stopped; each checks level 1, 0 XP, need 4 (task-033-01 curve), level 2 need 20, level 10 need 64, level 50 need 440, CSV XPGain 1) ([[sys-progression]]): `ExactLevel` (4 XP → level 2, 0 carried, need 20, one level-up (2), one XP event (0, 20, 2); 0 and −3 ignored); `CarryOverMultiLevel` (26 XP → level 3, 2 carried, need 25, level-ups 2 then 3, one XP event (2, 25, 3)); `RogueRigs.LevelUp.*` and `Integration.LevelUpDiscEndsHidden`, `RifleKillsFiveChasersLevelUp` compute their XP from the curve rows (task-028-03; task-030-02: the five-chaser tests `RifleKillsFiveChasersLevelUp` and `LevelUpUpgradeLoop` leave level 1 exactly 5 raw XP short (pre-fill when need(1) ≥ 5, else XPGain = need(1) / 5; task-031-03), `Cheats.*` grant 4, `Extraction` and the fractional-cube check of `PickupMotion` read the need); `XPGainScales` (XPGain base 2: raw 0.25 → 0.5 XP at level 1; raw 2 more → level 2 with 0.5 carried, one level-up); `XPPickupAddsOne` (XPGain 0.5; `BP_PickupXP` 100 uu from the possessed miner, pop yaw forced to 270 so it lands within 120 uu, inside the 300 uu `PickupRadius` (task-057-01: a random yaw away from the miner with a draw over 200 uu landed up to 320 uu off and rested uncollected, 2.3 % of draws by Monte Carlo); collected once, XP 0.5, level 1, XP event (0.5, 4, 1)).
- `RogueRigs.Upgrades.*` (`BP_Miner` on (42, 38), weapons stopped, its `BP_BurstRifle`, seed 20261003) ([[sys-upgrades]]): `ValueLookup` (55 values per tier, targeted = 1.5 × global, no magazine row; card texts "Dégâts", "Toutes les armes", "+25 %", "+15 %", "Fusil à rafales", "+45", "+8 %" (task-028-01 values), "PV max"; mismatched targets refused); `RarityDistribution` (20000 draws: luck 0 within 1.5 points of 50 / 30 / 13 / 5 / 2 %, measured 50.5 / 29.1 / 13.3 / 5.2 / 2.0; luck 10 near 21.4 / 25.6 / 22.2 / 17.1 / 13.7 %, mean rank up by > 0.5); `OfferTargets` (300 offers at luck 0–10: always 3 cards, no magazine card, no shared stat and target, weapon cards only on all weapons or the owned rifle (481 player, 209 all-weapons, 210 rifle cards); an unowned rifle's card is refused, its damage untouched); `DamageAppliesToRifle` (global +25 %: 10 → 12.5, base unchanged, offer ended; targeted fire rate +37.5 %: 1.25 × 1.375; move speed +10 %: 660); `MaxHealthRaisesHealth` (+45: 100/100 → 145/145; at Health 50: 190/95); `PercentStacking` (2 × +25 % → 15, + targeted 37.5 % → 18.75; crit damage 1.5 + 0.3 = 1.8; luck 3 + 1); `RerollRepeat` (renamed from `RerollOnce`, task-315-01: none without an offer; 50 offers: first reroll gives 3 cards sharing no stat and target, a second reroll is accepted and shares none with the first reroll; none after picking); `ReplayOnAcquire` (a rifle acquired later gets the global damage (12.5), not the first rifle's targeted fire rate).
- `RogueRigs.LevelUp.*` (`BP_Miner` on (42, 38), weapons stopped, seed 20261003; checks delay 0.8 s, heal 0.2; no player controller, so the flow state stands for the pause) ([[sys-level-up]]): `HealClampedToMax` (50 → 70 at level 2, effect event (2), delay running, no offer; 95 → 100 clamped; two levels in one call 40 → 80, four choices owed); `PauseAfterDelay` (47 frames (0.78 s): no screen, no offer built; 50 frames: screen open, one offer of 3 cards with reroll; index 3 refused; 30 carried ore: reroll costs 15, accepted, 15 ore left, next cost 20, shown again without an affordable reroll, refused, nothing spent); `ChainedOffers` (17 XP: two screens in sequence, 35 carried ore, one reroll (15) on the first screen (next cost 20), the second screen at once after the first pick with the cost back to 15 and an affordable reroll, closed once after the second; a level gained 20 frames into a delay joins it, the screen opens 50 frames after the first); `ChoiceResumes` (pick and reroll refused without a screen; picking card 1 closes once, ends the offer, applies that card; a later level runs the delay and screen again).
