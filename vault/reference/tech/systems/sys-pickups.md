# Pickups

- responsibility: the pickup actor (pop, attraction, collection) and the drop rule of ore and heal ore blocks. XP pickups add XP on collection; no heal or ore effect yet: those only log and broadcast.
- main_classes: `ARRPickup` (`Source/RogueRigs/Pickups/RRPickup.h/.cpp`, `Abstract`, Blueprintable), `ERRPickupType` (Ore, Heal, XP), `ERRPickupPhase` (Pop, Rest, Magnet, Collected); `URRPickupSubsystem` (`Pickups/RRPickupSubsystem.h/.cpp`, `UTickableWorldSubsystem`, Game and PIE worlds, pauses with the world) moves every pickup in one loop per frame: player 0 pawn and its `PickupRadius` read once, then `ARRPickup::UpdateMotion` per pickup (actor tick off; on only when the subsystem is missing). No physics, no collision: root `PickupMesh` `NoCollision`, no overlap, no navigation. Blueprint subclasses set `PickupType` and the mesh.
- lifecycle (task-027-01, DRGS-like, [[xp-level-up]]): spawned at a cell center (grid) or at robot feet (XP). Pop: random yaw (or `SetPopYaw` before BeginPlay), distance random in [`PopMinDistance`, `PopMaxDistance`]; horizontal ease-out over `PopDuration`; vertical main arc of `PopArcHeight` from spawn Z to spawn Z + `HoverHeight` over the first 1 - `PopBounceFraction` of the pop, then a bounce of `PopBounceHeight`. Rest: `AttractDelay` from the end of the pop, never attracted meanwhile. Magnet: first frame after the rest with the 2D distance to the miner within its `PickupRadius`: latches (keeps flying even if the miner leaves the radius), `OnMagnetStart`, speed starts at `MagnetStartSpeed` and gains `MagnetAcceleration` per second up to `MagnetMaxSpeed` (applied before each step), straight 3D line to the miner; nearby cubes latch together and form a stream. Collect within `CollectDistance` (or when the step reaches it): Verbose log; an XP pickup calls `AddXP(XPAmount)` ([[sys-progression]]); `ARRMiner::NotifyPickupCollected(Type, Location)` broadcasts `OnPickupCollected(Type)` then `OnPickupCollectedAt(Type, Location)`; Blueprint event `OnCollected(Location)`; destroy.
- properties (all `EditDefaultsOnly`, provisional, task-027-01 values): `PickupType` Ore, `XPAmount` 1 (set per cube by the robot), `PopMinDistance` 80 uu, `PopMaxDistance` 220 uu, `PopDuration` 0.35 s, `PopArcHeight` 80 uu, `PopBounceHeight` 15 uu, `PopBounceFraction` 0.25, `HoverHeight` 30 uu, `AttractDelay` 1.0 s, `MagnetStartSpeed` 400 uu/s, `MagnetAcceleration` 4000 uu/s2, `MagnetMaxSpeed` 2500 uu/s, `CollectDistance` 50 uu. Measured at 60 fps: arc peak 95 uu, bounce peak 45 uu, rest at 0.350 s; first magnet frame 466.7 uu/s, cap 2500.
- XP drop: `ARREnemy::DropXP` bursts `XPCubeCount` cubes of its `XPPickupClass` at its feet after the death shrink (chaser 3, kamikaze 4, shooter 6, heavy 12, set in each constructor; 0 = one per XP point), each worth `Stats.XPValue / XPCubeCount` so the values add up to the robot XP, spawned deferred with `SetXPAmount` and `SetPopYaw` = random start + index x 360 / N, jittered by a quarter spacing ([[sys-enemies-base]]); tests use the native `ARRTestPickupXP`.
- drop rule (in `ARRArenaGrid`, see [[sys-grid]]): `OrePickupClass` for Ore, `HealPickupClass` for HealOre; other types drop nothing. Per cell the grid counts dig drops already spawned (`CellDigDrops`). After each `ApplyTerrainDamage` that leaves the block standing, crossed = floor((max health − health) / `DropInterval`), capped at the number of multiples strictly below max health; the difference with the count is spawned. The destroying hit spawns no dig drop; `DestroyCell` spawns `DestroyDropCount`, whatever the source. Defaults at 67 uu (task-029-04): ore and heal ore health 1.5 = interval 1.5, so no dig drop and 1 pickup at destruction (one per broken block, [[ore-blocks]]); a heal cluster of 3 × 3 gives 9 (one 200 uu heal block gave 5). The former 4.5 health with 3 at destruction gave drops at 1.5 and 3.0, then 3 (5 total).
- entry_points: `ARRPickup::GetPickupType`, `GetPhase`, `IsMagnetized`, `GetMagnetSpeed`, `GetXPAmount` (BlueprintPure), `SetXPAmount`, `SetPopYaw`, `GetPopStart`, `GetPopEnd`; Blueprint events `OnMagnetStart()` (trail on) and `OnCollected(Location)` (detached sparkle); `URRPickupSubsystem::GetPickupCount`, `GetMagnetizedCount`, stat `RR Pickups Tick`; `ARRMiner::GetPickupRadius()`, `OnPickupCollected`, `OnPickupCollectedAt` ([[sys-player]]).
- data: `PickupRadius` from `PlayerBaseStats.csv` ([[sys-gas-core]]); drop tunables on the grid Blueprint.
- depends_on: [[sys-grid]], [[sys-player]], [[sys-gas-core]].
- implements: [[ore-blocks]], [[heal-ore]], [[ore-economy]] (drops only), [[player-stats]] (pickup radius).
- gotchas: one subsystem loop and one 2D distance per resting pickup per frame; no pooling (tests count live `ARRPickup` actors). Stress S7 burst of 400 chasers (1200 cubes, task-027-01): avg 9.19 ms, p99 11.34 ms; the single burst frame (400 deaths + 16 barrels) 109 ms max, the known per-death burst cost. Grid ore and heal chunks use the same 80-220 uu pop: at 67 uu cells a chunk can rest over unbroken rock for its 1 s rest (a Blueprint can lower `PopMaxDistance`). A single hit that both crosses a multiple and destroys the block gives no dig drop for that multiple. Ore value and heal amount: open. Pickups spawn only in a game world.
