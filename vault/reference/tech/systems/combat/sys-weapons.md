# Weapons

- responsibility: weapon lifecycle, weapon stats, how upgrades reach weapons and turrets.
- main_classes (in `Source/RogueRigs/Weapons/`): `ARRWeapon` (abstract; own `URRAbilitySystemComponent` + `URRWeaponAttributeSet`, root scene component, `Muzzle` scene component under it (since task-412-01 the shot origin of every weapon of a miner holding a hand weapon, see Shot origin below), editable `HandSocketName` (`FName`, EditDefaultsOnly, BlueprintReadOnly, category `Weapon|Attach`, default none; `GetHandSocketName()` BlueprintPure; task-400: the miner mesh socket this weapon snaps to), no actor collision (`bActorEnableCollision` off: a held weapon sits inside the miner capsule and would push it), `URRAutoFireComponent` [[sys-auto-fire]]; protected virtual `FireOnce()` decides what is fired: by default the burst rifle shot, overridden by weapons that fire differently); `URRWeaponAttributeSet` (`Damage`, `FireRate`, `ReloadSpeed`, `CritChance`, `CritDamage`, `MagazineSize`, `Ammo`, `Pierce`; all >= 0, `Ammo` <= `MagazineSize`, lowered when `MagazineSize` drops); `FRRWeaponStatsRow`; GEs `URRGE_ConsumeAmmo` (instant, `Ammo` -1) and `URRGE_RefillAmmo` (instant, `Ammo` overridden by the target's `MagazineSize`); `ARRShotgun` (Blueprintable, usable natively: `StatsRowName` `Shotgun`, `ProjectileClass` default `ARRShotgunPellet` [[sys-projectiles]]). Weapons: burst rifle (implemented in `ARRWeapon`), shotgun (implemented), turret launcher `ARRTurretLauncher` and turrets `ARRTurret` (implemented, [[sys-turret]]). `GetProjectileClass()` / `GetDamageEffectClass()` are public (a turret copies its launcher's).

## Decisions
- One ASC per weapon; upgrades routed by `Weapon.Player.*` tags (approved).
- Magazine and reload by GEs `ConsumeAmmo`, `Reloading`, `RefillAmmo` (approved). Implemented: `ConsumeAmmo`, `RefillAmmo`; the reload is a timer in [[sys-auto-fire]]; `Reloading` (duration GE + tag) waits for the tag hierarchy (open).
- Acquisition order (provisional): spawn and attach → `InitAbilityActorInfo(weapon, weapon)` → base values from CSV (`SetNumericAttributeBase`) → replay of global upgrades → registration in the player's registry.
- Global bonuses are broadcast to every weapon ASC, replayed on acquisition, never removed; the list of applied upgrades serves replay and debug (provisional).
- Player-state conditions (death, level transition) are read on the player's ASC; weapon ASCs do not carry those tags (provisional).
- 4-direction fire is a fire pattern inside `FireOnce()` (main shot + 3 weaker ones), not a projectile behavior (provisional).
- Burst rifle `FireOnce()` (implemented in `ARRWeapon`): `MakeDamageSpec()` (editable `DamageEffectClass`, default `URRGE_Damage`, context instigator and causer = the weapon), then one editable `ProjectileClass` spawned deferred through `SpawnShot` at `GetShotPlacement()` (Shot origin below), flat, aim yaw + uniform random in ±`SpreadDeg`, speed `ProjectileSpeed`, lifetime `Range / ProjectileSpeed`, `MaxHits` = `GetPierceCount()`; Owner = weapon, Instigator = miner ([[sys-projectiles]]). Skipped with a warning if `ProjectileClass` is unset or `ProjectileSpeed`/`Range` <= 0. The Blueprint subclass sets `ProjectileClass`, the mesh and the `Muzzle` position.
- Shot origin (task-412-01, commit e1e65788; owner principle: only the player's first weapon, the burst rifle, is shown, every other player weapon shoots from its Muzzle; the demo starts with the rifle). `GetShotPlacement()` returns `FRRShotPlacement` {`Origin`, `CapsuleHalfHeight`, `bSweepFromMiner`, `SweepStart`}, read at fire time (the Muzzle follows the hand animation, [[sys-player-classes]]). Floor = capsule bottom minus the CharacterMovement floor distance when walking (`GetFloorZUnderMiner`). Rule: with an owning miner holding a weapon on its hand socket (`IsHeldOnHandSocket`, found by `FindHandWeapon`), every weapon of that miner (rifle, shotgun, future ones) shoots from that hand weapon's `Muzzle` world location, capsule centred on it, half height = Muzzle Z - (floor Z + `ShotFloorClearance`), so bottom at floor + 20 and top about 2 x Muzzle height - 20 ([[sys-projectiles]]). `ShotFloorClearance` is EditDefaultsOnly, 20 uu (warning at acquisition if not below the grid `BlockHeight`; `ShotHeight` 50 must also stay below it). Q3: the projectile spawns on the miner axis XY at that height, then one `SweepTo(Muzzle)` (protected `SpawnShot`). Fallbacks: Muzzle below floor + clearance + radius -> sphere at floor + `ShotHeight` (50 uu) under the Muzzle, still swept, warning once per weapon; miner without hand weapon -> the old point (floor + `ShotHeight`, moved along the aim by capsule radius + `ShotForwardOffset` 20 uu) and sphere, no sweep; no miner (tests) -> own `Muzzle`, sphere, no sweep. `GetShotOrigin()` returns `GetShotPlacement().Origin` with a miner; turrets override it ([[sys-turret]], unchanged).
- First drawn frame (task-413-01, commit 148676a4): in `SpawnShot`, when `Placement.bSweepFromMiner` and `SweepTo` returned true, the shot calls `ARRProjectile::HoldFirstMove()` so it is first drawn at the Muzzle, not `speed x dt` ahead; rifle and shotgun pellets share it, turret and robot shots are not held. Rule, cause and measure: [[sys-projectiles]].
- Muzzle flash (task-414-02, commit 743a05e2): `MuzzleFlashSystem` (`TObjectPtr<UNiagaraSystem>`, EditDefaultsOnly, BlueprintReadOnly, category `Weapon|FX`) defaults by constructor path to `/Game/RogueRigs/FX/NS_MuzzleFlash` ([[bp-muzzle-flash]]), so `BP_BurstRifle` is unchanged; `BP_Shotgun` overrides it with `NS_MuzzleFlashShotgun` (task-440, larger). Protected `SpawnMuzzleFlash(ShotRotation)` attaches it to the hand weapon `Muzzle` (`FindHandWeapon()->GetMuzzle()`), world rotation = shot direction, auto-destroy, no pool. Rifle: one per bullet in `FireOnce` (3 per burst) when `SpawnShot` returned a projectile; shotgun: one per volley ([[sys-weapons-shotgun]]); turret: `MuzzleFlashSystem` = nullptr, so C++ spawns none, and `BP_Turret` spawns the green `NS_MuzzleFlashTurret` itself on `OnTurretFired` at its Muzzle, scale 0.6 (task-464-04, [[bp-turret]]; its own copy since task-476-01, when the rifle `NS_MuzzleFlash` shrank x0.7, [[bp-muzzle-flash]]); the rifle flash is green since task-464-03 (`M_MuzzleFlashGreen`), the shotgun flash stays white-gold; null system or `!FApp::CanEverRender()` (-nullrhi) spawns nothing.
- Light aim assist (task-463-01, commit d7210d03): `FireOnce` passes each bullet rotation, after the spread, through `GetAimAssistedRotation`; rules, data and test in [[sys-weapons-aim-assist]]. Burst rifle only; 0 in `AimAssistDeg` turns it off.
- Pierce (task-024-01): attribute `Pierce` = distinct robots one projectile damages (rifle base 4, [[burst-rifle]]); `GetPierceCount()` = `Pierce` rounded down, at least 1, read at fire time, so upgrades apply to the next bullet. Raised by piercing upgrades ([[sys-upgrades]]). The shotgun row holds 3 for its pellets ([[shotgun]]).
- Reload duration = base `ReloadTime` (CSV) / `ReloadSpeed`.
- Turret launcher: `MagazineSize` = turret charges; placing a turret starts recharging that charge at `ReloadSpeed`, one charge at a time; no cap on active turrets.
- Impact effects are weapon attributes (e.g. `StunChance`, `StunDuration`), changed by ordinary upgrade GEs; an effect is active when its attribute is above 0 (provisional).
- Turrets: at placement, copy every attribute of the turret launcher, impact effects and `Projectile.Behavior.*` tags included (provisional). A turret's specs have the turret as instigator.

- Hand socket (task-400-01): `ARRMiner::AddWeapon` attaches per weapon. `HandSocketName` set and the miner mesh `DoesSocketExist` -> `SnapToTargetNotIncludingScale` to it; set but missing -> `LogRogueRigs` warning and the shared path; none -> the shared path (miner `WeaponAttachSocketName` on the mesh, else the capsule at `WeaponAttachOffset`, [[sys-player-classes]]). Burst rifle `BP_BurstRifle` = `WeaponSocket_R` ([[bp-burst-rifle]]); shotgun and turret launcher keep none. The shot origin is the hand weapon Muzzle since task-412-01 (rule above). Test `RogueRigs.Weapons.MinerStartingWeapon` has two attach branches (hand socket on the mesh, else capsule).
- aim seam (task-020-02): `GetAimDirection` and `GetShotOrigin` are virtual (a turret overrides them); `FireOnce` spawns through `ARRProjectile::SpawnProjectile` ([[sys-projectiles]]).
- entry_points: `ARRWeapon::Acquire(Miner)`, called by the miner after spawn and attach ([[sys-player]]): `InitAbilityActorInfo(weapon, weapon)`, base values from CSV row `StatsRowName` (editable, set in Blueprint), magazine filled, auto-fire configured (ticks after the miner) and started if `bStartFiringOnAcquire`. Upgrade replay: after the base values, the owning miner's all-weapons upgrades are re-applied ([[sys-upgrades]]). Player registry: not implemented. `GetDisplayName()` (CSV `DisplayName`, or the row name). `GetAimDirection()` = owning miner's aim (weapon forward without miner). `GetShotOrigin()`, `GetShotPlacement()`, `GetShotHeight()`, `GetShotForwardOffset()`, `GetShotFloorClearance()`. Getters for the CSV constants. `ApplyStatsRow` is virtual (the shotgun copies `PelletCount`, `KnockbackForce`; getters `GetPelletCount`, `GetKnockbackForce`).
- data: `Content/RogueRigs/Data/Tables/WeaponStats.csv`, read at runtime with `FRRBaseStatsLoader::FindRow` (cached); row `BurstRifle` = [[burst-rifle]] values; column `Pierce` (attribute: rifle 4, shotgun 3); row `Shotgun` = [[shotgun]] values (damage 10 per pellet, `FireRate` 2 = 0.5 s between shots, `BurstCount` 1, crit 0.05 / 1.5, magazine 2, reload 2.5 s, `Range` 700, `SpreadDeg` 15, `PelletCount` 7, `KnockbackForce` 250 uu/s, `Pierce` 3; `ProjectileSpeed` 3000 is not in the gdd: provisional, copied from the rifle); column `DisplayName` is the French UI name (`Fusil à rafales`, `Fusil à pompe`, working names). Attribute columns become base values; `BurstCount`, `BurstDuty`, `ReloadTime`, `ProjectileSpeed`, `Range`, `SpreadDeg` (rifle: random half-angle; shotgun: fan half-angle), `PelletCount` (1 on the rifle), `KnockbackForce` (launch speed per hit before resistance; 0 on the rifle), `AimAssistDeg` (largest aim assist turn, 0 = none, [[sys-weapons-aim-assist]]) stay constants on the weapon.
- depends_on: [[sys-gas-core]], [[sys-projectiles]], [[sys-player]] (aim).
- implements: [[burst-rifle]], [[shotgun]], [[turret]], [[upgrades]].
- loadout (task-024-04): the miner starts with the burst rifle only (`StartingWeapons`, `GuaranteedWeaponClasses` empty); the shotgun and turret launcher come from new-weapon cards ([[sys-upgrades]]) through the miner's `WeaponCatalogue` of `FRRWeaponCatalogueEntry` (`WeaponClass`, French `Description`; `Weapons/RRWeaponCatalogueEntry.h`) and `MaxWeapons` 4 ([[sys-player]]). `ARRWeapon::GetClassDisplayName(Class)` reads the CSV `DisplayName` of a class default object's `StatsRowName` (card name before any instance exists).
- gotchas: knockback is a launch speed in uu/s; pellets hitting a robot in the same frame add up (`ApplyKnockback` keeps the pending launch); ground friction brakes it within a few frames (measured: 250 uu/s gives +12 uu in 3 frames). `AbilitySystem.DebugAttribute FireRate Damage` shows values above each weapon actor. Turret stats are frozen by attribute copy, not by spec snapshot.
