# Run — level transition

- responsibility: chain the levels of a run ([[intermission]], [[run-structure]]): intermission on a level 1-3 extraction, Continue, map travel, gameplay held behind the loading screen until the level is ready, run won on level 4, run reset on restart.
- main_classes: `URRRunTransitionSubsystem` (`Source/RogueRigs/Run/RRRunTransitionSubsystem.h`, `UGameInstanceSubsystem`); `FRRIntermissionRecap`, `ERRRunTransitionPhase` (None, Intermission, Loading), `ERRRunLoadingStage` (None, WaitingForLayout, OpeningMap, PreparingLevel); widget bases `URRIntermissionWidget`, `URRLoadingScreenWidget` (`UI/`, Abstract); widgets created by `ARRPlayerController` ([[sys-hud-bindings]]).
- entry_points (sequence):
  1. `URRRunFlowSubsystem::EndRun(true)` (run log level entry, ore secured, game paused, Game and UI input) calls `HandleLevelExtracted(Miner)`. Run in progress: phase Stats, `OnIntermissionStarted(Recap)` (stats screen), `OnRunEnded` not broadcast. Levels 1-3: `CaptureLevelEndSnapshot`, `AdvanceToNextLevel` first (next layout requested at once, [[sys-run-layout]]). Last level (task-317-01): `IsRunWon` and `Recap.bRunWon` true, no snapshot. The recap reads the run log's current level counters ([[sys-run-log]]) before the next level resets them. No run (direct PIE, test worlds): false, `OnRunEnded(true)` as before.
  2. `NextLevel()` (BlueprintCallable, Stats phase only, task-317-01). Levels 1-3: `URRIntermissionShopSubsystem::OpenShop(Miner)`, phase Shop, `OnShopScreenStarted`. Last level: `OnRunWonScreenStarted`, phase None, `URRRunFlowSubsystem::ShowRunWonEndScreen()` broadcasts `OnRunEnded(true)` (existing run won end screen in WBP_HUD); no shop.
  3. `Continue()` (BlueprintCallable, Shop phase only): shop closed, phase Loading, `OnLoadingStarted(LevelIndex, LayoutName)`; layout pending: stage WaitingForLayout until `OnLayoutReady`; then stage OpeningMap and the paint wait (below), then `OpenLevel(URRRunSettings::ArenaMapName, empty = current map)`; a failed layout logs an error and travels (grid fallback, provisional).
  4. `PostLoadMapWithWorld` (after every BeginPlay: grid built from the prepared layout, snapshot re-applied; before the first tick): stage PreparingLevel, logs the grid layout and size; run flow `SetRunFlowEnabled(false)`, spawner `SetSpawningHeld(true)`, controller ignores move, aim and turret input (`IsGameplayInputHeld`).
  5. Spawner `OnPoolPrewarmFinished` ([[sys-spawner-pool-prewarm]]; at once without spawner or prewarm; `LoadingHoldTimeoutSeconds` 10 safety, provisional): released, phase None, `OnLevelReady(LevelIndex, LayoutName)`; the alert bar starts.
- Shop (task-316-01, task-317-01): opened by `NextLevel` (levels 1-3), closed by `Continue` and `ClearTransition` (run reset). Offer, prices, buy, reroll: [[sys-run-shop]].
- Binding API for the bp widgets (task-206-04, 206-05, 317-01): controller class properties `IntermissionWidgetClass` (stats screen), `ShopScreenWidgetClass` (cards screen), `LoadingScreenWidgetClass` (category HUD|Run Transition, Z-order `TransitionWidgetZOrder` 50, loading 51). The controller creates the stats widget on `OnIntermissionStarted`, swaps it for the shop widget on `OnShopScreenStarted`, removes it and restores the HUD on `OnRunWonScreenStarted`, removes both on `OnLoadingStarted`.
  - `URRIntermissionWidget` (stats): implement `OnRecapShown(FRRIntermissionRecap)`; Next level button calls `NextLevel()`; pure `GetRecap()`, `IsRunWonRecap()`. Legacy, kept for the old WBP_Intermission: `Continue()` (NextLevel in Stats, else Continue), `GetShop()`, `OnShopRefreshed`.
  - `FRRIntermissionRecap` {bRunWon, FinishedLevelIndex, NextLevelIndex (0 when won), LevelCount, OreSecuredThisLevel, RunSecuredOre, NextLayoutName (empty when won), KillsByRobotType (TArray `FRRRecapRobotKills` {RobotType FName, DisplayName FText, Count}, most first), TotalKills, DamageByWeapon (TArray `FRRRecapWeaponDamage` {WeaponClassName FName, DisplayName FText, Damage float}, most first)}. Robot DisplayName = the run-log robot type (stats row name) as text; weapon DisplayName = `ARRWeapon::GetClassDisplayName` of the class found by name, else the class name.
  - `URRShopScreenWidget` (`UI/`, Abstract): pure `GetShop()`, `GetRecap()`; implement `OnShopRefreshed()` (bound to `OnShopChanged`; also call it from Construct); Continue button calls `Continue()`.
  - `URRLoadingScreenWidget`: implement `OnLoadingShown(LevelIndex, LayoutName)` and `OnLoadingStageChanged(Stage)`; pure `GetLoadingStage()`.
  - Subsystem (BlueprintAssignable): `OnIntermissionStarted(Recap)`, `OnShopScreenStarted()`, `OnRunWonScreenStarted()`, `OnLoadingStarted`, `OnLoadingStageChanged`, `OnLevelReady`; callable `NextLevel`, `Continue`; pure `GetPhase` (`ERRRunTransitionPhase` None, Stats, Shop, Loading), `IsInIntermission` (Stats or Shop), `IsInStatsScreen`, `IsInShopScreen`, `IsLevelLoading`, `GetLoadingStage`, `GetIntermissionRecap`, `GetLoadingLevelIndex`, `IsRunWon`.
- Loading across the travel: no MoviePlayer. The old world's controller shows the loading widget on `OnLoadingStarted`; the new world's controller shows a new one at BeginPlay while `IsLevelLoading`; both removed on `OnLevelReady`.
- Paint wait before the travel (task-208-01, owner 2026-10-17): the widget added on `OnLoadingStarted` is first drawn in the next frame, so an OpenLevel in the Continue frame showed the frozen game during the load (task-206-06). `URRLoadingScreenWidget::NativePaint` reports its first paint to `NotifyLoadingScreenPainted` (public, recorded only before the travel request: `GFrameCounter`); `OpenArenaMap` travels once the first paint frame is older than the current frame, else waits on the core ticker (runs while paused), with a fallback after `URRRunSettings::LoadingPaintWaitMaxFrames` (5, provisional) frames without a paint (no widget class, -nullrhi). Log lines: `Continue: loading started ... frame N`, `travel to <map> waits for the loading screen paint`, `first loading paint in frame N`, `opening <map> ... in frame N (loading started frame N, first loading paint frame N | no loading paint after N frames)`. Verified by a rendered -game log (task-208-01, Saved/Logs/task208_game.log, 1280 x 720): loading started frame 2210, first paint 2211, OpenLevel requested 2212 (13.8 ms after Continue), map loaded in frame 2213: frames 2211 and 2212 painted the loading screen before the blocking load.
- HUD and subtitles (task-207-01, owner 2026-10-17): from `OnIntermissionStarted` and `OnLoadingStarted` to `OnLevelReady` the controller collapses the HUD widget (whole WBP_HUD: minimap, bars, weapons, objectives, subtitle line; previous visibility restored on `OnLevelReady`; a new world created during the loading starts collapsed) and `URRSubtitleSubsystem` clears the current line and drops every `Show` ([[sys-subtitles]], [[sys-hud]]). Log lines `HUD hidden (intermission|loading)`, `HUD restored (level ready)`, `subtitles silenced (...)`, `subtitles allowed again (level ready)`. Verified by a rendered -game log (task-207-01, Saved/Logs/task207_game.log): silenced and HUD hidden in the intermission frame, new world silenced and HUD hidden at its start, both restored in the OnLevelReady frame.
- Restart: `URRRunFlowSubsystem::RestartLevel` (end screens) and `ARRGameMode::RestartLevel` (death) call `ResetRun` first: next map begins level 1.
- data: `URRRunSettings::ArenaMapName` (empty), `LoadingHoldTimeoutSeconds` (10), `LoadingPaintWaitMaxFrames` (5, provisional).
- depends_on: [[sys-run]], [[sys-run-layout]], [[sys-objectives-run-flow]], [[sys-spawner-pool-prewarm]], [[sys-hud-bindings]].
- implements: [[intermission]], [[run-structure]].
- gotchas: without `IntermissionWidgetClass` the stats phase logs a warning and waits for `rr.Run.Stats.Next`; without `ShopScreenWidgetClass` the shop phase waits for `rr.Run.Continue`. Restart reopens the current map, which is the level 1 map only while all levels share L_ArenaM1. Direct PIE or -game: no transition, no hold. Debug ([[sys-cheats]]): `rr.Run.Stats.Next` (NextLevel), `rr.Run.Continue` (shop phase only), `rr.Run.NextLevel` (EndRun(true), NextLevel, Continue; level 4: run won end screen), `rr.Run.EndLevel` (stats screen stays open), `rr.Run.Restart`, `rr.Run.Status` (phase stats/shop/loading, run won). task-317-01 changes verified by a rendered -game run (task-317-05, Saved/StatsCards/run.log): level 1 stats (8 kills, 1 weapon), Stats.Next to shop, Continue to level 2, level 4 extraction to the run-won stats screen, Stats.Next to the run-won end screen with phase none and no shop. Verified by a -game -nullrhi log (task-206-03, no widget classes set yet): levels 1 to 3 extracted into the intermission, arena_l2/l3/l4 ready about 110 ms after the request, map loaded 2.3 to 2.7 s after Continue, hold released 445 ms later on the prewarm (61 spawner ticks), level 4 extraction = run won, restart and deaths reset to level 1. Rendered -game at 1920 x 1080 (task-206-06, Saved/Captures/task206_*.png): intermission and new-world loading screen drawn; map load 3.3 s, hold 1990 ms (61 spawner ticks); the old-world loading widget was shown in the same frame as the travel, so it was never drawn (fixed by task-208-01); Kessler-Voss subtitles and HUD objective texts drew over the intermission (fixed by task-207-01). No automation test (owner rule).
