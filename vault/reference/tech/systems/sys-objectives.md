# Objectives and run flow

- responsibility: the level run flow (alert bar, mandatory objective pause, extraction shuttle, run end) and the command console objective.
- main_classes (`Source/RogueRigs/Objectives/`):
  - `URRRunFlowSubsystem` (tickable world subsystem, Game/PIE, not ticked while paused): `AlertSeconds` += dt × cheat multiplier; kills add `KillAlertSeconds` (`NotifyEnemyKilled`, called by `ARREnemy::HandleDeath`; a self-instigated death such as the kamikaze fuse is ignored). Nothing grows while the console is pending. At `ConsoleAlertThreshold` the alert is clamped and the console drops on a random Floor cell, straight-line 36–60 cells (67 uu) from the miner's cell, reachable in the flow field, whose whole landing footprint is reachable floor (below), preferring cells with rocks to mark (`bPreferCellsWithMarkedRocks`, provisional choice of this task). Alert 1 and nothing pending: `OnExtractionReady` once (phase `ExtractionReady`), then the shuttle lands (below). Run end (`EndRun`, from the shuttle): refused if already ended or the miner is dead (game over owns it); cancels the miner level-up offer (`URRLevelUpComponent::CancelChoices`: screen closed, later screens blocked; the end screen wins, [[sys-level-up]]); player 0 controller `SetPause(true)`, input Game and UI, cursor shown; `OnRunEnded(bSuccess)` once (phase `Ended`). `RestartLevel` reopens the current map.
  - `FRRRunFlowConfig` (`RRRunFlowConfig.h`): `AlertFillSeconds` 240, `KillAlertSeconds` 0.5, `ConsoleAlertThreshold` 0.4, `ConsoleMinDistanceCells` 36, `ConsoleMaxDistanceCells` 60 (task-029-04: 12–20 cells of 200 uu × 3), `bPreferCellsWithMarkedRocks` true, `ConsoleClass` (none = native `ARRConsole`); extraction ([[extraction]]): `ShuttleMinDistanceCells` 37 and `ShuttleMaxDistanceCells` 50 (task-049-01; was at least 75, no maximum; a max below the min counts as the min), `ShuttleCountdownSeconds` 45, `ShuttleBoardRadiusCells` 3 (1 cell of 200 uu, provisional choice of task-016-02), `ShuttleClass` (none = native `ARRShuttle`; the BP agent sets the shuttle Blueprint); bonus chest (task-056-01): `BonusChestAlertThreshold` 0.6 (0 = no chest), `BonusChestMinDistanceCells` 30, `BonusChestMaxDistanceCells` 45, `BonusChestClass` (none = native `ARRBonusChest`). Edited on `BP_RRGameMode` (`ARRGameMode::RunFlowConfig`), read on the first tick; `SetConfig` overrides (tests).
  - `ARRConsole` (Blueprintable, not abstract): marks blocks of `MarkedCellTypes` (Rock, Ore, HealOre, SpecialOre; barrels excluded) within `MarkRadiusCells` 6 (2 cells of 200 uu; Euclidean, cell centers) through `ARRArenaGrid::SetCellMarked` ([[sys-grid]]). States `ERRConsoleState`: Locked (marked rocks left, polled each tick), Idle, Hacking, Complete (final). Miner alive within `ZoneRadiusCells` 9 (3 cells of 200 uu; 2D): `ARRDrone::StartHack`; while linked progress += dt / `HackDuration` 16 (20 before task-042-01); otherwise `StopHack` and drain `DrainPerSecond` 0.05/s. Mesh: NoCollision by default.
  - `ARRBonusChest : ARRConsole` (task-056-01, Blueprintable, not abstract, [[objective-bonus-chest]]): same hack code, defaults `HackDuration` 8, `ZoneRadiusCells` 6, `DrainPerSecond` 0.05 (inherited), `MarkRadiusCells` 0 and empty `MarkedCellTypes` (no marked rocks: starts Idle), footprint 2 × 2. Dropped once per level, after `CheckExtraction`, when the alert reaches `BonusChestAlertThreshold` and extraction is not ready (a cheat jump to full skips it only when extraction becomes ready in that tick); never pauses the bar; spot picked by the console picker (`FindObjectiveCell`) 30–45 cells away, no marked-rock preference, retried each tick. On `CompleteHack` (or `ForceComplete`) the reward, once: `AddXP(XPNeedFraction` 0.5 × current level need) (XPGain stat applies, implementation choice), `OreChunkCount` 5 pickups of `OrePickupClass` (none = grid `GetDropPickupClass(Ore)`) popped around it, evenly spread yaw, and `URRLevelUpComponent::QueueBonusChoice(BonusLuck` 3) (offer level 0, owner luck + 3 for that offer and its reroll; same delay and pause as a level-up choice). All EditDefaultsOnly.
  - Landing clearance (task-026-00, `RRLandingFootprint`): `ARRConsole::FootprintCells` 2 × 2 and `ARRShuttle::FootprintCells` 4 × 3 (cells of 67 uu, EditDefaultsOnly; meshes 100 × 100 and 240 × 160 uu), rotation zero, X along the grid X axis. The footprint spans `Anchor - (Size - 1) / 2` to `+ Size - 1` per axis; the actor stands at its centre (a cell corner for an even size); `GetCell` is the anchor. A spot is valid only when every footprint cell is Floor reachable in the flow field. Fallbacks, each logged as a warning: console, no fitting spot in the ring → any ring cell (mesh may overlap blocks); shuttle, no fitting spot in the 37–50 band → the fitting spot nearest to the band, then the reachable floor cell nearest to it (footprint ignored).
  - `ARRShuttle` (Blueprintable, not abstract): spawned on a random reachable Floor cell (footprint clear) straight-line `ShuttleMinDistanceCells`–`ShuttleMaxDistanceCells` from the miner cell (fallbacks above; no reachable cell: retried each tick). Countdown `ShuttleCountdownSeconds` (cheat `ShuttleCountdownOverride` > 0 replaces it at landing, [[sys-cheats]]). Each tick (not paused): miner alive within the board radius (2D) → extracted (win); else countdown −dt, at 0 → missed (loss). Dead miner freezes it. Robots keep spawning meanwhile ([[sys-spawner]] is independent). Mesh NoCollision.
- entry_points: subsystem `GetAlert`, `GetAlertSeconds`, `GetPhase`, `HasPendingObjective`, `IsExtractionReady`, `GetConsole`, `GetKillCount`, `SetAlert`, `SkipToConsole`, `CompleteConsoleHack`, `SkipToExtraction`, `GetBonusChest`, `IsBonusChestTriggered`, `GetShuttle`, `IsRunEnded`, `WasRunSuccessful`, `EndRun`, `RestartLevel`, `SetRunFlowEnabled`, `SetRandomSeed`; delegates `OnAlertChanged(Alert, bPaused)`, `OnObjectiveChanged(Console, State, MarkedRocksLeft, MarkedRocksTotal)`, `OnObjectiveProgressChanged(Progress, bHacking)`, `OnConsoleDropped(Console)`, `OnBonusChestDropped(BonusChest)`, `OnExtractionReady()`, `OnShuttleLanded(Shuttle)`, `OnShuttleCountdown(Remaining, ShuttleLocation)` (every countdown frame and at landing), `OnRunEnded(bSuccess)`. Shuttle getters, delegates `OnShuttleCountdownChanged`, `OnShuttleFinished`. Console `ForceComplete` (cheats only: `SetAlert`, `SkipToConsole`, `CompleteConsoleHack`, `SkipToExtraction` and `ForceComplete` are in Blueprint category `Cheats` and do nothing in shipping, [[sys-cheats]]), getters, delegates `OnConsoleStateChanged`, `OnConsoleProgressChanged`, `OnConsoleMarkedRocksChanged`.
- Blueprint events (BlueprintImplementableEvent) for the visuals:
  - `ARRConsole`: `OnMarkedRocksChanged(Remaining, Total)` (also at drop), `OnHackProgress(Progress, bHacking)`, `OnHackStateChanged(NewState)`.
  - `ARRBonusChest`: the console events `OnHackProgress`, `OnHackStateChanged` (`OnMarkedRocksChanged(0, 0)` once at drop), plus `OnRewardGranted(XP, OreChunks, bUpgradeChoiceQueued)`; pure getters `WasRewardGranted`, `GetRewardXP`, `GetXPNeedFraction`, `GetOreChunkCount`, `GetBonusLuck` and the console ones (`GetHackProgress`, `GetZoneRadius`, `GetConsoleState`).
  - `ARRShuttle`: `OnLanded()`, `OnCountdown(Remaining)` (every countdown frame), `OnExtracted()` (win), `OnMissed()` (loss).
  - `ARRArenaGrid`: `OnCellMarkedChanged(Cell, bMarked, CellCenter)`; and per-instance custom data float `MarkedCustomDataIndex` (0) = `MarkedCustomDataValue` (1) on the block HISMs, readable by a material through PerInstanceCustomData (pulsing white outline, [[color-code]]).
  - `URRHUDWidget`: `OnAlertChanged`, `OnObjectiveChanged`, `OnObjectiveProgressChanged`, `OnExtractionReady`, `OnShuttleCountdown`, `OnRunEnded`; call `RestartLevel` ([[sys-hud]]).
- HUD locator (task-032-01): `URRHUDWidget::GetObjectiveTarget` / `GetObjectiveLocator` point at the console until it is `Complete`, then at the landed shuttle ([[sys-hud]]).
- data: tunables above (provisional values from [[level-flow]] M1 and [[objective-console]]); no table.
- depends_on: [[sys-grid]], [[sys-drone]], [[sys-flow-field]], [[sys-player]], [[sys-enemies]], [[sys-cheats]] (alert multiplier).
- implements: [[level-flow]] (M1 sequence), [[objective-console]], [[extraction]] (M1 end screens), alert counter of [[difficulty]].
- gotchas: every distance above is a cell count of the 67 uu grid; a cell size change needs them rescaled ([[arena-grid]]). Threat counter not built ([[sys-difficulty]]). One console and one bonus chest per level; no tier pool. The chest drops in other tests too when their alert passes 0.6 before full. The flow is active in every game world with a grid and a miner, including other tests (alert never reaches 0.4 there). Ore carried is not secured yet ([[ore-economy]] meta not built). The bare test world has no controller: those tests prove the end state; `Integration.ConsoleExtractionWin` / `ShuttleTimeoutLoss` prove the real pause, the HUD texts and the end screen. Tests: `RogueRigs.RunFlow.*`, `RogueRigs.Console.*`, `RogueRigs.Extraction.*` ([[sys-automation-tests]]).
