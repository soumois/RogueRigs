# Automation tests — hud text

Part of [[sys-automation-tests]] (harness, command and gotchas live there).

- `RogueRigs.HUD.Events*` (task-094-02, `RRHUDEventTests.cpp`, recorder and panel in `RRTestHUDWidget.h`; [[sys-hud-events]]): `EventsHealth` (one health and one damage event per hit with payload, none for same values, heal not damage, MaxHealth clamp not damage, never Max 0); `EventsWeapons` (one ammo and one slot event per round and per magazine change, none for an unchanged rounded value, slot event at reload start and end but not for progress, slot event on acquisition); `EventsRunFlow` (alert-bar icons sent once, horde relay payload, locator none, console on drop, none after the hack, console icon done); `EventsXP` (one event per gain, none for 0); `EventsPanelBinding` (two panels, one nested, bound once despite repeated binds; late miner and spawner reach both panels).
- `RogueRigs.HUD.Pressure*` (task-026-02, `RRHUDPressureTests.cpp`; `RRJuiceIntegrationTests.cpp`; [[sys-hud-pressure]]): `PressureBarPosition` (world-free `EstimateBarPosition`: 60 s ahead at 0.1 on a 240 s fill = 0.35, clamp 1, overdue = on the fill; constant along the base fill, kills move it forward, a console pause slides it back never behind 0.4); `PressureDamage` (fine grid, `BP_Miner`, `URRTestHUDWidget` bound: Max 100, hits 100 → 70 → 20 give (30, 0.7), (50, 0.2); a heal and a MaxHealth 60 clamp give nothing; lethal hit fraction 0; nothing once unbound); `PressureHorde` (native spawner, one horde lull 1 s, banner 1.5 s, front 2 s, spread 1 s; run flow fill 20 s: alert trigger puts the icon at `TriggerAlert` 0.3; run-time trigger: console 0.4, horde 0.1, shuttle 1, none done, one call per changed list; 200 frames: pending icon 0.1000 steady and never behind the fill, done at frame 121 (front at 120 ±1) frozen at 0.1000, one more call only; one banner announcing 0.5 s; nothing once unbound).
- `RogueRigs.HUD.FindWidgetInPanels` (task-094-10, `RRHUDEventTests.cpp`, [[sys-hud]]): a test HUD whose canvas holds a panel that holds a text and a second panel with its own text: `GetWidgetFromName` misses the panel text; `FindHUDWidget` finds the root-tree box, the panel text and the nested panel text (static `FindWidgetInTree` too); null for an unknown name, None, a null root, and from a panel for a widget of its parent; `FindUserWidgetWithProperty` null for an unknown variable. Since task-094-10 the integration tests (WBP_HUD cards, end screen, alert bar, pressure icons, vignette, HitFlash) look widgets and variables up through these helpers, expectations unchanged; `HUD.PressureHorde` reads the run flow alert-bar list through the HUD getter. The run-loop and pressure-loop harnesses call `RRTestAccess::FUserWidgetAccess::ConstructNestedOf(HUD)` after creating WBP_HUD: it runs NativeConstruct (and the Blueprint Construct) of every nested panel, children first, as Slate does in game (headless builds no Slate widget); WBP_AlertObjectives binds RestartButton there. `Integration.PressureVignetteOnHit` failed in the task-094-10 run (FadeStep dt 0); it passes since the task-104-01 Blueprint fix (task-103-01 run).
- `RogueRigs.HUD.MinimapEvents`, `LocatorEvents`, `VignetteWarmUpOnce` (task-103-01, `RRHUDMinimapEventTests.cpp`, fine grid, stopped `BP_Miner` on (121, 121), `URRTestHUDWidget`, world and `NativeTickOf` ticked together; [[sys-hud-events]], [[sys-hud-minimap]]): `MinimapEvents` (headless the minimap is created by the first bind: texture event once, one view event, one seen pass, rock (129, 115) seen; 60 idle frames: no view event, no minimap update, no seen pass; a 0.01-cell move: one update, no event; one cell: one event, one seen pass, cell 19 away now seen, nothing after; a seen rock destroyed: no event before, one on the next tick, none after; texture event once overall); `LocatorEvents` (no target: a move sends nothing; console drop: one locator and one minimap event; 60 idle frames: none; 0.5 uu: none; 50 uu: one, then none; hack: one (None), then moves send nothing); `VignetteWarmUpOnce` (no vignette: no warm-up; with an Image DamageVignette at 0 and a panel: warm-up once to 0.001 on bind, panel handed the HUD once; reset to 0, 30 ticks and a rebind: still once, opacity stays 0).
- `RogueRigs.Text.*` (task-079-01, `RRTextContentTests.cpp`, [[sys-text-content]]): `LoadsRealFiles` (3 files, nothing rejected, a flavor for each of the 13 stats, lines for the 5 alert events, counts equal the raw items); `IdsInEventsList` (every alert `event`, bark `trigger` and `speaker_id` of the real files is in the C++ lists); `Fallback` (broken, missing and unknown-id cases: false and empty text, one warning each, unknown ids warn once over 3 asks); `AlertPickNoRepeat` (200 picks per event: never twice in a row, every line used, same seed same sequence); `UpgradeCardFlavor` (`BP_Miner`, rifle only: description = name, newline, flavor, no digit; name and value text unchanged; without the files the description is empty and the numbers equal); `AlertEventsWired` (fine grid: console, chest, extraction and countdown lines set at their events, countdown line unchanged over 30 frames; test HUD: horde line picked before the banner, next horde another line; since task-099-01 each of the five events also shows its line as a `kessler_voss` subtitle "Kessler-Voss: <line>", the countdown subtitle once over 30 frames).
- `RogueRigs.Subtitles.*` (task-099-01, `RRSubtitleTests.cpp`, [[sys-subtitles]]): `ReplaceAndPrefix` (empty line refused, table prefix, replace without a clear, explicit name, unknown speaker without prefix); `DurationAndClear` (4 s + 0.06 s per character, override, ticked down, auto clear, `Clear`, delegate order shown/cleared, nothing when idle).
