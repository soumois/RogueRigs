# Spawner wave director

- responsibility: when and what the spawner spawns while `DirectorConfig.bEnabled` (default): lone robots, waves of packs at least 120° apart around the miner (level 1), announced hordes ([[enemies-index]] wave director, [[drgs-analysis]]).
- main_classes: `Source/RogueRigs/Enemies/RRWaveDirector.h/.cpp`: data structs `FRRWaveDirectorConfig` {`bEnabled`, `HordeTrigger` (`ERRHordeTrigger` RunTime | Alert), `Phases`, `PackTypes`, `Hordes`}, `FRRDirectorPhase` {`Name`, `StartTime`, `SingleInterval` (first one at phase start), `SingleClass`, `bWaveOnStart`, `bKeepWaveTimer` (task-028-01: entering the phase keeps the previous wave timer, for a phase that only changes the pack mix), `WaveIntervalStart` → `WaveIntervalEnd` over `WaveIntervalRampSeconds`, `SidesMin`–`SidesMax` packs per wave, `PackWeights` {`PackType` name, `Weight`}}, `FRRDirectorPackType` {`Name`, `Members`}, `FRRDirectorPackMember` {`RobotClass`, `CountMin`, `CountMax`, `bFront`, `bBehind` (task-030-01: never leads the pack)}, `FRRDirectorHorde` {`TriggerTime` (front time), `ConsoleLandedDelaySeconds` (task-524: ≥ 0 = front timed from the console landing, below), `TriggerAlert` (lull start), `LullSeconds`, `WarningSeconds`, `SpreadSeconds`, `SizeMin`, `SizeMax`, `Members`, `FillClass`}; world-free scheduler `FRRWaveDirector` (`Advance` → `FRRDirectorAction` orders). Executed by `ARREnemySpawner` ([[sys-spawner]]).
- last_level_profile (task-048-01, [[difficulty]], owner 2026-10-07): `FRRWaveDirectorConfig::MakeLastLevel()`, a verbatim copy (no shared helper) of the `MakeDefault` body as of 2026-10-07: the defaults above (waves 7.1 → 4.1 s, distinct-side packs, same pack types, hordes, overtime, shooter counter). The 150-alive cap was `ARREnemySpawner::MaxAlive`, outside the config (80 since task-046-01: a last level must set 150 back); `PackMinSeparationDegrees` stays 0 (distinct sides). Not called anywhere until levels exist; keep it frozen when `MakeDefault` is softened for level 1.
- console_timed_horde (task-524, owner 2026-11-13, provisional): a listed horde with `ConsoleLandedDelaySeconds` ≥ 0 under the RunTime trigger has its front that many seconds after the console landed instead of at `TriggerTime`, while the scheduler expects a console (`FRRWaveDirector::SetConsoleExpected`: the spawner sets it each director tick when the world has an enabled run flow); until the landing it waits, and the hordes after it wait in turn. The spawner polls `URRRunFlowSubsystem::GetConsole` each director tick and calls `NotifyConsoleLanded` once (run time kept until `Reset`), logging `console landed at <t> s; horde 0 front at <t> s`. `MakeDefault` sets 20 s on horde 0 only (the second keeps 175 s); its overtime copy is made before, so it stays -1. World-free use (no `SetConsoleExpected`) and a run without run flow keep `TriggerTime` (95 s). Banner, lull and spread are unchanged: the banner 4 s before the front. Measured in a `-game` run: console at 96.3 s, front 0 at 116.2 s.
- behavior: lull, banner and front silence lone robots and waves; the wave timer restarts after the front. Robot classes resolve to the `WeightedEnemyClasses` entry with the same nearest native class (the Blueprints of [[bp-enemy-spawner]]), else the class itself; entry `MaxAlive` caps apply (excess dropped; horde fill keeps the size). Pack: one candidate scan per wave; shooter room = `ShooterMaxAlive` − shooters alive (`GetDirectorShooterRoom`), shared by the wave, excess shooters replaced without an extra random draw; pack anchors (`FRRSpawnedPack::AnchorAngle`, degrees around the miner): with `FRRWaveDirectorConfig::PackMinSeparationDegrees` > 0 (task-046-01, `MakeDefault` 120; struct default 0) each anchor is a random cell at least that angle from the anchors already placed (sector drawn first and kept when possible, then side room, then anywhere; none far enough = the farthest cell, `PickSeparatedAnchor`); when packs × angle ≥ 360 (3 packs at 120°) the first anchor is a random cell (same sector rule) from which every 360/N step has a cell within 3° (`PickEvenSpreadStart`), the others take the cell nearest their step (`PickAnchorNearAngle`); the pack takes the cells of the anchor side nearest the anchor. With 0, a distinct side per pack (still: random side with room, else largest, random anchor; running: sector drawn first, side and anchor = a random cell of that sector, [[sys-spawner]] run heading), the cells nearest the anchor, front members on the cells nearest the view, the other members shuffled, then `bBehind` members inserted at random in the back half of them (middle or back of the pack, never the front row). Horde: one side (running: the side of a random cell of the drawn sector), cells sorted by distance to the view (the front row spans the side), front members first, spread along the front row (task-292-01: the side cells at the nearest view distance, ordered along the side, members at both ends and evenly between, one member in the middle; a row shorter than the front members keeps the nearest cells; before: the nearest, often adjacent, cells), spawned in order over `SpreadSeconds`; a cell that entered the margin meanwhile is skipped. Packs and hordes clamp to `MaxAlive` (80).
- entry_points: delegates `OnDirectorPhaseChanged(PhaseIndex, PhaseName)`, `OnHordeLull(HordeIndex)`, `OnHordeIncoming(HordeIndex, SecondsUntil)` (banner), `OnHordeStarted(HordeIndex, Side)`, `OnHordeFinished(HordeIndex, Spawned)`, `OnOvertimeStarted()`; pure `IsInOvertime`, `GetCurrentWaveInterval`, `IsDirectorEnabled`, `GetDirectorPhase`, `GetHordeTrigger`, `GetHordeCount`, `GetHordeTriggerTime(i)`, `GetHordeConsoleDelay(i)` (-1 when not console timed), `GetHordeTriggerAlert(i)`, `GetHordeState(i)` (`ERRHordeState`), `GetActiveHorde`, `GetSecondsUntilHordeFront`; C++ `GetDirectorConfig`, `GetDirector` (`GetConsoleLandedTime`, `IsConsoleTimedHorde`, `GetHordeFrontTime(Config, i)`), `ResolveRobotClass`, `TrySpawnDirectorWave` (→ `FRRSpawnedPack` {type, side, robots, cells}), `TrySpawnEnemyOfClass`.
- data: `ARREnemySpawner::DirectorConfig` (also `ShooterMaxAlive`, `ShooterCapReplacement`) (EditAnywhere, category Spawner|Director); tune on [[bp-enemy-spawner]] or the C++ defaults.
- depends_on: [[sys-spawner]], [[sys-objectives]] (alert, Alert trigger only).
- implements: [[enemies-index]] wave director; horde events for [[level-flow]] M1.
- gotchas: run time counts only enabled spawning. Alert mode at 0.4 coincides with the console drop. A saturated cap shrinks hordes. Heavy capsules nudge neighbours off compact pack cells. A test world with an enabled run flow that sets its own horde 0 `TriggerTime` must set `ConsoleLandedDelaySeconds` to -1, else the horde waits for a console. The log has a line per horde lull, banner (`horde <i> banner at <t> s, front in <s> s`, task-524) and front. Tests: `RogueRigs.Spawner.Director*`, `DirectorConsoleTimedHorde` for the landing timing ([[sys-automation-tests]]).
