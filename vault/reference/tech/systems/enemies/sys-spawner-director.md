# Spawner wave director

- responsibility: when and what the spawner spawns while `DirectorConfig.bEnabled` (default): lone robots, waves of packs at least 120° apart around the miner (level 1), announced hordes ([[enemies-index]] wave director, [[drgs-analysis]]).
- main_classes: `Source/RogueRigs/Enemies/RRWaveDirector.h/.cpp`: data structs `FRRWaveDirectorConfig` {`bEnabled`, `HordeTrigger` (`ERRHordeTrigger` RunTime | Alert), `Phases`, `PackTypes`, `Hordes`}, `FRRDirectorPhase` {`Name`, `StartTime`, `SingleInterval` (first one at phase start), `SingleClass`, `bWaveOnStart`, `bKeepWaveTimer` (task-028-01: entering the phase keeps the previous wave timer, for a phase that only changes the pack mix), `WaveIntervalStart` → `WaveIntervalEnd` over `WaveIntervalRampSeconds`, `SidesMin`–`SidesMax` packs per wave, `PackWeights` {`PackType` name, `Weight`}}, `FRRDirectorPackType` {`Name`, `Members`}, `FRRDirectorPackMember` {`RobotClass`, `CountMin`, `CountMax`, `bFront`, `bBehind` (task-030-01: never leads the pack)}, `FRRDirectorHorde` {`TriggerTime` (front time), `TriggerAlert` (lull start), `LullSeconds`, `WarningSeconds`, `SpreadSeconds`, `SizeMin`, `SizeMax`, `Members`, `FillClass`}; world-free scheduler `FRRWaveDirector` (`Advance` → `FRRDirectorAction` orders). Executed by `ARREnemySpawner` ([[sys-spawner]]).
- last_level_profile (task-048-01, [[difficulty]], owner 2026-10-07): `FRRWaveDirectorConfig::MakeLastLevel()`, a verbatim copy (no shared helper) of the `MakeDefault` body as of 2026-10-07: the defaults above (waves 7.1 → 4.1 s, distinct-side packs, same pack types, hordes, overtime, shooter counter). The 150-alive cap was `ARREnemySpawner::MaxAlive`, outside the config (80 since task-046-01: a last level must set 150 back); `PackMinSeparationDegrees` stays 0 (distinct sides). Not called anywhere until levels exist; keep it frozen when `MakeDefault` is softened for level 1.
- behavior: lull, banner and front silence lone robots and waves; the wave timer restarts after the front. Robot classes resolve to the `WeightedEnemyClasses` entry with the same nearest native class (the Blueprints of [[bp-enemy-spawner]]), else the class itself; entry `MaxAlive` caps apply (excess dropped; horde fill keeps the size). Pack: one candidate scan per wave; shooter room = `ShooterMaxAlive` − shooters alive (`GetDirectorShooterRoom`), shared by the wave, excess shooters replaced without an extra random draw; pack anchors (`FRRSpawnedPack::AnchorAngle`, degrees around the miner): with `FRRWaveDirectorConfig::PackMinSeparationDegrees` > 0 (task-046-01, `MakeDefault` 120; struct default 0) each anchor is a random cell at least that angle from the anchors already placed (sector drawn first and kept when possible, then side room, then anywhere; none far enough = the farthest cell, `PickSeparatedAnchor`); when packs × angle ≥ 360 (3 packs at 120°) the first anchor is a random cell (same sector rule) from which every 360/N step has a cell within 3° (`PickEvenSpreadStart`), the others take the cell nearest their step (`PickAnchorNearAngle`); the pack takes the cells of the anchor side nearest the anchor. With 0, a distinct side per pack (still: random side with room, else largest, random anchor; running: sector drawn first, side and anchor = a random cell of that sector, [[sys-spawner]] run heading), the cells nearest the anchor, front members on the cells nearest the view, the other members shuffled, then `bBehind` members inserted at random in the back half of them (middle or back of the pack, never the front row). Horde: one side (running: the side of a random cell of the drawn sector), cells sorted by distance to the view (the front row spans the side), front members first, spawned in order over `SpreadSeconds`; a cell that entered the margin meanwhile is skipped. Packs and hordes clamp to `MaxAlive` (80).
- entry_points: delegates `OnDirectorPhaseChanged(PhaseIndex, PhaseName)`, `OnHordeLull(HordeIndex)`, `OnHordeIncoming(HordeIndex, SecondsUntil)` (banner), `OnHordeStarted(HordeIndex, Side)`, `OnHordeFinished(HordeIndex, Spawned)`, `OnOvertimeStarted()`; pure `IsInOvertime`, `GetCurrentWaveInterval`, `IsDirectorEnabled`, `GetDirectorPhase`, `GetHordeTrigger`, `GetHordeCount`, `GetHordeTriggerTime(i)`, `GetHordeTriggerAlert(i)`, `GetHordeState(i)` (`ERRHordeState`), `GetActiveHorde`, `GetSecondsUntilHordeFront`; C++ `GetDirectorConfig`, `GetDirector`, `ResolveRobotClass`, `TrySpawnDirectorWave` (→ `FRRSpawnedPack` {type, side, robots, cells}), `TrySpawnEnemyOfClass`.
- data: `ARREnemySpawner::DirectorConfig` (also `ShooterMaxAlive`, `ShooterCapReplacement`) (EditAnywhere, category Spawner|Director); tune on [[bp-enemy-spawner]] or the C++ defaults.
- depends_on: [[sys-spawner]], [[sys-objectives]] (alert, Alert trigger only).
- implements: [[enemies-index]] wave director; horde events for [[level-flow]] M1.
- gotchas: run time counts only enabled spawning. Alert mode at 0.4 coincides with the console drop. A saturated cap shrinks hordes. Heavy capsules nudge neighbours off compact pack cells. Tests: `RogueRigs.Spawner.Director*` ([[sys-automation-tests]]).
