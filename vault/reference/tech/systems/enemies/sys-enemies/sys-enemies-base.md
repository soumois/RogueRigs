# Robot base (`ARREnemy`)

- responsibility: everything a robot has before its own behavior; subclasses implement `UpdateBehavior` (alive only) and may extend `HandleDeath` / `DropXP`.
- main_classes: `ARREnemy` (abstract `ACharacter`, `IAbilitySystemInterface`, `RREnemy.h/.cpp`): own `URRAbilitySystemComponent` with `URRHealthAttributeSet`, `URRMovementAttributeSet`, `URREnemyAttributeSet` ([[sys-gas-core]]); `URREnemyMovementComponent` ([[sys-flow-field]]). No controller (`AutoPossessAI` disabled, `bRunPhysicsWithNoController`, default movement mode at BeginPlay); RVO off (task-034-01), orient to movement, no walking off ledges.
- capsules (task-034-01, `Enemy|Collision`, [[enemies-index]]): `PostInitializeComponents` stores the own capsule radius as `BodyRadius` (`GetBodyRadius`), sizes `HitCapsule` (`GetHitCapsule`; child of the root, Pawn object type, QueryOnly, overlaps only `Projectile`, hidden, no navigation) to the own radius and half height, then shrinks the root capsule radius to `TerrainCapsuleRadius` (24 uu, the chaser's; 0 or larger than own = unchanged), so every robot meets rock, floor and the miner like a chaser while keeping its look. The root capsule ignores `Projectile`; shots hit `HitCapsule` ([[sys-projectiles]]). Heavy: body 48, root 24; shooter body 34.
- crowd (task-018-02, `Enemy|Crowd`): `bIgnoreOtherRobots` (true) makes `SetIgnoreOtherRobots` put `RRCollisionChannels::RobotMaskFilter` on the capsule body and move-ignore mask: robots pass through robots, everything else still collides. Separation (task-034-01, replaces RVO, which made robots give way to each other): robots register with `URRRobotSeparationSubsystem` (`RRRobotSeparationSubsystem.h/.cpp`, world subsystem) at BeginPlay and unregister at EndPlay; each living tick with movement on, `UpdateSeparation` adds `GetSeparation(this)` × `SeparationWeight` (0.5, provisional; `bUseSeparation` true) to the movement input. `GetSeparation`: the first query of a frame rebuilds a 2D hash (`BucketSize` 128 uu) of the living robots; each neighbour in the 3 × 3 buckets closer than the sum of both separation radii (`GetSeparationRadius` = `BodyRadius` × `SeparationRadiusScale`, task-295-01; before: the sum of both `BodyRadius`) pushes away by overlap / contact distance; sum clamped to length 1; exactly stacked robots split along X by pointer order; no physics. `SeparationRadiusScale` (`Enemy|Crowd`, default 1; 1.3 in the `ARRKamikaze` and `ARRHeavy` constructors, not overridden by `BP_Kamikaze`/`BP_Heavy`) changes only the crowd spacing: capsules, hit capsule and `GetBodyRadius` unchanged. Separation radius before → after: chaser 24 → 24, shield chaser 24 → 24, shooter 34 → 34, kamikaze 37.4 → 48.6, heavy 48 → 62.4. An ensure in the rebuild flags a separation radius above `BucketSize` / 2 (64). `GetRobotCount` for tests. BeginPlay still writes `AvoidanceRadiusExpansion` 1.1 and `AvoidanceLockTimeAfterAvoid` 0.3 s to the world avoidance manager (no effect with RVO off); `AvoidanceConsiderationRadius` 250 uu kept.
- death (single, `State.Dead`, [[sys-damage]]): `SetMovementActive(false)`, `DisableMovement`, collision off; puff (task-167-01, `Enemy|Death`): `DeathPuffSystem` (null by default = no puff; one-shot Niagara system set by the robot Blueprint) played once at the actor location (robot centre) through `URRNiagaraPoolSubsystem::Spawn` with cap `DeathPuffPoolSize` (40, provisional), prewarmed to that cap at BeginPlay so no death creates a component; pool full = no puff ([[sys-actor-pool]]); linear shrink over `DeathShrinkDuration` (0.15 s); at its end (robot gone), before the XP and the release, debris (task-166-02, `Enemy|Death`, `LaunchDebris`): nothing when `DebrisSystem` is null or `DebrisPieces` empty (M1 death); else 2, 3 or 4 meshes (`FMath::RandRange(2, 4)`, equal odds, task-173-01) drawn by `FRRDebrisSelection::Choose` (`Enemies/RRDebrisPiece.h/.cpp`): groups (Torso, ArmL, ArmR, LegL, LegR) in random order, each at most once; a group with a Whole mesh and both halves is cut one time in two (`FMath::RandBool`), a cut gives 2 meshes (Upper, Lower); a cut that would exceed the count voids the draw, which is redrawn from scratch (task-173-01; at most 16 attempts, the last one throws that limb whole; an attempt succeeds about 70 % of the time). Forcing the limb whole, as before, cut limbs only about one time in three; with the redraw a thrown limb is cut 42 % of the time (the rest of the gap to 50 % comes from the count: a cut fits less often); the torso has only a Whole mesh; stop at the count. Robots with fewer parts need no other code (task-288-05): only groups present in `DebrisPieces` are drawn (a group needs a Whole mesh or both halves; a lone half is skipped), and the thrown count is capped by the pieces available, so the kamikaze list (Torso, LegL, LegR, all Whole) throws 2 pieces on a count of 2 and 3 on a count of 3 or 4 (the log line shows the drawn count, not the thrown one); test `RogueRigs.Kamikaze.DebrisThrowsTwoOrThreePieces` ([[sys-tests-kamikaze-shooter]]). Measured in a -game run (task-173-01, 732 deaths): count 2/3/4 = 32/34/34 %; torso in 44 % of deaths (one mesh for a whole group, a consequence of equal group odds), each whole arm or leg 24-28 %, each half 17-21 %. A Verbose `LogRogueRigs` line per death logs the count and the mesh indices (`<robot> debris: count N, mesh indices [..]`). Played once through `URRNiagaraPoolSubsystem::Spawn` with cap `DebrisPoolSize` (40, provisional), prewarmed at BeginPlay; pool full = no debris, the puff still played. Hit direction: `RecordHitDirection(Direction)` (public), called before the spec is applied by projectiles (flight velocity, [[sys-projectiles]]) and explosions (robot − centre, [[sys-explosions]]); kept horizontal and normalized in `LastHitDirection` (zero direction or dead robot = ignored), cleared in `ResetForNewLife`; none recorded = random horizontal direction at launch. **Niagara contract** for the debris system (one-shot, built by the bp agent): component at the robot feet = `DropLocation` (actor location − scaled capsule half height at death: the actor origin is the capsule centre, so C++ applies the offsets from the capsule bottom), so the analytic floor plane = system Z; component rotation = robot yaw only (read `Engine.Owner.Rotation` for the initial mesh orientation; emitters in world space, `Local Space` off, or the offsets are rotated twice); user parameters set before activation with `UNiagaraDataInterfaceArrayFunctionLibrary`: `User.PieceMeshIndex` (Array Int32, one entry per thrown piece = `FRRDebrisPiece::MeshIndex` = index in the mesh renderer = order in `debris_pieces.json`), `User.PieceOffset` (Array Vector (Vector3f), same order and length, world-space offset of the piece pivot from the system location, robot yaw already applied, cm, pieces at scale 1), `User.HitDirection` (Vector, horizontal unit vector the pieces fly toward); spawn one particle per array entry (count = array length, 2 to 4; a run checked 207 components: the particle MeshIndex values match the requested array, order included). Names: `ARREnemy::DebrisMeshIndexParameter`, `DebrisOffsetParameter`, `DebrisHitDirectionParameter`. Then a burst of `XPCubeCount` pickups of `XPPickupClass` at the feet splitting `Stats.XPValue` (chaser 3, kamikaze 4, shooter 6, heavy 12; [[sys-pickups]]); back to the actor pool (`Release`, [[sys-actor-pool]]; a robot not created by the pool is destroyed; a kamikaze waits until its own explosion left the queue, `CanReleaseToPool`).
- pool (task-091-01, `IRRPoolable`): BeginPlay runs once per actor. `OnPoolAcquired`: the first delivery captures the visual parts (relative transform, visibility, hidden in game, materials, light intensity of every non-root, non-absolute scene component); every delivery after a release runs `ResetForNewLife`: all active gameplay effects removed, `State.Dead` cleared, CSV stats re-applied (MaxHealth, Health, MoveSpeed, Shield), AttackPower default, IncomingDamage 0, death flags and time, velocity, pending launch, input, light-step floor and flow-field arrival state cleared, default movement mode, far-movement LOD off, cached target, visual parts restored (undoes Blueprint events such as the broken shield shell or a heavy telegraph pose), separation registration; subclasses then reset their state machine and counters (chaser, heavy, shooter: aim, sight, laser, view override; kamikaze: fuse, flare, explosion source forgotten through `URRExplosionSubsystem::ForgetSource`; shield chaser: break count). `OnPoolReleased`: leaves the separation, stops movement, restores the scale (death shrink), cancels latent actions (Blueprint Delay nodes). An idle robot keeps `State.Dead`, so `IsDead` filters skip it; actor iterators also check `IsPooledIdle` (flow-field pawn cells, explosions, turret, pacing bot). `GetPoolLifeCount` keys the projectile pierce list ([[sys-projectiles]]): a reused robot is a new target. Notifies the run flow ([[sys-objectives]]).
- damage numbers (`EditAnywhere`, `Enemy|Damage Numbers`): each hit, killing hit included, goes to `URRDamageNumberSubsystem::AddHit` at capsule top + `DamageNumberHeight` (40); merge, style and toggle in [[sys-damage-numbers]].
- knockback: `ApplyKnockback(Velocity)` launches a living robot with XY × (1 − `GetKnockbackResistance()`), added to a launch still pending this frame (several shotgun pellets stack); caller: projectiles with a knockback, i.e. shotgun pellets ([[sys-projectiles]]).
- shared helpers (task-020-02, protected, for every state machine): `SetMovementActive(bool)` (off also drops input and cuts velocity; also the movement clip event, see animation clips), `IsTargetWithin(Miner, Range)` (alive, 2D, inclusive), `MarkStateStart` / `GetTimeInState` / `HasStateLasted(Duration)` on `StateStartTime` with `TimeTolerance` 1e-4 s, `ApplyDamageSpecTo(TargetASC, EffectClass, Damage)` (SetByCaller `Data.Damage`, source = own ASC so `AttackPower` scales it) built on `MakeDamageSpec(EffectClass, Damage)` (task-021-01: the spec a robot projectile carries), `UpdateTelegraphBlink(Rate)` (hidden during the first half of each cycle since the state start), `SetMeshesVisible` (task-119-01: false hides the visible meshes and remembers them, true shows only those again; a Blueprint effect mesh hidden at rest, like the heavy ShockRing, is never lit by the flash end, `RelocateTo` or `HandleDeath`). `ArrivalRangeRatio` (`Enemy|Movement`, base 0.9): arrival distance = engage range × ratio. `FindTarget()` = cached `RRWorld::FindLivingMiner` ([[sys-world-queries]]).
- entry_points: `RecordHitDirection`, `GetLastHitDirection`, `OnPoolAcquired`, `OnPoolReleased`, `GetPoolLifeCount`, `LoadStatsRow`, `GetStats`, `GetHealthSet`, `GetEnemyMovement`, `IsDead`, virtual `IsDeathPending` (false; kamikaze kill fuse), `HoldsSpawnSlot` (not dead or death pending: the spawner alive count and class caps use it, task-096-01), `GetKnockbackResistance`, `ApplyKnockback`, `FindTarget`, `SetIgnoreOtherRobots`, `IsIgnoringOtherRobots`, `GetBodyRadius`, `GetHitCapsule`; virtual `UpdateBehavior`, `HandleDeath`, `DropXP`; protected `LaunchDebris`.
- data: `StatsRowName`, `XPPickupClass`, `DeathPuffSystem` (set by the Blueprint), `DeathPuffPoolSize`; `DebrisSystem`, `DebrisPoolSize` (40), `DebrisPieces` (`TArray<FRRDebrisPiece>`: `Group` `ERRDebrisGroup` Torso, ArmL, ArmR, LegL, LegR; `Kind` `ERRDebrisKind` Whole, Upper, Lower; `MeshIndex`; `Offset` cm, robot space from the floor under the robot, front +X: the report `centre_offset_cm_unreal`; set on BP_Chaser by the bp agent, chaser 13 pieces: 0 Torso Whole, 1/2 ArmL/ArmR Upper, 3/4 ArmL/ArmR Lower, 5/6 ArmL/ArmR Whole, 7/8 LegL/LegR Upper, 9/10 LegL/LegR Lower, 11/12 LegL/LegR Whole; unset in C++); CSV in [[sys-enemies]].
- depends_on: [[sys-gas-core]], [[sys-flow-field]], [[sys-world-queries]].
- implements: [[enemy-death]].
- blob shadow (task-264-02, `Enemy|Blob Shadow`): `BlobShadow` (`URRBlobShadowComponent`) on the root capsule, diameter = own capsule radius × `BlobShadowDiameterScale` (2.2), hidden at death start, restored with the visual parts; not part of the wind-up flash ([[sys-blob-shadow]]).
- animation clips (task-284-05, `Enemy|Animation`; moved from `ARRChaser`, one writer for every robot): the `UStaticMeshComponent` named `AnimatedMeshName` (default `BodyMesh`) plays clips baked in a texture through `MF_RobotAnimWPO` (clip = clamp(round(ClipId + ClipOffset), 0, 3); rows 0, 16, 31, 47; clips 0 and 2 loop with the material RunRate, 1 and 3 clamp at their last frame; [[chaser-meshy-pipeline]]). Found once at BeginPlay (`ResolveAnimatedMesh`, kept in `AnimatedMesh`); none = no animation. Custom Primitive Data 0 (`AnimClipDataIndex`) = clip id, 1 (`AnimStartDataIndex`) = clip start in world seconds, written together by `SetAnimClip` (one `SetCustomPrimitiveDataVector2f`) on events only, never per tick; `GetAnimClipId` / `GetAnimClipStart` (public) return the last write (-1 before any). Protected API for state machines: `PlayLoopClip(Id)` (start = now − `FMath::FRand()` × `LoopPhaseSpread` 2 s, random phase per robot), `PlayClip(Id, Duration)` (start = now; Duration > 0 starts `AnimClipTimer`, which calls virtual `OnAnimClipEnded`, default `PlayMovementClip`), `HoldClipEnd(Id)` (start = now − `AnimHoldLead` 10 s: a clamped clip shows its last frame), `PlayMovementClip` (`RestClipId` held when it is ≥ 0 and the movement is off, else `LoopClipId` looped), `IsTimedClipPlaying`. Every play clears the timer. Movement event: with `RestClipId` ≥ 0, `SetMovementActive` calls `PlayMovementClip` only when the movement state changes (`bMovementClipActive`; state entries repeating the same value write nothing) and never while dying. `PlayMovementClip` runs at the end of BeginPlay and of `ResetForNewLife` (new phase each life). Defaults: `LoopClipId` 0, `RestClipId` -1 (no rest: chaser, shield chaser, kamikaze), heavy 3, shooter 2. To add a clip on a state (task-285 telegraph, slam, recover; task-287 aim, fire): call `PlayClip` in `EnterState` after `SetMovementActive` (a movement change writes the rest or loop first), and `PlayMovementClip` when leaving it, or pass a duration and let `OnAnimClipEnded` return.
- gotchas: no native `BodyMesh` on the base: `ARRKamikaze` owns one, `BP_Chaser`, `BP_ShieldChaser`, `BP_Heavy` and `BP_Shooter` add it.
