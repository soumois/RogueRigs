# Robot base (`ARREnemy`)

- responsibility: everything a robot has before its own behavior; subclasses implement `UpdateBehavior` (alive only) and may extend `HandleDeath` / `DropXP`.
- main_classes: `ARREnemy` (abstract `ACharacter`, `IAbilitySystemInterface`, `RREnemy.h/.cpp`): own `URRAbilitySystemComponent` with `URRHealthAttributeSet`, `URRMovementAttributeSet`, `URREnemyAttributeSet` ([[sys-gas-core]]); `URREnemyMovementComponent` ([[sys-flow-field]]). No controller (`AutoPossessAI` disabled, `bRunPhysicsWithNoController`, default movement mode at BeginPlay); RVO off (task-034-01), orient to movement, no walking off ledges.
- capsules (task-034-01, `Enemy|Collision`, [[enemies-index]]): `PostInitializeComponents` stores the own capsule radius as `BodyRadius` (`GetBodyRadius`), sizes `HitCapsule` (`GetHitCapsule`; child of the root, Pawn object type, QueryOnly, overlaps only `Projectile`, hidden, no navigation) to the own radius and half height, then shrinks the root capsule radius to `TerrainCapsuleRadius` (24 uu, the chaser's; 0 or larger than own = unchanged), so every robot meets rock, floor and the miner like a chaser while keeping its look. The root capsule ignores `Projectile`; shots hit `HitCapsule` ([[sys-projectiles]]). Heavy: body 48, root 24; shooter body 34.
- crowd (task-018-02, `Enemy|Crowd`): `bIgnoreOtherRobots` (true) makes `SetIgnoreOtherRobots` put `RRCollisionChannels::RobotMaskFilter` on the capsule body and move-ignore mask: robots pass through robots, everything else still collides. Separation (task-034-01, replaces RVO, which made robots give way to each other): robots register with `URRRobotSeparationSubsystem` (`RRRobotSeparationSubsystem.h/.cpp`, world subsystem) at BeginPlay and unregister at EndPlay; each living tick with movement on, `UpdateSeparation` adds `GetSeparation(this)` × `SeparationWeight` (0.5, provisional; `bUseSeparation` true) to the movement input. `GetSeparation`: the first query of a frame rebuilds a 2D hash (`BucketSize` 128 uu) of the living robots; each neighbour in the 3 × 3 buckets closer than the sum of both `BodyRadius` pushes away by overlap / contact distance; sum clamped to length 1; exactly stacked robots split along X by pointer order; no physics. `GetRobotCount` for tests. BeginPlay still writes `AvoidanceRadiusExpansion` 1.1 and `AvoidanceLockTimeAfterAvoid` 0.3 s to the world avoidance manager (no effect with RVO off); `AvoidanceConsiderationRadius` 250 uu kept.
- death (single, `State.Dead`, [[sys-damage]]): `SetMovementActive(false)`, `DisableMovement`, collision off; puff (task-167-01, `Enemy|Death`): `DeathPuffSystem` (null by default = no puff; one-shot Niagara system set by the robot Blueprint) played once at the actor location (robot centre) through `URRNiagaraPoolSubsystem::Spawn` with cap `DeathPuffPoolSize` (40, provisional), prewarmed to that cap at BeginPlay so no death creates a component; pool full = no puff ([[sys-actor-pool]]); linear shrink over `DeathShrinkDuration` (0.15 s); then a burst of `XPCubeCount` pickups of `XPPickupClass` at the feet splitting `Stats.XPValue` (chaser 3, kamikaze 4, shooter 6, heavy 12; [[sys-pickups]]); back to the actor pool (`Release`, [[sys-actor-pool]]; a robot not created by the pool is destroyed; a kamikaze waits until its own explosion left the queue, `CanReleaseToPool`).
- pool (task-091-01, `IRRPoolable`): BeginPlay runs once per actor. `OnPoolAcquired`: the first delivery captures the visual parts (relative transform, visibility, hidden in game, materials, light intensity of every non-root, non-absolute scene component); every delivery after a release runs `ResetForNewLife`: all active gameplay effects removed, `State.Dead` cleared, CSV stats re-applied (MaxHealth, Health, MoveSpeed, Shield), AttackPower default, IncomingDamage 0, death flags and time, velocity, pending launch, input, light-step floor and flow-field arrival state cleared, default movement mode, far-movement LOD off, cached target, visual parts restored (undoes Blueprint events such as the broken shield shell or a heavy telegraph pose), separation registration; subclasses then reset their state machine and counters (chaser, heavy, shooter: aim, sight, laser, view override; kamikaze: fuse, flare, explosion source forgotten through `URRExplosionSubsystem::ForgetSource`; shield chaser: break count). `OnPoolReleased`: leaves the separation, stops movement, restores the scale (death shrink), cancels latent actions (Blueprint Delay nodes). An idle robot keeps `State.Dead`, so `IsDead` filters skip it; actor iterators also check `IsPooledIdle` (flow-field pawn cells, explosions, turret, pacing bot). `GetPoolLifeCount` keys the projectile pierce list ([[sys-projectiles]]): a reused robot is a new target. Notifies the run flow ([[sys-objectives]]).
- damage numbers (`EditAnywhere`, `Enemy|Damage Numbers`): each hit, killing hit included, goes to `URRDamageNumberSubsystem::AddHit` at capsule top + `DamageNumberHeight` (40); merge, style and toggle in [[sys-damage-numbers]].
- knockback: `ApplyKnockback(Velocity)` launches a living robot with XY × (1 − `GetKnockbackResistance()`), added to a launch still pending this frame (several shotgun pellets stack); caller: projectiles with a knockback, i.e. shotgun pellets ([[sys-projectiles]]).
- shared helpers (task-020-02, protected, for every state machine): `SetMovementActive(bool)` (off also drops input and cuts velocity), `IsTargetWithin(Miner, Range)` (alive, 2D, inclusive), `MarkStateStart` / `GetTimeInState` / `HasStateLasted(Duration)` on `StateStartTime` with `TimeTolerance` 1e-4 s, `ApplyDamageSpecTo(TargetASC, EffectClass, Damage)` (SetByCaller `Data.Damage`, source = own ASC so `AttackPower` scales it) built on `MakeDamageSpec(EffectClass, Damage)` (task-021-01: the spec a robot projectile carries), `UpdateTelegraphBlink(Rate)` (hidden during the first half of each cycle since the state start), `SetMeshesVisible` (task-119-01: false hides the visible meshes and remembers them, true shows only those again; a Blueprint effect mesh hidden at rest, like the heavy ShockRing, is never lit by the flash end, `RelocateTo` or `HandleDeath`). `ArrivalRangeRatio` (`Enemy|Movement`, base 0.9): arrival distance = engage range × ratio. `FindTarget()` = cached `RRWorld::FindLivingMiner` ([[sys-world-queries]]).
- entry_points: `OnPoolAcquired`, `OnPoolReleased`, `GetPoolLifeCount`, `LoadStatsRow`, `GetStats`, `GetHealthSet`, `GetEnemyMovement`, `IsDead`, virtual `IsDeathPending` (false; kamikaze kill fuse), `HoldsSpawnSlot` (not dead or death pending: the spawner alive count and class caps use it, task-096-01), `GetKnockbackResistance`, `ApplyKnockback`, `FindTarget`, `SetIgnoreOtherRobots`, `IsIgnoringOtherRobots`, `GetBodyRadius`, `GetHitCapsule`; virtual `UpdateBehavior`, `HandleDeath`, `DropXP`.
- data: `StatsRowName`, `XPPickupClass`, `DeathPuffSystem` (set by the Blueprint), `DeathPuffPoolSize`; CSV in [[sys-enemies]].
- depends_on: [[sys-gas-core]], [[sys-flow-field]], [[sys-world-queries]].
- implements: [[enemy-death]].
- gotchas: no native `BodyMesh` on the base: `BP_Chaser` and `ARRKamikaze` own one.
