# Subtitles

- responsibility: show voice lines as one-line subtitles (task-099-01): one line at a time, a new line replaces the current one (queue of one), "<Speaker>: <line>" for Rook and Vesna, the line alone for Kessler-Voss (task-215-01, owner decision: 4 of the 15 alerts name the company), timed in C++ so the widget never polls. Serves the five company alert lines and the Rook and Vesna barks of five key events (task-497-01).
- main_classes (`Source/RogueRigs/Text/`): `URRSubtitleSubsystem` (`UTickableWorldSubsystem`, Game and PIE worlds, `Config = Game`), `FRRSubtitleSpeaker` {`Id`, `DisplayName`, `bShowPrefix` (default true)}.
- entry_points: `Show(SpeakerId, DisplayName, Text, DurationOverride = -1)` (empty name = table name, no prefix for an unknown speaker without a name nor for a speaker whose `bShowPrefix` is false, even with an explicit name; duration <= 0 = formula; empty text refused); `ShowAlertLine(EventId)` (picks with `URRTextContentSubsystem::GetAlertLine`, speaker `kessler_voss`; logs `alert '<id>' replaces the <speaker> bark` when it replaces a bark); `ShowBark(TriggerId)` and `GetBarkCooldownRemaining()` (barks below); `Clear()`; pure getters `HasSubtitle`, `GetCurrentSpeakerId`, `GetCurrentSpeaker`, `GetCurrentText`, `GetCurrentSubtitle`, `GetCurrentDuration`, `GetRemainingSeconds`, `GetSpeakerDisplayName`, `ShowsSpeakerPrefix(SpeakerId)` (table `bShowPrefix`; true for a speaker missing from the table), `GetDurationForText`; static `Get(WorldContext)`, `ComposeSubtitle`.
- events (BlueprintAssignable): `OnSubtitleShown(SpeakerId, Speaker, Text, Subtitle, Duration)` on every show, replace included; `Speaker` is the display name even when the prefix is off (kessler_voss), `Subtitle` is the text as shown; each show logs `URRSubtitleSubsystem: '<subtitle>' for <s> s.` at Log; `OnSubtitleCleared()` when the time runs out or on `Clear`, never between a replace.
- barks (task-497-01, owner 2026-11-10): `ShowBark` picks a line of the trigger among both speakers (`URRTextContentSubsystem::PickBarkLine`: random, never the same line twice in a row), text only, shown with the speaker prefix. Dropped and logged (`bark '<id>' dropped (<reason>, cooldown left N s)`) when the trigger is not in `BarkTriggers`, while silenced, while any line is shown (alerts keep priority, never two lines), or within `BarkCooldownSeconds` of the last bark shown (world time; reset on a new world and on `OnLevelReady`, so the first bark of a level shows at once). An alert arriving during a bark replaces it at once. Exception, owner answer "choix A": a trigger of `BarkTriggersAfterAlert` met by an alert line waits in one slot (`waits for the alert line to end`) and is tried again when that line runs out, cooldown included; silencing empties the slot. Success logs `bark '<id>' shown (<speaker>) at T s, next bark after 30 s`.
- run transition (task-207-01): `Initialize` binds `URRRunTransitionSubsystem` ([[sys-run-transition]]); `OnIntermissionStarted` / `OnLoadingStarted` clear the current line (`OnSubtitleCleared`) and silence; `Show` then returns false and drops the line (no queue, nothing pops up later) until `OnLevelReady`; a world created while the phase is not None starts silenced. Pure `IsSilenced()`. Bare test worlds without a game instance never silence.
- run end (task-211-01): `OnWorldBeginPlay` binds `URRRunFlowSubsystem::OnRunEnded` (end screen: run won on the last level, shuttle missed; a level 1-3 extraction does not broadcast it and is silenced by the intermission) and the auth `ARRGameMode::OnGameOver` (miner death), and logs `world begin play, subtitles allowed|silenced (run end bound|unbound, game over bound|unbound)`. Either clears the current line and silences for the rest of the world (`bRunEndSilenced`: `OnLevelReady` does not lift it); log `subtitles silenced (run ended, run won | run ended, shuttle missed | game over, miner dead)`. The restart (`RestartLevel`, game mode restart timer) opens a new world: a new subsystem, allowed. `Deinitialize` unbinds.
- hooks: `URRRunFlowSubsystem::PickAlertLine` (console_dropped, bonus_chest_dropped, extraction_ready, shuttle_countdown once per `LandShuttle`) and `URRHUDWidget::HandleHordeIncoming` (horde_incoming) call `ShowAlertLine` ([[sys-text-content]], [[sys-hud-pressure]]). `ShowBark` callers: `URRRunFlowSubsystem::ShowBark` for console_dropped (after `OnConsoleDropped`), console_hacked (`HandleConsoleStateChanged`, first Complete), shuttle_landed (after `OnShuttleLanded`); `URRHUDWidget::HandleHordeIncoming` for horde_incoming, after its alert line; `ARRBonusChest::OpenLid` for bonus_chest_opened, before the reward. The display widget is a WBP_HUD sub-widget (task-099-02, [[wbp-hud]]).
- data: `Speakers` (kessler_voss "Kessler-Voss" prefix off, rook "Rook", vesna "Vesna"; C++ default, not set in `Config/DefaultGame.ini`), `BaseSeconds` 4, `SecondsPerCharacter` 0.06 (characters of the line, prefix excluded); config properties, owner decision 2026-10-10. Barks (owner 2026-11-10, provisional, C++ defaults, not set in `Config/DefaultGame.ini`, section `[/Script/RogueRigs.RRSubtitleSubsystem]`): `BarkCooldownSeconds` 30; `BarkTriggers` horde_incoming, console_dropped, console_hacked, bonus_chest_opened, shuttle_landed; `BarkTriggersAfterAlert` horde_incoming, console_dropped, shuttle_landed (each raises its own alert in the same frame, shuttle_landed through shuttle_countdown).
- depends_on: [[sys-text-content]].
- implements: owner decisions of task-099 (company voice lines as subtitles).
- gotchas: the timer uses world time and freezes while the game is paused. extraction_ready and shuttle_countdown fire in the same frame (`CheckExtraction` then `LandShuttle`): the countdown line replaces the extraction line at once. A waiting bark meets the cooldown of the bark before it: in game logs the horde bark is often dropped that way. Tests: `RogueRigs.Subtitles.*` (`Barks`: trigger list, cooldown, alert replace, wait after alert, no repeat), `RogueRigs.Text.AlertEventsWired` ([[sys-automation-tests]]).
