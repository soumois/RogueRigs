# HUD minimap data

- responsibility: data of the round minimap ([[readability-rules]] Minimap line): a terrain texture of the cells already seen and the miner, console, bonus chest and shuttle positions. Drawing (circle, material, markers) is the widget Blueprint's (task-061-02).
- main_classes: `URRMinimap : UObject` (`Source/RogueRigs/UI/RRMinimap.h/.cpp`), owned by `URRHUDWidget` (`Minimap`, Transient); structs `FRRMinimapConfig`, `FRRMinimapState`.
- texture: transient `UTexture2D` B8G8R8A8, sRGB, nearest filter, clamp, never streamed, one pixel per grid cell (240 × 240 on `arena_m1_fine`). Orientation screen-aligned for camera yaw 0 (screen up = world +X, right = world +Y): pixel u = cell Y, v = grid width − 1 − cell X. Colors: Rock, Ore, SpecialOre, Barrel → `RockColor`; Floor, Spawn → `FloorColor`; HealOre → `HealVeinColor`; Void → `VoidColor`; never seen → `UnseenColor` (opaque black 0, 0, 0, alpha 255 since task-184-01; the disc is fully opaque, owner 2026-10-15).
- seen rule ([[readability-rules]] Minimap reveal, task-064-01): on each move of the bound miner (`BoundMiner` root `TransformUpdated`) the HUD reads the miner cell; when it differs from the last one, every unseen cell whose center lies within `RevealRadiusCells` of the miner cell center becomes seen for the rest of the level. A circle, the same in every direction (replaces the camera footprint trapezoid, which revealed more upward).
- driver (task-103-01, no tick): the miner root's `USceneComponent::TransformUpdated` (fired by the engine only when the transform really changes, so an idle miner costs nothing) calls `URRMinimap::Update` (seen pass if the cell changed, flush) and sends `OnMinimapViewChanged` when pixels changed or the miner moved more than `ViewChangeThresholdCells` in texture pixels. A destroyed seen cell (`OnPixelsDirtied`) schedules one next-tick flush for the whole batch, then one event. Creation: `TryCreateMinimap` at HUD initialization and construct, at each `BindToMiner`, on a miner move, and on at most `MinimapRetryFrames` (120) next-tick retries while no built grid exists (headless test widgets have no player context: created by the first bind).
- update rule and cost: a pixel is written only when a cell becomes seen or a seen cell is destroyed (`ARRArenaGrid::OnCellDestroyed`, [[sys-grid]]); the changed pixels of a frame are copied as one dirty rectangle to `UpdateTextureRegions`; nothing is sent on a frame without change, and the seen pass (one disc of about π R² bit tests, row half-widths from one square root per row) runs only when the miner enters another cell.
- entry_points (`URRHUDWidget`, category HUD|Minimap): pure `GetMinimapTexture()` (null until a built grid is found); BlueprintAssignable dynamic multicast delegates (task-103-01, for WBP_MinimapLocator through `URRHUDPanelWidget::BindToHUD`): `OnMinimapTextureReady(UTexture2D* Texture)` (signature `FRROnMinimapTextureReadySignature`; once per HUD, when the texture is created; replaces the BlueprintImplementableEvent of the same name) and `OnMinimapViewChanged(const FRRMinimapState& State)` (`FRROnMinimapViewChangedSignature`; State = `GetMinimapState`; sent on texture creation, miner bind, cells revealed, a seen cell destroyed (next tick, once per batch), miner move > `ViewChangeThresholdCells`, console or bonus chest dropped, shuttle landed; never while the miner is idle). Bind both in `BindToHUD` and read `GetMinimapTexture` / `GetMinimapState` there (the texture may already exist); pure `GetMinimapState(FRRMinimapState& OutState)` (false without texture) with `TextureSize`, `MinerPosition`, `MinerUV`, `ViewRadiusCells`, `ViewRadiusUV`, `bHasConsole` / `ConsolePosition`, `bHasBonusChest` / `BonusChestPosition`, `bHasShuttle` / `ShuttlePosition` (positions in texture pixels, float; a console or chest is listed whatever its state, the shuttle once landed); static pure `GetMinimapOffset(Position, Center, Radius, bClampToCircle, bOutOfRange)` = (Position − Center) / Radius, clamped to length 1 when asked.
- UV mapping for the widget: sample UV = `MinerUV` + (WidgetUV − 0.5) × 2 × `ViewRadiusUV`, masked to the circle; a marker sits at the circle center + `GetMinimapOffset(MarkerPosition, MinerPosition, ViewRadiusCells)` × circle radius (100 px).
- data: `MinimapConfig` (`FRRMinimapConfig`, EditDefaultsOnly on the HUD widget Blueprint): `bEnabled` true, `ViewRadiusCells` 40, `RevealRadiusCells` 18 (provisional, owner 2026-10-09), `ViewChangeThresholdCells` 0.05 (0.125 px on the 200 px disc of 80 cells: the scroll still looks continuous), `RockColor` (176, 166, 196), `FloorColor` (58, 56, 66), `HealVeinColor` (214, 38, 38), `VoidColor` (8, 8, 12), `UnseenColor` (0, 0, 0, 255, task-184-01, was transparent). Floor and void colors are provisional choices of task-061-01: [[color-code]] has no floor or void entry.
- depends_on: [[sys-grid]], [[sys-objectives]] (console, bonus chest, shuttle getters), [[sys-player]] (miner camera).
- implements: [[readability-rules]] Minimap line (data side).
- gotchas: a camera yaw other than 0 needs the image and offsets rotated by the widget. A grid rebuilt at runtime is not re-read. The reveal centre is the bound miner only (no owning-pawn fallback since task-103-01). Tests `RogueRigs.HUD.MinimapEvents` ([[sys-automation-tests]]).
