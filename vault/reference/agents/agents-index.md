# Dev crew

A single Orchestrator splits objectives into tasks and delegates each to one specialized agent. Agents never talk to each other: they read inputs from and write outputs to this vault. Token ceilings are first estimates, corrected after each milestone retrospective.

Planned nodes: agent-orchestrator, agent-cpp, agent-bp, agent-level-design, agent-balance, agent-text, agent-style-guide, agent-art, agent-animation, agent-sound, agent-qa (deferred).
