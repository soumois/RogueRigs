# Assignment 5 — Plan (proposal of 2026-10-14, nothing decided yet)

## Three actors
- Owner: decides, signs off, reviews, plays, writes the judgment part of the README.
- Crew: the Claude Code sessions ([[agent-orchestrator]] and its agents). It builds the tool.
- Code Architect: the deliverable agent (name proposed). It builds the feature. The crew must NOT write the feature by hand, or deliverable 2 is not "generated by the agent".

## Schedule (Pacific time; 5 days, owner budget 5 to 6 hours a week)
| Day | Owner | Crew / Code Architect |
|---|---|---|
| Wed Oct 14 | answer [[assignment-5-open-decisions]] (15 min) | crew: scanner and GDD feature extraction |
| Thu Oct 15 | none | crew: gap detection, scoring, blackboard, state file |
| Fri Oct 16 | read the blackboard of the dry run, approve or veto the top feature (30 min) | crew: writing step; dry run without writes |
| Sat Oct 17 | review the diff, edit, build, play (2 to 3 h) | Code Architect: run with approval, writes on a branch |
| Sun Oct 18 | README judgment part, captures, push and tag (1 h) | crew: README draft, vault docs, lint |
| Mon Oct 19 | submit before 15:59 Pacific (buffer day) | none |

## Owner tasks
Open decisions; model access through an environment variable, never in the repo or vault; sign-off; diff review with recorded changes; play-test; README; `git push origin master --tags`; submit the folder URL.

## Crew tasks
The tool ([[assignment-5-agent-design]]); the dry run; the run; system doc node for the generated feature in `tech/systems`; test pass; README draft; vault update.

## Definition of done
- The feature runs in the game from a clean clone, reachable in one click ([[sys-cheats]]).
- Blackboard and state file of the real run are in the repo.
- README: feature, why chosen (from the blackboard), what the owner changed.
- Lint clean, tests pass, tag pushed.
