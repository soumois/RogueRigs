# Course overview

- Instructor: Joshua Burdick, localization automation engineer at Epic Games.
- Philosophy: game first. The pipeline is the means, a playable game is the goal.
- 14 live lessons over 7 weeks, Tuesday and Thursday; office hours on Saturday (1 h). Discord for async questions.
- Capstone: a playable, published game (a clickable link), due November 9, 2026.

## Grading of the capstone
Game 50 % · multi-agent AI pipeline 20 % · technical quality 10 % · presentation and demo 10 % · documentation and architecture 5 % · peer feedback 5 %. A sophisticated pipeline without a shipped game scores 20/100.

## Assignments
#1–2 GDD draft then final · #3 agent crew · #4 RAG content pipeline · #5 goal-oriented coding agent · #6–7 generate-evaluate-refine pipeline, style guide agent · #8–9 narrative engine, adversarial QA (optional) · #10 full AI pipeline. Details: [[assignments-index]].

## Submission rules
- Every assignment is a GitHub link. The repo is `soumois/RogueRigs`.
- A private repo must give the instructor access (his GitHub account is on Discord).
- Each assignment has its own folder and README under `assignments/`; the root README carries the assignment table at the top and no assignment history.
- Code that does not run scores 0 on every criterion (stated for Assignment 4).
- A README is never cut down without the owner's agreement: update history, captures and GIFs stay (owner rule, 2026-10-14). The README of an assignment is judged and must be complete on its own.
