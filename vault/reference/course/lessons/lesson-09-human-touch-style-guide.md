# Lesson 09 — The human touch and the Style Guide Agent

Slides only: no transcript, the guest speaker and the oral workshop are not covered.

## The aesthetic divide
AI assets are high volume, technically polished, symmetrical, but lack deliberate imperfections that carry narrative weight. Human assets show wear, intentional asymmetry and micro-choices that tell a past.

## When to use which
- Good for AI: distant background foliage, generic NPC barks, random loot icons: high volume, low impact.
- Needs a human: narrative set pieces, main character designs, emotional beats, core player-facing experiences.
- Exercise: three safe assets, one that AI would break, and why.

## The AI librarian
Use AI to search and organise human-made libraries (semantic or vector search over meshes, textures, audio) instead of generating: "spooky abandoned house furniture" works without manual tags.

## Case studies
- Codex Mortis, sold as the first fully AI-made game (marketing wording): a stress test of removing all human curation. Where does the same break appear in your pipeline?
- Call of Duty AI-art backlash: brand risk. Rust: procedural generation is never fire and forget.

## Ethics
Is this content mine, tied to a deliberate creative choice? Does it honestly represent the game? What would you tell a player who asks how it was made?

## What the player values
Players ignore the pipeline. 10,000 hollow fetch quests collapse perceived value. Maximise meaningful moments per hour, not volume.

## Workshop: Style Guide Agent
An automated art director: define the parameters (palettes, polygon budgets, texture resolution, style limits), evaluate every asset before it enters the engine, reject or approve. It is the Evaluate step of GER; the assignment adds score plus reason and the refiner.
