# Run structure

- A run is 4 levels played back to back, with nothing in between.
- Upgrades earned in a level carry into the next level. Nothing carries between runs in the core scope.
- Win: reach the extraction shuttle at the end of level 4.
- Lose: the miner dies, or misses the shuttle, on any level.
- Objective used by each of the 4 levels: open (see [[objective-variants]]).
- Difficulty ramp between levels: open.
- Milestone: M2 (M1 has a single fixed arena).
