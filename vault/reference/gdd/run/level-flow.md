# Level flow

1. **Land.** The corporate alert bar starts filling over time. Every robot killed makes it fill faster.
2. **Survive and mine.** Robot waves and chest spawns punctuate the level. XP cubes drop from kills.
3. **Objective.** Default: [[objective-beacon-hack]]. Variants: [[objective-variants]].
4. **Extract.** The shuttle lands far from the miner, with a countdown: [[extraction]].
