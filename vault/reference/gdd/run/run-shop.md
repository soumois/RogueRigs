# Run shop

Owner 2026-10-17, provisional.

- Opens on the [[intermission]] screen between two levels. Buying is optional.
- Purchases last for the current run only. Upgrades that apply to every run belong to the meta shop ([[ore-economy]]), a separate system.
- Currency: the ore collected during the run (the current ore counter). The same ore will later also pay for rerolls.
- Catalogue, prices and reroll cost: open.
- First version: not built; the intermission shows an empty shop area.
