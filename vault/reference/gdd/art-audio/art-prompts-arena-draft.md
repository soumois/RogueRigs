# Arena prompts — draft stage

Superseded: the grey rock arena borders were later replaced by a cliff into space ([[art-prompts-arena-final]]).

## 1. First arena scene
```
Flat-shaded low-poly 3D game screenshot, steep top-down camera (almost vertical, slight perspective), 16:9. An asteroid mining site: dark charcoal blue-grey rock with large smooth facets forms the arena borders (indestructible). Inside, low knee-high blocks of light grey rock with a violet tint and visible cracks (destructible), some with glowing violet crystals sticking out (ore). A scrappy independent miner in white and teal patched gear stands in the center, firing at a horde of clean industrial yellow-orange security robots with glowing red eyes. A red explosive barrel, cyan glowing XP cubes on the ground, bright muzzle flashes and a small explosion lighting the scene. Strong directional sunlight with lifted shadows so everything stays readable. Visible polygon facets, no textures, no UI, no text.
```

## 2. Floor cleanup
```
Keep everything exactly the same (characters, robots, lasers, explosion, crystals, lighting, camera). Only change the ground: remove all small scattered pebbles and rubble. The floor should be a clean, flat, slightly darker surface with only subtle large polygon facets, so that robots, pickups and destructible blocks stand out clearly.
```
