# Rigs side — prompts

Results: `vault/assets/rigs-lineup.jpg` and `vault/assets/miner-turnaround.jpg`.

## 1. Sheet: miner, drone, turret
```
Same art style as the previous images. Character sheet on a plain light grey background, three-quarter top view:
1) an independent space miner in a patched, mismatched white and teal suit, carrying a laser rifle that fires white-gold bolts;
2) a small floating drill drone that hovers next to the miner, with a spinning drill bit, same white and teal salvaged look;
3) a deployable scrap-built auto-turret made from salvaged parts, white and teal accents.
Everything here is repaired, bolted and improvised, in contrast with the clean corporate robots. No yellow, green, blue or violet on these three. Flat-shaded low-poly, no text.
```

## 2. Drone: smaller, same drill (superseded by 3)
```
Keep this exact image: same miner, same turret, same colors and style. Only change the floating drill drone: make it about half its current size, roughly the size of the miner's head and shoulders, compact and nimble, same design, same white, teal and rust colors, same drill bit and glowing eye. No text.
```

## 3. Drone: smaller, mining laser instead of drill
```
Keep this exact image: same miner, same turret, same colors and style. Only change the floating drone: make it about half its current size, compact and nimble, roughly the size of the miner's head and shoulders. Replace the drill bit with a precise mining laser emitter under its body, firing a thin white-gold cutting beam downward. Same white, teal and rust salvaged look, same glowing eye. Flat-shaded low-poly, no text.
```

## 4. Miner T-pose turnaround (for 3D generation)
```
Same character design as the validated miner (patched white, teal and rust salvaged suit). Character turnaround sheet for 3D modeling: front view, side view and back view, standing in a neutral T-pose, arms straight out, legs slightly apart, no weapon, no backpack glow, no effects. Flat-shaded low-poly, plain white background, even neutral lighting, no shadows, no text.
```
Use front and back views only; see [[asset-pipeline]].
