# Space background layers: ChatGPT prompts (task-335-01)

Need: two square tileable painted textures for the void behind the arena ([[color-code]] void line): a deep layer of wide dark colour washes (plane Z -8000) and a cloud layer of wisps and filaments with dark gaps (Z -5000), added over near-black, procedural stars kept. Own design. No image was generated by the agent (ChatGPT route, owner generates, S2 of [[task-335-space-texture-layers]]).

## Prompt chain
- Step 01, verbatim file `Art/Source/space-background/prompts/01-space-deep.txt`. Core: "flat square 1:1 texture ... near-black base #05030A to #0B0714 ... 4 to 7 very wide, very soft, very low-contrast washes ... deep indigo-violet #1A1245 to #2A1A55, violet #2E1858 to #3A2068, dusty magenta #3A1838 to #4A2046 ... brightest point below #4A2850 ... washes cross the borders ... no frame, no vignette ... no stars, planets, asteroids, text".
- Step 02, file `.../02-space-clouds.txt`. Core: "thin drifting wisps, ribbons and filaments ... large dark gaps, about 40 percent pure near-black ... indigo #241660 to #34207A, violet #4A2A88 to #5E3A9C, dusty magenta cores #6A2E64 to #7E3C78 ... brightest core below #8A4A84 ... strands cross the borders ... same forbidden list".
- Step 03, file `.../03-space-correction.txt`: A (border, vignette, seam), B (stars or objects), C (too bright or saturated), each "Keep this exact image: same ..." changing one thing, previous image attached.
- The hex ranges are provisional: [[color-code]] gives the family (deep indigo-violet, violet, dusty magenta, low saturation), not values. Dark on purpose: the layers are additive and the cloud peak must stay about 20 to 35 sRGB luma near an edge.

## Generation route
ChatGPT image generation, by the owner, one prompt per layer. Save the picks as `Art/Source/space-background/owner-2026-10-27-space-deep.png` and `owner-2026-10-27-space-clouds.png` (or the extension he gives).

## Seam method
`Tools/art/make_tileable.js --in <image> --out <tileable> --preview <3x3> --size 2048` ([[art-prompts-rock-top-texture]]). Keep the raw file.

## Review checklist
- Flat square, no perspective, no baked light, no vignette or corner darkening.
- No star, planet, asteroid, text, object; only indigo, violet, dusty magenta, never green, blue, red, orange, cyan ([[readability-rules]]).
- Deep: no filament or hard edge, very low contrast. Clouds: visible strands and dark gaps, cores below the stated peak.
- 3 x 3 preview: no seam line, no strong repeating motif.
