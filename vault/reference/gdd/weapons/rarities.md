# Rarities

- Tiers, low to high: grey, green, blue, purple, yellow.
- Rarity colors appear only in the interface (upgrade cards, HUD), never on an object in the arena ([[readability-rules]]).
- A tier scales the upgrade's magnitude.
- Magnitude per tier and drop odds per tier: open.
- Milestone: M2.
