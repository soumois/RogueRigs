## Questions
Decided 2026-11-03 (owner "ok"): every default below is accepted; values provisional, owner 2026-11-03.
- Q1 Conflit GDD : le nœud main-menu dit « pas de bouton retour au menu en pause ». Default: ta demande le remplace ; Exit agit comme le bouton « Main Menu » de fin de run gagnée : run réinitialisée (minerai à 0), L_MainMenu ouvert directement, sans écran de chargement ni fondu, sans fenêtre de confirmation.
- Q2 Ouverture : Default: Échap ou Start manette pendant le jeu met en pause et ouvre le menu, la même touche ou Resume le ferme ; P fait la même chose (Échap arrête le Play In Editor). Inaccessible quand un autre écran met déjà le jeu en pause (cartes de level-up, écrans d'intermission, chargement, game over, run gagnée) et dans le menu principal. Curseur affiché, focus clavier sur Resume.
- Q3 Contenu : Default: bloc global = les 6 stats du mineur à leur valeur actuelle (vie max et chance en points ; vitesse, rayon de ramassage, gain d'XP, vitesse de minage en bonus % sur la base), puis la somme des bonus globaux d'armes pris (dégâts %, cadence %, rechargement %, chance et dégâts critiques en points) ; puis un bloc par arme possédée (dégâts, cadence, rechargement, chance critique, dégâts critiques, chargeur, perforation), emplacements verrouillés non affichés. Textes en anglais écrits dans le widget, titre « PAUSED », boutons « Resume » et « Exit ».
- Q4 Maquette : Default: un tour = une seule image (16:9, 1K, environ 6 crédits), gpt-image-2 image-to-image avec la maquette de fin de niveau validée en Image 1, prompt écrit par l'agent art avec le contenu de Q3 ; le fichier t'est envoyé dans cette conversation avec le coût lu dans le log ; chaque remarque de ta part = un nouveau tour d'une image sur la maquette précédente.
- Q5 Éléments après « je valide » : Default: sprites existants d'abord (cadre et séparateurs de fin de niveau, barre de titre, bouton Continue pour Resume et Exit, icône minerai, icônes d'armes) ; un élément nouveau est découpé dans la maquette validée s'il est net à 1K, sinon régénéré via Kie.ai image-to-image depuis la maquette (1 variante, environ 6 crédits, 24 crédits au plus pour l'étape, cadres en 3x3) ; tu les vois dans la capture finale.
- Q6 Vérification : Default: capture -game par l'agent capture aux quatre résolutions de la règle (1920 x 1080, 1280 x 720, 1920 x 1200, 2560 x 1080), menu ouvert en cours de run avec deux armes, comparée à la maquette validée, plus Resume et Exit déclenchés par une commande rr.Debug.PauseMenu (mêmes fonctions que les boutons) ; aucun nouveau test automatisé.
- Q7 Disposition (provisoire, tu retouches à la main) : Default: WBP_PauseMenu dans Content/RogueRigs/UI/, Root Canvas et ancres, positions en fractions d'écran mesurées sur la maquette validée, fond noir semi-transparent sur l'arène en pause.
